#### 资产信息梳理

> 资产信息梳理从资产概览、资产标签分布（TOP10）、软件应用分布（TOP10）、资产来源分布（TOP10）进行资产重要信息描绘。

![](图片附件/image146.png)

（1）筛选

点击「组织机构」筛选框，支持基于组织机构多层级筛选，多选。

（2）资产概览

---

确认资产 统计经过运营人员确认，通过手动添加、文件导入或从第三方确信来源获取的 IP 资产

未知资产 统计第三方来源（如扫描器、全流量等）识别到的存活资产，但未经过运营人员确认的未知资产数量

关联告警资产 统计最近 7 天内存在安全告警的确认 IP 资产数量

存在漏洞资产 统计存在「待处置」、「验证中」、「修复中」、「复测中」漏洞状态的全量漏洞，关联的确认 IP 资产数量

新增的资产 统计从第三方来源自动同步或手动添加/导入的资产，且未被修改过的新增 IP 资产数量

变更的资产 统计已存在，且被修改确认 IP 资产数量

新增端口的资产 统计从第三方来源同步新增端口数据的确认 IP 资产数量

变更端口的资产 统计从第三方来源同步端口数据，且端口数据发生变更的确认 IP 资产数量

---

![](图片附件/image147.png)

（3）资产标签分布（TOP10）

基于确认 IP 资产存在的「资产标签」，并聚合统计其关联资产的数量，进行 TOP10 排序。

点击「标签」可跳转至确认 IP 资产列表，筛选包含该标签的 IP 资产。

![](图片附件/image148.png)

（4）软件应用分布（TOP10）

基于确认 IP 资产存在的「软件」，并聚合统计其关联资产的数量，进行 TOP10 排序。点击「软件」可跳转至确认 IP 资产列表，筛选包含该软件的 IP 资产。

![](图片附件/image149.png)

（5）资产来源分布（TOP10）

基于确认 IP 资产的「来源」属性，并聚合统计其关联资产的数量，进行 TOP10 排序。

点击「来源」可跳转至确认 IP 资产列表，筛选包含该来源的 IP 资产。

![](图片附件/image150.png)
