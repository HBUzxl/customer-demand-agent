## 告警列表

告警列表用于统一管理告警信息，用户能够筛选告警、查看告警信息、研判处置告警。

1.筛选告警

平台提供简单筛选和告警筛选两种筛选方式。默认使用简单筛选，用户能够通过告警名称、等级、攻击 IP、受害 IP 等单个或多个字段快速筛选告警，多个条件之间为"与"的关系。

![](图片附件/image45.png)

高级筛选支持多条件"AND/OR"组合方式、多种判断条件、多级嵌套方式，能够更加灵活地筛选告警。

![](图片附件/image46.png)

2.查看告警信息

告警列表中展示告警重要信息，展开能够查看告警原因、处置建议和研判处置状态，或点击查看按钮进入告警详情页面。

![](图片附件/image47.png)

3.研判处置告警

在告警列表或详情页面可以对告警进行研判或处置操作，包括确认告警、忽略告警、给告警打标签、利用告警生成情报、发送通知、添加告警白名单、触发工单、IP 封禁、触发剧本、归档告警、导出告警、AI研判。

1.确认/忽略告警：用户对告警进行人工研判后可以确认或忽略告警，忽略后列表中默认不再展示告警。

2.打标签：用户给告警打标签，后续能够通过标签筛选告警。

![](图片附件/image48.png)

3.生成情报：根据告警信息生成威胁情报。

![](图片附件/image49.png)

4.发通知：将告警信息以短信或邮件的方式通知其他人员，通知内容能够自定义设置。点击"通知内容"输入框，能够编辑文字，或选择变量添加到内容中。以默认通知内容为例，发送后接收人将看到"2022-09-28
    18:00:00 万象平台新增"测试告警"，告警等级为"低危"，告警类型为"SQL 注入"，攻击 IP 为"1.1.135.219"，受害 IP/网站为"1.1.135.219"，告警内容为"测试 SQL 注入"，处置建议为"无"。请您及时关注并处理！"

![](图片附件/image50.png)

5.白名单：将攻击 IP 或受害 IP 设置为告警白名单，之后满足条件的攻击 IP 或受害 IP 将不再产生告警。

![](图片附件/image51.png)

6.触发工单：发起告警处置工单。

![](图片附件/image52.png)

7.IP 封禁：手动封禁告警中的攻击 IP。

![](图片附件/image53.png)

8.触发 PlayBook：若当前告警的关联分析规则设置触发 SOAR，则可以选择已配置的 PlayBook，若告警的关联分析规则没有设置触发 SOAR，可以在"更多"中选择其他 PlayBook。

![](图片附件/image54.png)

9.归档告警：手动归档告警，平台也会自动化归档历史告警信息，可以在配置中心-系统管理-数据存储中设置。

10.AI研判：可点击【告警列表-操作列-AI研判】按钮，设置研判条件（如处理优先级、预期动作、自动化程度、研判建议等），创建安全事件研判。

![](图片附件/AI研判.png)

![](图片附件/AI研判配置.png)

在【告警详情-AI研判】页面也可创建事件研判，同时可查看研判过程。

![](图片附件/AI事件分析.png)

在【AISOC】页面可查看所有事件研判的信息及详细研判处置过程。

![](图片附件/AISOC页面.png)
