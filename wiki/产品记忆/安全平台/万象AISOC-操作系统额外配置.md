#### 操作系统额外配置

##### 关闭 Selinux

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**       | 强制执行                                                                                                                                                                                                                                                                                                               |
| **适用产品形态** | 所有                                                                                                                                                                                                                                                                                                                   |
| **步骤**         | 执行以下 shell 命令： <br/> #更改配置为 disabled <br/> sed -i '/SELINUX/s/enforcing/disabled/'  /etc/selinux/config <br/> #重启系统以生效（若有其他配置需要重启可统一更改后再重启）<br/> reboot <br/> #重启后执行命令查看是否生效 <br/> sestatus <br/> 输出：disabled 即生效 <br/> ![](图片附件/image4.png) |

##### 时间

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**       | 强制执行                                                                                                                                        
| **前提**         | 各节点时间不一致或与北京时间有差异                                                                                                                               |
| **适用产品形态** | 所有                                                                                                                                                             |
| **步骤**         | 执行以下 shell 命令： <br/> #查看时间 <br/> date <br/> #修改时间 <br/> date -s '2023-09-15 00:00:00' <br/> #将系统时间同步到硬件时间 <br/> hwclock \--systohc |
| **注意事项**     | 部署完成后再将时间往过去时间调，会引起万象崩溃。                                                                                                                         |

##### 单机版、集群版管理端清空数据盘磁盘分区

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 强制性       | 强制执行                                                                                                               |
| 前提         | 非新硬盘 ，反复使用的硬盘作为数据盘，需要删除分区确保正常安装。                                                        |
| 适用产品形态 | 单机版、集群版管理端                                                                                                   |
| 备注         | 单机版、管理端安装程序会自动处理数据盘，前提是该盘符不能有任何使用，所以需要对盘符进行清除操作                         |
| 步骤         | 执行以下 shell 命令：<br/> #sdX 中的 X 替换为需要清除数据的数据盘盘符 <br/> parted \--script /dev/sdX "mklabel msdos" |

    <td>RAID0 多盘符情况，下面以宝德 5000 机型为例，执行以下 shell 命令<br/>- 执行命令 lsblk<br/><img src="图片附件/image6.png" style="zoom:50%;"/><br/> - 执行磁盘清理和挂载命令<br/>
    （非标准宝德 5000 服务器，根据 lsblk 显示的【数据盘】盘符在下方更改或删减 arr 赋值的字母；
    非标准宝德 5000 服务器，根据 lsblk 显示的【数据盘】盘符更改出现的"/dev/sd"前缀。如阿里云显示 vdb 需要改为/dev/vd）
    <pre>
declare -a arr=("b" "c" "d" "e" "f" "g")
for i in "${arr[@]}"
do
  echo "$i"
  DEVICE="$i"
  parted --script /dev/sd${DEVICE} "mklabel gpt mkparprimary xfs 0% 100%"
  mkfs.xfs -f /dev/sd${DEVICE}1
  mkdir -p /data${DEVICE}
  mount /dev/sd${DEVICE}1 /data${DEVICE}
  echo "# /dev/sd${DEVICE}1" >> /etc/fstab
  echo "UUID=$(blkid -o value -s UUID /dev/sd${DEVICE}1) /data${DEVICE} xfs defaults 0 0" >> /etc/fstab
done
mount -a /etc/fstab
lsblk
    </pre>

##### 磁盘读写检查

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**       | 非强制                                                                                                                                                                                                                                                                                                                                                                 |
| **前提**        | 非新硬盘，读写性能较差，安装过程中会引起部分过程超时。部分安装步骤过程无法重试可能导致重新安装系统。                                                                                                                                                                                                                                                                   |
| **适用产品形态** | 所有                                                                                                                                                                                                                                                                                                                                                                   |
| **步骤**         | ![](图片附件/image10.png) <a href="图片附件/fio" target="_blank">点击下载</a> <br/> 将上面 fio 文件传输到各万象节点的/root/目录下然后执行以下 shell 命令 <br/> #给执行权限 <br/> chmod +x ./fio <br/> #读写性能检查 <br/> ./fio \--rw=write \--ioengine=sync \--fdatasync=1  \--size=100m \--bs=8000 \--name=etcd_perf \--runtime=60  \--time_based=1 <br/> 执行结果示意图及要求 <br/> ![](图片附件/image11.png) |
| **注意事项**     | 不满足该要求部署完成后可能会导致万象页面周期性无法正常访问                                                                                                                                                                                                                                                                                                             |

##### 大数据禁用 dnsmasq

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**   | 仅大数据节点执行                                                                                                                                |
| **适用模式** | 集群版大数据                                                                                                                                    |
| **备注**     | 该步骤会引起 hadoop 相关服务启动因 53 端口占用而失败（大多数在大数据操作系统重启后出现），可在 http://大数据主节点 IP:8080 查看到相关报错       |
| **步骤**     | 执行以下 shell 命令 <br/> systemctl stop dnsmasq <br/> systemctl disable dnsmasq <br/> systemctl status dnsmasq <br/> ![](图片附件/image13.png) |

##### CentOS7.9 系统更改 cgroup mem 相关配置

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**   | CentOS7.9 系统下强制执行                                                                                                                                                                                                        |
| **适用模式** | 单机版、集群版管理端                                                                                                                                                                                                            |
| **步骤**     | \# 注意输入的准确性，该命令只允许执行一次 <br/> sed -ibackup '/GRUB_CMDLINE_LINUX/ s/"\$/ cgroup.memory=nokmem"/g' /etc/default/grub <br/> /usr/sbin/grub2-mkconfig -o /boot/grub2/grub.cfg <br/> #重启！ <br/> reboot |

##### Kylinv10 系统关闭 auditd

| 项目       | 内容                                                                                                                                                                                                                                                                                                            |
| :------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **强制性**   | Kylinv10 系统强制执行                                                                                                                                                                                                                                                                             |
| **适用模式** | 所有                                                                                                                                                                                                                                                                                              |
| **步骤**     | \# GRUB_CMDLINE_LINUX 最后添加 \` audit=0\`<br/> sed -iback 's/^GRUB_CMDLINE_LINUX="\\(.*\\)"/GRUB_CMDLINE_LINUX="\1 audit=0"/' /etc/default/grub <br/> grep GRUB_CMDLINE_LINUX /etc/default/grub <br/> /usr/sbin/grub2-mkconfig -o /boot/grub2/grub.cfg <br/> /usr/sbin/grub2-mkconfig -o /boot/efi/EFI/kylin/grub.cfg <br/> reboot |
