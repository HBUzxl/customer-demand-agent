### Web 攻击

统计展示 Web 风险类型下的事件等级分布、事件数量变化趋势、源 IP 和目的 IP 排名、二级分类占比、以及事件详情列表。用户能够通过时间范围、事件类型、源 IP、目的 IP，时间默认展示最近 24 小时。

1.威胁统计

展示事件等级分布情况，包括超危事件、高危事件、中危事件、低危事件、安全事件、未知事件。

![](图片附件/image117.png)

2.事件量统计

默认展示最近 24 小时事件数量。

![](图片附件/image118.png)

3.源 IP（TOP5）

展示源 IP 数量 TOP5。

![](图片附件/image119.png)

4.目的 IP（TOP5）

展示目的 IP 数量 TOP5。

![](图片附件/image120.png)

5.事件类型占比（TOP5）

展示 TOP5 事件类型占比。

6.日志列表

展示事件时间、源 IP、目的 IP、目的端口、事件名称、事件分类、事件等级，默认按事件时间由近到远。

![](图片附件/image122.png)
