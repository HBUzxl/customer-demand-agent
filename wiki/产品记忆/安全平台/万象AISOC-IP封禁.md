### IP 封禁

边界拦截能够联动防火墙等边界安全设备封禁外部攻击 IP，查看已封禁 IP 情况，进行人工封禁或解禁。

![](图片附件/image67.png)

1.查找封禁 IP 数据：支持通过封禁时间、IP 地址、封禁方式、边界安全设备名称等条件筛选封禁数据。

2.封禁占比统计：统计自动化封禁和人工手动封禁的数量及占比。

3.封禁趋势：统计展示封禁趋势和封禁总数。

4.封禁 IP 列表：展示已封禁的 IP 信息列表，点击操作中![](图片附件/image68.png)按钮可以解禁单个 IP，选个多个 IP 后点击"批量解禁"可以批量多个 IP。解禁时，可以查看当前 IP 封禁状态，并填解禁备注，解禁后 IP 不再展示在列表中。

![](图片附件/image69.png)

5.设备列表：展示边界安全设备的厂商、名称、已封禁 IP 数量以及设备 IP 封禁数量上限。

6.人工封禁操作框：选择封禁边界安全设备后，输入单个或多个 IP 进行封禁或解禁，多个 IP 间用英文逗号或回车隔开，一次性最多封禁/解禁 1000 个 IP。

7.查看封禁历史

![](图片附件/image70.png)

8.下载封禁记录：点击"下载"按钮能够将当前封禁列表信息导出到 Excel 表格中，导出内容包括 IP 地址、封禁时间、封禁方式、防火墙名称、备注。
