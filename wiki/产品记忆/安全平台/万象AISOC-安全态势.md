## 安全态势

综合态势页面是从平台整体视角，综合展示平台运行状态、威胁、资产、AI分析、运营数据及自定义的仪表盘投放数据，帮助用户快速掌握平台整体情况。默认统计时间范围为"今天"，用户在右上角可以设置时间范围。

平台运行状态，当平台管理端或大数据出现异常时，点击【异常】可以跳转到"平台监控"页面查看详情。

![](图片附件/运行状态.png)

告警趋势，展示告警数量变化趋势，鼠标移入柱形会出现浮窗展示各等级告警数量，点击蓝色文字能够跳转到"告警列表"查看告警详情。
从告警及重点告警维度对告警总数、环比增长/下降情况、研判状态、处置状态、高危攻击、攻击成功等指标进行量化和展示；点击对应指标数值，可跳转到告警列表查看对应指标关联的告警情况。

![](图片附件/威胁.png)

从资产清点、资产风险、资产脆弱性三个维度对资产情况进行量化和展示；支持基于资产类型统计相关资产总数、新增未知资产总数；从资产发起攻击、遭受攻击、异常行为维度等，统计疑似失陷资产、遭受攻击资产、发起高危攻击资产数量，量化资产风险情况；基于资产脆弱性，统计存在高危漏洞的资产数量、存在漏洞的资产数量、高危漏洞事件数量，量化资产脆弱性情况；点击相关量化指标数值，快速查看对应资产情况。

![](图片附件/资产.png)

统计AI分析研判事件总数、AI分析中任务数量及研判准确率；统计智能响应事件总数、AI有效处置数量及处置准确率；统计AI分析事件等级占比信息，能够查看具体等级关联的事件数量、占比情况；统计事件来源分布情况，从告警机制、自动化策略、人工创建3个维度量化事件来源，并展示来源自动化率；统计AI运营模式分布情况，从半自动、全自动、手动3个维度量化运营模式关联的事件指标，并展示AI自动化率。

![](图片附件/AI分析.png)

1、基于确认、忽略、待研判三个维度量化告警研判情况，支持点击对应指标数值，快速查看相关告警信息；支持统计告警研判率、自动研判率；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑；
2、基于已处置、待处置维度量化告警处置情况，支持点击对应指标数值，快速查看相关告警信息；支持统计告警处置率率、自动处置率；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑；
3、通过从平均检测时间MTTD、平均响应时间MTTR、降噪率三个维度，对告警运营情况进行量化展示；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑；
4、基于工单待处理、我关注、我创建等视角，统计对应工单总数、工单超时数量；支持点击对应指标数值，快速查看相关工单信息；
5、通过通知、IP封禁、主机隔离等处置动作维度对告警进行量化；支持点击对应指标数值，快速查看相关告警信息；
6、基于自动化策略、SOAR剧本等响应方式对告警自动响应情况进行量化；支持点击对应指标数值，快速查看相关自动策略及剧本信息；支持统计告警自动化响应率；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑；
7、基于事件来源（分析中/事件总数）、AI分析（告警/自动化/人工）、研判准确率等指标对AI事件分析过程及结果进行综合量化展示；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑；
8、基于AI处置（有效处置/总数）、处置有效率、自动模式（半自动/自动/手动）等指标对AI事件智能响应模式、结果及有效性进行综合量化展示；鼠标移至卡片右上角的【注释】icon，可查看当前指标的计算逻辑。

![](图片附件/运营.png)

告警攻击 IP 排名，鼠标移入攻击 IP 浮窗展示更多信息，点击浮窗中蓝色文字能够跳转到对应页面，点击攻击次数跳转到告警列表。当告警的"攻击结果"为成功或疑似成功，标记为"疑似成功"。当告警命中威胁情报，标记为"命中情报"。

![](图片附件/攻击IP.png)

告警受害 IP 排名，鼠标移入受害 IP 浮窗展示更多信息，点击浮窗中蓝色文字能够跳转到对应页面，点击被攻击次数跳转到告警列表。当受害 IP 关联资产且资产为"疑似失陷"状态，标记为"疑似失陷"。当受害 IP 存在超危或高危漏洞时，标记为"高危漏洞"。

![](图片附件/受害IP.png)
