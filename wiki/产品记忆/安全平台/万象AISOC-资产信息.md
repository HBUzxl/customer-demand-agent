#### 资产信息

确认资产用于管理基础信息完整的确认资产信息，包括「IP 资产」和「应用资产」。点击右上角「列表/详情 TAB」可以切换列表和卡片展示资产信息。

（1）资产权限

基于系统权限模型，当前登录账号只能看到和管理自己所属组织和下级组织的资产信息。

（2）资产管理

① 资产筛选：可通过默认筛选条件及更多筛选条件，对资产进行筛选；

![](图片附件/image162.png)

② 分组统计

系统从「资产类型」、「中心/域」、『组织机构』三个维度对资产进行统计。在「筛选框」中输入对应的信息，可模糊筛选对应的类型、域或组织机构信息；点击对应统计，可筛选右侧资产列表。

![](图片附件/image163.png)

（1）新增资产

点击「新增资产」能够通过「手动添加」或「批量导入」新增资产信息。

（2）手动添加资产

（3）批量导入资产

点击「批量导入」后，在新的页面配置如下信息：

① 选择资产「所属组织机构」，并上传资产模板 Excel 文件；

② 点击「确定」按钮，即可上传资产；

③
点击右上角「下载 Excel 模板」可下载资产导入模板，模板中标记\*的为必填信息，若没有填写会导入失败。

![](图片附件/image164.png)

（4）资产操作

① 批量操作

选择列表中多个资产，点击「更多操作」按钮，可对选中资产进行批量忽略、导出选中（Excel 格式，单次最多 100 条）、触发工单（跳转至新增工单页面，填写工单信息后，进入工单流程）、发通知（针对当前选中资产，选择通知方式、配置通知模板后，即可发送通知）。

（5）资产详情

点击「资产列表-详情」按钮，进入资产详情页面，资产详细信息展示如下：

① IP 资产详情-头部卡片信息

---

ICON IP 资产标识

资产名称 显示「资产名称」+「IP」

所属安全域 使用标签展示安全域信息

资产类型 使用标签展示资产类型

资产重要性 使用标签展示资产重要性

发起攻击告警 当前 IP 作为攻击 IP 发起攻击告警数量，点击数值可携带当前资产「IP」、「组织机构」跳转到「研判处置-告警列表」页面，筛选符合条件的告警信息

遭受攻击告警 当前 IP 作为受害 IP 遭受的告警数量，点击数值可携带当前资产「IP」、「组织机构」跳转到「研判处置-告警列表」页面，筛选符合条件的告警信息

漏洞数量 当前 IP 存在的漏洞数量，点击数值可携带当前资产「IP」、「组织机构」跳转到「资产中心-资产脆弱性-IP 漏洞事件」页面，筛选符合条件的漏洞信息

端口数量 当前 IP 存在的端口数量，点击数值可跳转至「端口/软件」TAB，查看对应的端口信息

软件数量 当前 IP 存在的软件数量，点击数值可跳转至「端口/软件」TAB，查看对应的软件信息

编辑 针对当前 IP 资产进行编辑管理

更多操作-发通知 点击「发通知」按钮，在侧弹页面配置通知方式、通知模板后，可发送当前资产信息给具体的账户

更多操作-触发工单 点击「触发工单」按钮，在新页面配置资产工单信息，保存后，可基于工单流程进行资产的管理

更多操作-忽略资产 点击「忽略资产」按钮，页面弹窗提示：是否忽略当前 IP 资产？（忽略资产后，关联的资产信息也会同时删除）；忽略的资产可在「确认记录」页面查看

价值属性

保密性 描述当前资产保密新，用于评估资产重要性、资产评分

完整性 描述当前资产完整性，用于评估资产重要性、资产评分

通用扩展属性，针对各类资产通用型字段

变更记录 记录资产全生命周期的变更信息
