#### 资产脆弱性

资产脆弱性从资产存在中高危漏洞（TOP10）、资产存在弱口令漏洞（TOP10）、漏洞处置来描述资产关联脆弱性漏洞的情况。

![](图片附件/image156.png)

（1）筛选

点击「组织机构」筛选框，支持基于组织机构多层级筛选，多选。

点击「统计时间」筛选框，统计在选定时间范围内资产关联脆弱性漏洞的情况。

资产存在中高危漏洞（TOP10）

统计确认 IP 资产存在中危、高危、超危漏洞的情况，并基于 IP 进行聚合统计漏洞数量，展示 TOP10。

鼠标悬浮至 IP，可通过浮窗查看资产概览信息，点击「查看资产详情」，可跳转至确认 IP 详情页面，查看该资产详细信息。

点击「数值」，可跳转至「IP 漏洞事件」页面，显示该 IP 关联的漏洞信息。

![](图片附件/image157.png)

资产存在弱口令漏洞（TOP10）

统计确认 IP 资产存在弱口令漏洞的情况，并基于 IP 进行聚合统计漏洞数量，展示 TOP10。

鼠标悬浮至 IP，可通过浮窗查看资产概览信息，点击「查看资产详情」，可跳转至确认 IP 详情页面，查看该资产详细信息。

点击「数值」，可跳转至「IP 漏洞事件」页面，显示该 IP 关联的脆弱性漏洞信息。

![](图片附件/image158.png)

统计确认 IP 资产存在漏洞的处置情况。
