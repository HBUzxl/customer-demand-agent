#### 遭受攻击告警

遭受攻击告警从可疑资产、告警处置情况、资产发起中高危告警（TOP10）、资产遭受中高危告警（TOP10）描述资产重遭受攻击告警的情况。

![](图片附件/image151.png)

（1）筛选

点击「组织机构」筛选框，支持基于组织机构多层级筛选，多选。

点击「统计时间」筛选框，统计在选定时间范围内资产关联告警的情况。

（2）可疑资产

| 疑似感染僵木蠕资产 | ① 统计匹配到安全告警（攻击 IP 或受害 IP），且告警类型包含：恶意软件、APT、域名命中、各类后门通信（排除反弹 shell、webshell 通信）的确认 IP 资产数量。<br/> ② 点击「数值」，跳转到「确认 ip 资产」列表页面，查看对应的资产。 |
| 疑似失陷资产 | ① 统计匹配到安全告警（攻击 IP 或受害 IP），且告警失陷状态包含：失陷、疑似失陷的确认 IP 资产数量 <br/> ② 点击「数值」，跳转到「确认 ip 资产」列表页面，查看对应的资产。 |

（3）告警处置情况

统计确认 IP 资产作为攻击源 IP、受害目的 IP 的告警处置情况。

![](图片附件/image152.png)

（4）资产发起中高危告警（TOP10）

统计确认 IP 资产作为攻击源 IP 发起攻击的告警情况，并基于攻击源 IP 进行聚合统计告警数量，展示 TOP10。

鼠标悬浮至 IP，可通过浮窗查看资产概览信息，点击「查看资产详情」，可跳转至确认 IP 详情页面，查看该资产详细信息。

![](图片附件/image153.png)

点击「数值」，可跳转至「告警列表」页面，显示该 IP 关联的告警信息。

![](图片附件/image154.png)

（5）资产遭受中高危告警（TOP10）

统计确认 IP 资产作为受害目的 IP 遭受攻击的告警情况，并基于受害目的 IP 进行聚合统计告警数量，展示 TOP10。

鼠标悬浮至 IP，可通过浮窗查看资产概览信息，点击「查看资产详情」，可跳转至确认 IP 详情页面，查看该资产详细信息。

点击「数值」，可跳转至「告警列表」页面，显示该 IP 关联的告警信息。

![](图片附件/image155.png)
