### 数据管理

点击【机构管理】按钮，在侧弹页面配置机构管理信息，配置如下：

① 机构简称，必填，输入机构对应的简称，如期货交易中心；

② 交易所简称，非必填，仅用于交易所机构报送（如北交所、深交所、上交所），输入后，系统可读取当前交易所简称用于报送；

③ 机构类型，必选，用户选择本机构对应的机构类型，用于生成机构代码；

④ 社会统一信用代码，必填，用户填写本机构对应的社会统一信用代码，用于生成机构代码；

⑤ API Token，必填，中证返回的 API
Token 信息，用于数据报送质量信息的拉取认证。
