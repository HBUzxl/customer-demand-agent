## 威胁场景

威胁场景针对全网攻击方式、方向、过程、结果等进行分析和统计展示。

### 外部威胁

外部威胁是基于安全告警中【告警标签】为【外部威胁】的告警数据统计集合，主要对互联网侧发起攻击的量化展示。默认对【今日】范围的外部威胁告警进行统计。

| 标题 | 描述 |
| -------------- | --------------------------------------------------- |
| 告警概览 | ① 统计告警总数、不同等级告警数量、告警环比情况；点击【蓝色】数值可跳转至告警页面；② 统计攻击 IP、疑似攻击成功的 IP、命中情报、封禁 IP 数量；点击【蓝色】数值可跳转至告警页面； |
| 处置建议 | 针对外部威胁，提供专业化的处置建议；|
| 攻击/受害目的IP | 从攻击/受害 IP 维度统计外部攻击和受害 IP TOP；|
| 命中情报/国家 | 从命中情报统计情报国家 TOP、命中情报数量、情报总数；|
| 告警名称 TOP10 | 从告警名称维度，统计关联告警数量最多的告警名称；|
| 风险研判&处置 | 统计告警研判率（已研判、已确认、已忽略）、处置率（已处置、未处置）、封禁 IP、边界拦截设备数量；|
| 告警列表 | 外部威胁告警列表，可筛选告警，可查看原始告警信息，可对告警进行 IP 封禁、可生成情报。|

| 标题 | 描述 |
| -------------- | --------------------------------------------------- |
| 告警概览 | ① 统计告警总数、不同等级告警数量、告警环比情况；点击【蓝色】数值可跳转至告警页面；② 统计攻击 IP、疑似攻击成功的 IP、命中情报、封禁 IP 数量；点击【蓝色】数值可跳转至告警页面； |
| 处置建议 | 针对攻击穿透场景，提供专业化的处置建议； |

| 穿透威胁 | 通过桑基图的方式将安全设备、攻击 IP、受害 IP 进行聚合展示； |
| 告警名称 | 从告警名称维度，统计关联告警数量最多的告警名称； |
| 涉及设备 TOP10 | 从安全设备维度，统计产生告警关联的设备名称；鼠标悬浮弹窗可查看设备的概要信息； |
