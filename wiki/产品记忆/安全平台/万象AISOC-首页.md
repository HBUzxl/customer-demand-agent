# COSMOS - 长亭万象AISOC 安全分析与运营管理平台

<!-- endtoc -->

## 产品介绍

知攻善防·智能安全，长亭科技面向企业发布了万象（COSMOS）安全分析与运营管理平台，基于「人+平台」、「智能驱动安全」的产品设计理念，取“包罗万象”之意，采用先进大数据架构、依托长亭多年攻防经验，围绕数据管理、风险分析、运营响应，为用户建立常态化安全运营平台，帮助政企全面提升安全分析及响应效率。 

万象（COSMOS）包括5层功能架构，包括：采集层、数据层、分析层、应用层、展示层，提供多源数据采集能力、安全数据细分管理能力、安全风险场景分析能力、安全自动化编排能力、风险告警/可视化态势展示能力、智能告警分析研判能力、资产&脆弱性管理能力等。

万象是一个"安全数据中心"，能够通过主被动结合的方式接入覆盖企业全部范围的基础 IT 数据、资产脆弱性数据、流量检测数据、威胁情报数据、用户行为数据等，并支持对多源异构数据进行零基础范化，为业务层数据分析提供标准化数据基础。

万象是一个"安全分析中心"，能够集成多种安全分析算法、安全分析工具、安全分析引擎、分析结果展示工具等，有效发现网络空间中的暴力破解、恶意文件、Web 攻击、隐蔽隧道等多种攻击行为，并支持通过多维聚焦的方式进行呈现。

万象是一个"安全运营中心"，能够基于"人+平台"的运营理念，依靠平台提供的智能风险分析能力、结合实战攻防经验丰富的长亭安服团队，能够高效的支撑风险分析研判工作，输出更加紧贴业务的风险告警，并支持自动化处置。

## 核心模块

| 维度 | 能力概要 |
|:---|:---|
| 数据ETL | 具备多源异构数据采集能力、数据解析全过程可配置&监控能力、数据多次解析能力、数据模型管理能力； |
| 日志检索 | 具备日志数据综合检索能力、数据可视化分析能力、数据下钻&排序&调查&导出&自定义展示等管理能力； |
| 自然语境 | 具备复杂逻辑匹配&统计聚合&时序分析等自然语境分析能力；具备自动化攻击结果判断、告警信息补全能力，可针对网络攻击、用户异常行为、脆弱性、恶意文件、主机安全等场景对告警属性进行灵活扩展及定义，形成告警分析和处置闭环； |
| 关联分析 | 基于离线周期与流式实时引擎，具备复杂逻辑匹配&统计聚合&多源校验（异构数据）&关联查询（多表join、in）&时序分析&函数定义及语句编排等能力、支持多次复杂分析结果引用，通过平台大数据分析架构及灵活白盒化配置能力帮助客户实现业务风险感知能力； |
| 安全告警 | 具备告警展示、自动策略、白名单、告警研判、告警通知、告警处置、告警模型、告警分类等综合管理能力；支持告警多维度聚合； |
| 资产管理 | 具备IP资产&应用资产的资产运营管理能力、具备资产模型管理能力、具备第三方资产对接能力； |
| 风险可视 | 具备大屏展示能力、具备内置及扩展多种可视化视图能力；具备多种报告类型（日/周/月/季/年/临时）管理及自定义报告模板能力； |
| SOAR | 具备自动化处置类、人工流程类、日常合规类、运维监控类、即时通知类、综合工具类等剧本构建和管理能力，快速上线面向用户实际业务的运营场景； |

除上述功能外，还支持数据上报、威胁情报管理、脆弱性管理、网络拓扑管理、运营知识库、工单管理、设备监控、多种部署模式（级联部署、集群部署等）等；


## 技术实现

### 核心特性

- **全链路数据采集**：kite-agent、kite-receiver、etlgo 等；
- **管理端核心系统**：pedestal、vision 等；
- **大数据分析平台**：mars、detector 等；
- **SOAR 自动化响应**：soar-scheduler、soar-executor、workflow 等；
- **可视化与报表**：datav、report-center 等；


### 技术栈

- **前端**：React 17 + TypeScript 5 等；
- **后端**：Go + PostgreSQL + ClickHouse + Redis + Kafka 等；
- **大数据**：Flink + Spark + ClickHouse + HDFS 等；
- **基础设施**：Kubernetes/k3s + Docker + Helm 等；
