# APISEC 操作手册

**长亭高级API安全系统（APISEC）**


# 产品概述


## 产品介绍

长亭高级API安全系统通过采集流量信息，智能发现业务API资产及传输敏感数据并自动提取用户身份，结合风险和行为分析模型，实时感知API健康状况，及时发现API异常行为，确保信息系统中所有API资产可视、风险可知、安全可控。

## 核心优势


### API资产智能梳理

长亭高级API安全系统根据Restful规范，自动识别请求路径中的变量，并对不同变量的请求路径进行聚合，提炼API资产。另一方面，系统自动学习API流量中请求响应的结构模式，并区分不同业务的请求模式，从而自动发现如JSON-RPC等根据请求体中谓词进行区分的API资产。
长亭高级API安全系统提供可编程的数据处理技术作为解决方案，对业务系统中特殊的数据构造逻辑定制化的进行解析与处理，用于后续的API资产识别、敏感数据发现、风险检测等方面，保证数据的准确性。基于实践经验，长亭高级API安全系内置多个常见的特殊解析逻辑，并提供特征校验的方式对流量进行预测，提示用户是否需要开启对应的解析逻辑。

### 全方位覆盖OWASP API TOP10威胁检测

长亭高级API安全系统结合语义分析对注入类攻击提供准确的识别结果，基于大数据基线检测、专家策略等检测API资产面临的各类风险威胁，支持四十余种不同的风险检测策略，覆盖OWASP API TOP10分类中的各个大类，并为不同检测策略提供相应的自定义能力。同时基于流量匹配已知软件与API的指纹特征，识别知名供应商的产品，并根据知识库与版本匹配识别已知漏洞，提早预防漏洞被攻击者利用。

### 准确的数据识别能力

长亭高级API安全系统支持自适应的深度解码技术，可以在对HTTP报文进行解析后，继续对请求参数、请求头、请求体、响应头、响应体尝试进行多层的递归解码，包括Gzip等压缩算法，Base64、Hex等编码算法，JSON、XML等序列化算法。
长亭高级API安全系统一方面保证数据识别的完整性，不让数据丢失在复杂的编码中，同时保证数据不被过度解码，解码出来的数据是有意义的，为后续的API资产识别、敏感数据发现、风险检测等提供有力的数据基础。

### 流量接入全面

长亭高级API安全系统支持多种场景下不同的流量采集方式，并能够对企业内部的API资产进行统一管理：
1.Nginx嵌入式：Nginx加载动态模块，适用于使用Nginx网关统一接收访问流量并进行负载均衡的网络拓扑
2.云上vxlan解析：支持解析公有云上流量镜像的vxlan协议，适用于解析阿里云等公有云上流量镜像服务
3.交换机流量镜像：支持解析交换机的流量镜像，适用于通过交换机流量镜像获取业务流量进行解析的场景
4.SDK引流：提供SDK用于其他系统二次开发，在常规接入方式无法适用的场景下，提供可以定制开发的基础

# 资产梳理

“资产清点”模块主要维护应用-站点-API的三维资产数据。可实时、准确、全面的了解监测网络中的API资产信息，及其相关的访问情况、脆弱性情况和敏感数据传输情况等。

## API资产

点击【API资产】模块，可视化查看当前系统发现的业务资产API列表。支持点击页面右侧自定义展示列按钮，灵活定义资产审计页面列表展示字段。支持按[请求开始时间]、[响应开始时间]、[请求传输数据项]、[响应传输数据项]等各种条件进行日志检索。

![图片](images/长亭高级API安全系统操作手册/image_46.png)

API列表页面可按应用或站点进行分组查询，分组后，系统可自动将API列表聚合到对应应用或站点中。并可按累计请求数、路径升序和路径降序排列。

![图片](images/长亭高级API安全系统操作手册/image_47.png)

支持点击操作栏详情按钮，跳转至详情页面查看该请求详细日志记录，如果命中了数据项添加匹配规则，日志中会增添请求/响应含有数据项的列对匹配数据项进行逐一显示。支持在详情页对该日志进行删除或下载。
在API发现列表中，支持基于API全生命周期，发现新增API、僵尸API，并自动打标签梳理。

![图片](images/长亭高级API安全系统操作手册/image_48.png)

点击某具体API后的查看按钮，可详细查看API的累计请求数、业务属性等基本信息、API运行状态和请求响应参数具体Key-Value值。

![图片](images/长亭高级API安全系统操作手册/image_2.png)

支持在API发现页面，点击生成报告按钮，一键导出	API统计报告，包括但不限于总览、域名分布、敏感数据传输情况、API活跃情况分布等。

![图片](images/长亭高级API安全系统操作手册/image_3.jpeg)


## 站点发现

站点发现模块将展示系统持续发现的请求域名及端口号并进行列表展示。

![图片](images/长亭高级API安全系统操作手册/image_4.png)

支持在当前页面手动单次或选中批量移入自定义应用，后续发现的API将会随站点自动移入该应用。

![图片](images/长亭高级API安全系统操作手册/image_5.png)

同时，也可对站点进行导入导出操作。

![图片](images/长亭高级API安全系统操作手册/image_6.png)

点击查看按钮可以查看对应站点的详情信息，包括站点信息、基础配置、站点自定义规则，展示站点相关API资产数量，并可点击跳转到API资产列表。

![图片](images/长亭高级API安全系统操作手册/image_7.png)


## 应用管理

应用管理模块，主要是业务应用的增删改查和维护域名资产与业务应用的映射关系。系统内置默认应用，用于系统冷启动。可设置站点自动移入该应用逻辑。

![图片](images/长亭高级API安全系统操作手册/image_8.png)

添加应用，支持通配符通配。系统可按管理员配置的映射关系，自动将发现的域名及域名下的API资产自动移入到该应用中。[数据抽样率]：可设置该应用下请求检测的频率。若数据抽样率设置为80%，则代表平均100个请求中只有80个会计算累计请求次数、匹配数据项规则、记录日志，剩余20个请求不会记录具体API信息。

![图片](images/长亭高级API安全系统操作手册/image_9.png)


## 资产发现配置


### Restful 聚合规则

聚合规则页面是对API聚合规则进行增删改查的入口。API聚合规则为第一优先级，系统首先将按手动聚合规则对发现API进行聚合，其次将按系统自动聚合模型进行聚合。

![图片](images/长亭高级API安全系统操作手册/image_10.png)


### 谓词拆分

拆分规则页面是对API拆分规则进行增删改查的入口。支持根据不同业务情况配置query或body中字段，手动编写应用或API拆分规则，API发现引擎将按照拆分规则执行API发现任务。支持多拆分任务并行。

![图片](images/长亭高级API安全系统操作手册/image_11.png)


### 可编程解析

支持按照业务场景，对API流量进行可定制的解析处理。

![图片](images/长亭高级API安全系统操作手册/image_13.png)


### 标记规则

标记规则页面主要是维护API所有的标记规则。系统内置常见的API接口类型识别规则，包括但不限于：注册、登录、查询、上传、配置、下载接口等业务类型识别规则。

![图片](images/长亭高级API安全系统操作手册/image_14.png)

支持基于应用系统流量识别API接口业务类型，支持用户通过cookie、query、session等不少于30种流量特征，自定义API业务标签。

![图片](images/长亭高级API安全系统操作手册/image_15.png)


### 1对1资源位

支持对API流量中的越权行为的1对1资源位进行配置与启动。

![图片](images/长亭高级API安全系统操作手册/image_16.png)


### 身份识别标识

身份信息标识是API部分脆弱性生成的前置条件(如未鉴权、水平越权等)，系统内置常见的API身份信息识别特征不少于50条。身份信息标识列表展示了系统所有内置身份信息标识。

![图片](images/长亭高级API安全系统操作手册/image_17.png)

支持用户通过Query、Cookie、Header、Body自定义配置用户身份标识，生效范围可选全局、应用、站点、API。

![图片](images/长亭高级API安全系统操作手册/image_18.png)


### 业务成功标识

业务成功响应标识是API部分风险检测的前置条件，支持配置业务成功响应标识，系统内置200响应码成功标识。

![图片](images/长亭高级API安全系统操作手册/image_19.png)

支持定义业务成功响应标识的生效范围以及可按照响应码、Cookie、Header、Body设置成功响应标识的匹配条件。

![图片](images/长亭高级API安全系统操作手册/image_20.png)


# 数据安全

敏感数据发现模块可对API请求、响应报文进行深度解码，可识别多种编码格式如：UTF-8、Base64等，还原原始API流量中经过多层转义后的敏感数据。

## 敏感数据传输

敏感数据传输模块对API中所有请求和响应命中敏感信息情况进行列表展示，可点击查看详细请求日志。能正确统计命中次数，并能在页面展示相关敏感数据示例。

![图片](images/长亭高级API安全系统操作手册/image_21.png)

同时，可点击查看上下文按钮，将命中敏感信息情况按源IP、用户、API数据聚合展示。

![图片](images/长亭高级API安全系统操作手册/image_22.png)


## 敏感数据发现规则

敏感数据发现规则模块，列表展示了系统内置的数据发现规则。支持在当前页面定义正则表达式规则、K-V规则，系统将按定义的正则表达式持续匹配自动发现API请求响应中的数据项。

![图片](images/长亭高级API安全系统操作手册/image_24.png)

支持点击添加数据项按钮，新增正则表达式，并可选择生效应用，支持多选。

![图片](images/长亭高级API安全系统操作手册/image_25.png)


## 数据分类分级

数据分类分级模块以树状结构展示了数据分类分级模版的各个分类，以及数据标签关联不同分类时的分级情况。系统内置一套分类分级模版。

# 风险与脆弱性


## 风险事件

风险事件页面基于API访问情况建立行为基线，并通过基线模型计算出对应基线的异常偏离度，对偏离基线的异常行为进行聚合并可视化展示，详细展示命中风险类型、命中策略、命中站点等信息。同时也可点击具体命中策略，查看策略详情。

![图片](images/长亭高级API安全系统操作手册/image_27.png)

支持点击查看详情按钮，查看具体API请求命中的风险事件列表，同时也可在此页面查看具体的事件详情。

![图片](images/长亭高级API安全系统操作手册/image_28.png)

支持对风险事件进行进一步处置，包括：未处置、生成脆弱性、标记为已忽略、标记为继续观察。

![图片](images/长亭高级API安全系统操作手册/image_29.png)


## 攻击事件

攻击事件页面是对命中系统内置语义分析引擎的事件展示。智能语义分析技术是基于语法标准并结合AI技术，无需规则配置自动识别SQL注入、XSS、文件包含、CSRF等常见API攻击，具备识别变种攻击和0day能力。

![图片](images/长亭高级API安全系统操作手册/image_30.png)


## 脆弱性

脆弱性事件页面是对识别API中的设计缺陷、错误配置和逻辑漏洞的可视化列表展示，支持在该页面查看详细日志信息以及编辑备注。系统内置包括但不限于弱口令、未鉴权访问、越权访问、不必要的HTTP方法等识别模型。

![图片](images/长亭高级API安全系统操作手册/image_31.png)
