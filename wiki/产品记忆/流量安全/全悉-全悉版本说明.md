## Answer-26.04.001

### 版本定位

正式发布版本，重点增强旁路阻断、日志外发、IPv6 管理与页面交互体验。

### 新增与优化

1. 旁路阻断白名单 IP 支持区分源地址和目的地址，提升白名单配置的精细化程度。
2. 旁路阻断日志支持通过 Syslog 外发，便于对接客户现有日志平台或安全运营平台。
3. 旁路阻断黑白名单支持在策略网段中检索 IP 目标，提高策略定位和维护效率。
4. 添加旁路阻断黑白名单时，IP 地址支持填写范围，降低批量配置成本。
5. 旁路阻断策略删除时支持全选并一次性删除，提升批量运维效率。
6. 全悉管理地址及导流 Agent 支持 IPv6，适配 IPv6 网络环境下的部署与管理需求。
7. 优化页面交互体验，并修复已知问题，提升系统易用性和稳定性。

## Answer-25.12.001

### 版本定位

正式发布版本，重点增强二层阻断、URL 阻断、云端探针监控、加密流量处理与 Windows 导流能力。

### 新增与优化

1. 支持两层 VLAN 场景下的二层阻断，增强复杂网络环境下的阻断适配能力。
2. 支持按 URL 进行阻断，提升 Web 访问控制和威胁处置的精细化能力。
3. 支持以四元组形式通过告警添加旁路阻断策略，提升告警处置到阻断策略生成的联动效率。
4. 支持监控单个云端探针的采集流量大小，便于掌握探针运行状态和流量采集情况。
5. 新增联动主机安全产品获取加密密钥能力，增强加密流量检测相关场景的支撑能力。
6. 新增加密套件支持范围，提升加密流量解析和检测适配能力。
7. 新增 Windows Server 流量导流 Agent，支持 Windows Server 环境下的流量导入与检测。

## Answer-25.10.002

### 版本定位

正式发布版本，重点支持猎隼版（迷你版）部署，增强调试信息收集和双因子认证能力，并更新检测规则能力。

### 新增与优化

1. 支持 mini 版本部署，适配轻量化交付场景。
2. Web 端支持一键收集并下载调试信息，包括当前容器日志、系统信息等数据，便于在不容易进入远程 shell 的情况下快速获得排障信息。
3. 支持开启强制双因子认证，开启后平台内所有用户均需通过二步验证登录系统。
4. 新增多项漏洞利用、远控通讯、未授权访问、信息泄露和命令执行类检测能力。
5. 修复登录信息解码、远程管理行为识别、Webshell 连接识别、代理工具连接识别以及部分漏洞检测结果判断问题。

## Answer-25.07.001

### 版本定位

正式发布版本，重点新增资产场景化能力，并增强应用识别、漏洞知识库和风险事件能力。

### 新增与优化

1. 新增应用识别能力，可针对开发框架、编程语言、邮件系统等数百种应用进行自动识别。
2. 新增漏洞知识库，支持 CNNVD、CNVD、CT 编号等查询。
3. 新增风险事件能力，基于识别的应用版本匹配漏洞知识库，发现应用漏洞。
4. 优化资产识别，统计识别 IP 下的应用信息、服务信息、登录入口信息、风险信息和攻击情况。
5. 新增多项远程代码执行、SQL 注入、任意文件读取、未授权登录和命令执行类检测能力。
6. 优化文件上传检测成功判断，并修复 XML 实体注入、表达式注入、敏感信息收集、RDP 漏洞探测和 UDF 提权等漏报问题。

## Answer-25.05.001

### 版本定位

正式发布版本，重点增强检测白名单、自定义情报、威胁事件标记、资产识别导出和旁路阻断能力。

### 新增与优化

1. 【检测白名单】新增高级模式，支持对 HTTP 任意字段加白，支持正则匹配，支持输入多个 IP。
2. 【自定义情报】新增批量添加能力，支持 IP、域名、URL 等情报批量添加。
3. 【威胁事件】新增告警标记能力，支持根据重要和紧急程度进行标记及筛选。
4. 【资产识别】新增识别资产导出能力，导出字段支持选择。
5. 【旁路阻断】优化旁路阻断能力，支持基于四元组进行阻断。
6. 新增多项远程代码执行、SQL 注入、任意文件读取和认证绕过类检测能力。
7. 优化情报相关告警家族名展示，并修复文件上传、可执行文件下载和 Cobalt Strike HTTP 上线相关检测问题。

## Answer-25.04.001

### 版本定位

正式发布版本，重点新增解密 Agent、Windows Server 环境导流能力、无告警监控和流量丢包监控能力。

### 新增与优化

1. 【加密流量】新增解密 Agent，支持抓取主机侧密钥，实现 TLS 1.2 和 TLS 1.3 解密检测。
2. 【加密流量】新增部分主流加密套件适配。
3. 【Agent 引流】新增 Windows Server 环境导流 Agent。
4. 【消息中心】新增长时间无告警监控，支持统一在平台侧进行配置及展示。
5. 【消息中心】新增流量丢包监控，支持统一在平台侧进行配置及展示。
6. 新增多项未授权访问、任意文件读取、远程代码执行、SQL 注入和勒索病毒通讯类检测能力。
7. 优化敏感信息泄露、反弹 Shell、SmartBI 漏洞利用、文件上传结果判断、域名 IOC 白名单过滤和告警高亮显示。
8. 修复 SQL 注入、WebShell 连接、Redis 弱口令、C2 通讯和命令执行告警结果判断等问题。
