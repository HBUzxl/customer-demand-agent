## 1.1 注意事项

1. 如果熟悉全悉非平台版本安装，则需要注意：软件版需要安装到 `/data/saturn` 目录下面
2. 数据传输要求：平台开启 443 和 9092 端口，探针开启 443 端口，平台和探针直接网络要互通
3. 此处探针即一体机，部署方式见 [全悉一体机部署](01-全悉一体机部署.md) 文档

## 1.2 安装包下载

打开公网下载链接：[全悉发布版本](https://devboard.chaitin.net/devboard/release?product_id=69a167e8dcc6cf385cdf13e3&type=version_release)，选择 **Answer-Platform** 前缀版本下载，文件名最后有软件版/硬件版可以按需选择。

![选择Answer-Platform前缀版本下载](images/2-010-image-2023-10-13_14-3-39.png)

下载后得到安装包 `artifacts.zip`

## 1.3 部署方式一：硬件版安装

### 1. 制作安装 U 盘

1. 准备约 16G 容量的 U 盘，格式化为 MS-DOS(FAT)（下图为 MacOS 下操作流程）

如果图形化界面无 scheme 选择框，直接略过此选择项

![格式化U盘1](images/1-037-image2021-7-15_13-23-3.png)

![格式化U盘2](images/1-038-image2021-7-15_13-23-30.png)

![格式化U盘3](images/1-039-image2021-7-15_13-23-53.png)

2. 参考"安装包下载"小节得到 `artifacts.zip`
3. 解压后（可能需要多次解压）得到两个文件，一个是 Saturn 硬件版压缩文件，一个存放压缩文件的解压缩密码
4. 双击 Saturn 硬件版压缩文件，输入解压密码，得到一组文件

![输入密码解压Saturn硬件版](images/2-009-image-2023-10-13_14-29-54.png)

5. 将解压目录下的所有文件拷贝到 U 盘目录下，安装 U 盘制作成功

### 2. 连接设备

**2.1 串口连接**

1. 使用串口线连接设备，其中 rj45 端连接设备 console 口，usb 端连接 PC usb 口
2. 线查好后，通过命令查询连接情况：`ls /dev/cu.usbserial-*`
3. 确认存在输出后，通过命令连接设备：`screen -L /dev/具体目录名称 115200`
4. 连接成功后会进入设备 shell

![串口连接进入shell](images/1-067-image2022-1-27_16-10-51.png)

**2.2 IPMI连接**

1. 对于没有提供 console 功能的设备，可以使用设备 IPMI 来管理设备；当然也可以通过 VGA 接口，VGA 麻烦的是需要外接显示器和键盘
2. 确保设备提供了 IPMI 功能，一般在设备上留有 IPMI 口，并标明 IPMI
3. 当前使用的是【宝德】设备，默认 IPMI 的 IP 是 192.168.255.254/24 或 192.168.3.1/24（当然也可以在 BIOS 中修改 IPMI 的 IP）
4. 将电脑 IP 也配置成与 IPMI IP 在同一网段，然后使用网线将电脑与设备 IPMI 口相连
5. 利用电脑浏览器访问 IPMI：`https://192.168.255.254` 或 `https://192.168.3.1`
6. 进入页面后，选择"远程管理"，再选择"kvm"，即可进入设备控制台。（提示：不支持将字符复制到控制台中）

### 3. 配置 RAID

- 设备加电后，在出现一些磁盘相关信息后（大约十几秒后），会提示按 `ctrl + r` 进入 RAID 设置界面
- 利用键盘上下键，调整到如下图所示位置，点击回车键

![RAID配置-调整位置](images/1-008-iShot2022-05-31_14.51.18.jpg)

- 进入到 RAID 配置界面，首先配置系统盘

![RAID配置-配置系统盘](images/1-009-iShot2022-05-31_14.52.34.png)

- 系统盘配置完成后，进行数据盘配置（raid 是否开启缓存功能应按照实际需求进行，以下是开启 raid 缓存功能）

![RAID配置-配置数据盘1](images/1-010-iShot2022-05-31_14.55.01.png)

![RAID配置-配置数据盘2](images/1-011-iShot2022-05-31_14.56.31.png)

- 最后配置完成情况，系统盘 RAID 0，446GB；数据盘 RAID 5，14TB

![RAID配置完成](images/1-012-iShot2022-05-31_14.57.36.jpg)

- 保存退出。按 `ESC` 退出，并选择保存处选择 `OK`，然后按 `ctrl+alt+退格键` 或其他方法进行重启即可

注：TA-H10-10000 设备 RAID 配置路径：BIOS → Advanced → Dynamic UEFI Oprom → AVAGO MegaRAID

**配置系统盘（RAID-0）**：
1. 系统盘选择 RAID-0
2. 利用 tab 键将光标移动到 SSD 磁盘上，利用空格键选中，选中后显示 `[X]`
3. 利用 tab 键将光标移动到 OK 按钮，点击回车键

**配置数据盘（RAID-5）**：
1. 数据盘选择 RAID-5
2. 将剩下的磁盘全选
3. 点击 Advanced 按钮，进入高级选项
4. 读策略选择 Ahead，开启预读
5. 写策略选择 Always Write Back，开启始终回写
6. I/O 策略选择 Cached，开启 I/O 缓存
7. 磁盘缓存策略选择 Enable，开启磁盘缓存
8. 点击 OK 保存配置

最终配置：系统盘 RAID 0 约 446GB；数据盘 RAID 5 约 14TB。

### 4. 重置 BIOS（可选，仅限首次安装系统的设备）

- 对于第一次安装的设备（若设备之前安装过其他系统，此步骤可忽略），建议重置 BIOS
- 加电/重启（串口命令行执行 `reboot`）后按提示按 ESC 键进入 BIOS 界面
- 如下图，按 Enter 键，跳出提示选择"yes/是"（自动重启）

![重置BIOS](images/1-062-image2022-1-21_18-5-4.png)

### 5. 写入设备序列号（可选，仅限首次安装系统的设备）

对于第一次安装的设备（若设备之前安装过其他系统，此步骤可忽略），需要写入设备序列号。

1. 使用 U 盘引导（加电/重启 — 串口命令行执行 `reboot` — 后，根据提示按 ESC 键进入 BIOS 界面）
2. 调整启动顺序，第一启动顺位选择 "UEFI: Build-in EFI Shell"；并保存退出（按 F4 键）

![调整启动顺序](images/1-063-image2022-1-21_18-9-0.png)

3. 重新启动后，在 Mapping Table 中寻找 USB 字样，确定 U 盘对应盘符（如下图中的 fs1:）

![Mapping Table中查找U盘盘符](images/1-052-image2022-1-21_18-10-23.jpg)

4. 在 "Shell>" 提示符号输入 `fs1:`，回车，切换到 U 盘根目录

![Shell切换到U盘](images/1-053-image2022-1-21_18-12-34.png)

5. 执行命令，写入序列号（在 UEFI Shell 中，删除字符需要使用 Ctrl-H 组合键而不是退格键）：

| 设备型号 | 操作步骤 |
|---------|---------|
| 宝德 NET-925G/NET-925、研祥 NPC-8208 | 切换到 `EFI\aptio_4` 目录，执行 `DMIEDITEFIx64 /ss <序列号>` |
| 立华 FW-5216 | 切换到 `EFI\aptio_4` 目录，执行 `DMIEDITEFIx64 /bp FW-5216` |
| 宝德 NET-926、研华 FWA-6520、研祥 NPC-8220 | 切换到 `EFI\aptio_5` 目录，执行 `AMIDEEFIx64 /ss <序列号>` |
| 立华 FW-8896 | 切换到 `EFI\aptio_5` 目录，执行 `AMIDEEFIx64 /bp FW-8896` |

![设备型号操作](images/1-034-image2020-10-28_17-15-13.png)

6. 执行 `smbiosview -t 1 -b` 确认序列号是否写入成功
7. 执行 `reset` 重启（注意不是 `restart`）

### 6. 安装

1. 使用 U 盘引导（加电/重启 — 串口命令行执行 `reboot` 后根据提示按 ESC 键进入 BIOS 启动界面）
2. 选择自己制作的 U 盘作为首启动项；保存配置重启（按 F4 键）

![选择U盘作为首启动项](images/1-055-image2022-1-21_18-28-19.png)

3. 选择 "Saturn Installer"，按 Enter 键进入 U 盘内置的安装系统

![选择Saturn Installer](images/1-056-image2022-1-21_18-29-18.png)

4. 用户名为 `root`，免密登录进入到安装系统后，执行以下指令：

```bash
cd /media/sdc1          # 有可能是 sdc0 等，视现场情况而定
lsblk                   # 选择较小的盘做系统盘，较大的做数据盘
./install.sh sdb sda    # 具体命令为"/install.sh 系统盘 数据盘"
```

![root免密登录](images/1-057-image2022-1-21_18-32-36.png)

![lsblk选择系统盘](images/1-058-image2022-1-21_18-34-50.png)

5. 安装过程持续约 10 分钟；完成后会有 "Done" 字样，之后执行 `reboot` 重启系统

![安装完成Done](images/1-059-image2022-1-21_18-38-38.png)

6. 按照提示按 ESC 进入 BIOS 界面，调整启动顺序（系统盘放置在首位）（选择：UEFI Hard Disk:UEFI OS），拔掉 U 盘，重启

![调整启动顺序](images/1-071-image2022-6-17_15-16-46.jpg)

### 7. 配置

1. 安装完成，重启进入系统（默认用户名/密码：`admin/admin`），之后进入 Saturn shell

![重启进入系统](images/1-060-image2022-1-21_18-39-49.png)

2. 配置管理接口 mgmt，默认 IP 是 192.168.1.1/24（其中掩码采用位数表示，"IPv4 Route"直接回车跳过）

![配置管理接口mgmt](images/1-061-image2022-1-21_18-40-30.png)

3. 执行 `network show` 命令查看是否正常。如出现如下错误，请重启设备重试一下。

![network show错误](images/1-070-image2022-6-17_15-16-2.jpg)

4. 配置 DNS 服务器：

```
Saturn>>> set dns IP  # IP 为 DNS server 地址，例如 8.8.8.8
```

5. （针对雷池设备）进入 Linux shell：

```
Saturn>>> admin
SN: CT0101201911088644
Admin Passcode:    # 此值需要向产品师傅索取
```

6. （针对全悉新硬件）进入 Linux shell：可以使用用户名和密码

7. 检查和配置系统时间

具体的所有操作见下图：

![配置操作总览](images/1-072-image2022-6-17_15-40-52.png)

详细操作流程：

**检查硬件时间**：`hwclock`，如果硬件时间正确，即可以将硬件时间同步到系统时间，执行 `hwclock -s`，即完成时间配置。

![检查hwclock](images/1-069-image2022-6-15_11-7-22.png)

**时区检查和配置**：如果硬件时间不正确，可以设置系统时间，再同步到硬件时间。检查时区 `date -R`，正常是 `+0800`，如果不是 `+0800`，则表示时区不正确。配置时区，执行 `timedatectl set-timezone Asia/Shanghai`。

![检查时区date -R](images/1-068-image2022-6-15_11-15-27.png)

**时间检查和配置**：

```bash
# 检查
date -R
# 配置日期：date -s YY/MM/DD，例如 date -s 2022/3/30
date -s YY/MM/DD
# 配置时间：date -s hh:mm:ss，例如 date -s 10:25:30
date -s hh:mm:ss
# 配置完成后，将系统时间同步到硬件时间
hwclock -w
```

8. 优雅关机：安装完成后，需要优雅的关机，直接拔掉会触发未知的问题。在 shell 下执行 `poweroff` 命令。

9. （可选）系统时间异常情况下，系统部分程序需要清空数据，具体操作见下图：

![系统时间异常清空数据](images/1-073-image2022-6-17_15-45-1.png)

清理数据指令：

```bash
cd /data/saturn/
./stop-saturn.sh
docker-compose -f docker-compose-upgrade.yml stop
rm -rf workdir/prometheus/data/*
rm -rf workdir/pg_data/*
rm -rf workdir/zookeeper_data/*
rm -rf workdir/kafka/data/*
rm -rf workdir/es/data/*
rm -rf workdir/upgraderpg_data/*
rm -rf workdir/clickhouse/*
docker-compose -f docker-compose-upgrade.yml up -d
./start-saturn.sh
```

## 1.4 部署方式二：软件版安装

### 部署要求

**硬件资源需求**：

假设探针每 1Gbps 流量每秒产生 50 条告警，根据实际探针总流量选择对应的平台配置。

| 平台型号 | CPU | 内存 | 数据磁盘 | 网卡 | 告警接收处理能力 | 处理探针流量总和 | 可接入探针数量 |
|---------|-----|------|---------|------|----------------|----------------|------------|
| 低 | 4物理核心/8逻辑核心 | ≥ 32G | ≥ 4T（盘数≥1块） | ≥ 百兆卡 | 1000 条/秒 | 20Gbps | 1G探针:20台 / 5G探针:4台 / 10G探针:2台 |
| 中 | 8物理核心/16逻辑核心 | ≥ 48G | ≥ 6T（RAID5，盘数≥3块） | ≥ 千兆卡 | 2000 条/秒 | 40Gbps | 1G探针:40台 / 5G探针:8台 / 10G探针:4台 |
| 高 | 12物理核心/24逻辑核心 | ≥ 64G | ≥ 8T（RAID5，盘数≥4块） | ≥ 千兆卡 | 5500 条/秒 | 110Gbps | 1G探针:110台 / 5G探针:22台 / 10G探针:11台 |

> **通用要求**：建议根目录分区 ≥ 256G

- 操作系统推荐使用 ubuntu22.04 server 版（可兼容 18.04/20.04）/ centos 7.6+，安装时不要选择最小化安装，做好时间同步和时区配置，SSH 弱口令需修改
- 硬件版本宿主机：ubuntu 18.04
- Docker API 版本 ≥ 1.41，尽量使用软件版携带的 Docker 环境
- 需要 iptables 软件支持，可在线安装或离线安装包方式安装

### 1. 环境准备

**挂载数据盘**：

```bash
fdisk -l                   # 数据盘为 /dev/sda
mkfs -t ext4 /dev/sda
mount /dev/sda /data
# 持久化
blkid /dev/sda             # 查询 UUID
UUID=xxx /data ext4 defaults 0 1    # 追加到 /etc/fstab
```

> **注意**：如果未挂载数据盘，软件安装完成后需要手动修改 `/data/saturn/config/manager/manager.yml` 中的 `data_mount`，否则可能会导致误清除磁盘数据。

**查看目录并创建**：

```bash
mkdir /data            # 应该通过"挂载数据盘"到此目录
mkdir /data/saturn
```

**拷贝并解压安装包**：

```bash
cd /data/saturn
cp /path/to/artifacts.zip ./    # /path/to/ 为安装包实际路径，需替换
unzip artifacts.zip
unzip saturn-software-installer-Answer-Platform-xxxxxx.zip
```

![解压安装包](images/2-008-image-2023-10-13_14-14-38.png)

### 2. 安装 Docker 环境（仅首次部署）

```bash
cd /data/saturn/software-deploy/deps
tar zxvf docker-installer.tar.gz
cd docker-installer
chmod +x install-docker.sh
./install-docker.sh
```

**可能遇到的报错及解决办法**：

```
./install-docker.sh: line 12: /usr/lib/systemd/system/docker.service: No such file or directory
Failed to start docker.service: Unit docker.service not found.
Failed to enable unit: Unit file docker.service does not exist.
```

解决办法：

```bash
mkdir -p /usr/lib/systemd/system
touch /usr/lib/systemd/system/docker.service
systemctl daemon-reload
./install-docker.sh              # 重新执行安装脚本
docker ps                        # 能执行成功表示 docker 服务安装成功
```

### 3. 软件版解压与安装

> 注意：此步骤需要获取 root 权限执行，安装命令必须在 `/data/saturn` 目录下。

进入安装目录：

```bash
cd /data/saturn
```

获取安装密码：

```bash
cat saturn-software-dpdk-installer-saturn-*.bin.password
```

在 `/data/saturn` 目录下，执行安装命令：

```bash
./saturn-software-dpdk-installer-saturn-*.bin -p [password]
```

显示 "Saturn Installer Done" 字样代表此阶段安装完成。

启动 Docker：

```bash
cd /data/saturn
./start-saturn.sh
```

## 1.5 部署/升级完成后 CheckList

### 界面检测列表

- 界面能否正常登陆（浏览器 `https://设备管理口地址/`）
- 版本是否符合预期
- 等待几分钟，是否有告警信息

### 后台检测列表

**检查系统时间是否正常**：

```bash
date -R
```

**检查 Docker 是否正常启动**：

版本是否符合预期，升级列表参考 `/data/saturn/saturn.version`：

| 组件类别 | Docker 容器名 |
|---------|-------------|
| 前端 | frontend |
| 后端/管理端 | zeus、zeusbee、migrate（启动时执行一次立即退出）、gateway |
| 消息通道 | kafka |
| 存储 | es、db、redis |
| 升级 | upgrader、upgraderdb、upgraderfrontend |

**检查各个 Docker 是否运行正常**：

```bash
# 是否有持续性异常重启
docker ps
# 是否有异常启动日志（xxx 为前置罗列的 docker 容器名）
docker logs xxx -f
# 检查是否包含关键字（retry、error、restart 等）
```

**对外服务端口**：

| 服务 | 端口 | 检查命令 |
|------|------|---------|
| gateway | 80/443/tcp | `docker ps` |
| 宿主机 | 22/ssh | `netstat -ntl; netstat -nul; 查看进程占用 lsof -i:65530` |

**检查 docker-compose 配置是否准确**：

文件名：`/data/saturn/docker-compose-*.yml`

**检查系统级别服务是否正常**：

```bash
systemctl status saturn-upgrade-answer    # 升级服务/全悉界面
systemctl status minion                   # minion 管理服务
systemctl status manager                  # manager 管理服务
# Active: active(running) 状态为正常
```
