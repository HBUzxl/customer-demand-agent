# APISEC 产品介绍

## 产品定位

APISEC 是长亭科技自主研发的 API 安全检测与治理平台，专注于 API 资产的自动发现、梳理与持续监控，敏感数据的识别与追踪，API 安全风险的检测与告警处置。通过流量分析建立完整的 API 资产清单，追踪敏感数据传输路径，检测安全漏洞与攻击行为，并通过告警联动机制实现风险的快速处置闭环，帮助企业全面掌握 API 资产态势，及时发现并处置 API 安全风险。

## 核心能力

- **API 资产自动梳理**：通过流量分析自动发现并梳理企业 API 资产，支持 Restful 路径聚合、RPC 谓词拆分、可编程解析等多种发现模式；按站点、应用、访问者维度建立完整资产清单，持续监控资产变更
- **敏感数据发现与追踪**：识别 API 请求与响应中的敏感数据（身份证、手机号、银行卡号等），支持 10 层递归解码还原多层转义后的真实数据；溯源分析追踪敏感数据传输链路，建立从源头到目的地的完整流转视图；支持自定义发现规则与数据分类分级管理
- **风险与脆弱性检测**：检测 SQL 注入、XSS、命令注入等 Web 攻击行为，识别未鉴权访问、越权访问、弱口令等 API 设计缺陷；内置漏洞情报库匹配已知 CVE，结合指纹识别知名软件与 API 的已知漏洞
- **告警联动处置**：全局规则与自定义规则双机制告警，支持与 WAF、IPS 等安全设备联动实现自动封禁与策略下发；邮件、短信、Webhook 多通道告警通知，处置日志完整记录实现闭环审计
- **可视化态势感知**：仪表盘一页呈现 API 资产概况、风险事件统计、敏感数据态势、告警处置状态，支持从全局到单条 API 的逐层钻取分析

## 适用场景

| 场景 | 说明 |
|------|------|
| API 资产盲区治理 | 企业 API 数量庞大且持续新增，传统人工盘点无法覆盖，APISEC 自动发现建立完整清单 |
| 敏感数据泄露管控 | API 传输中大量敏感数据（个人信息、金融数据）未经加密或脱敏，需识别传输路径并管控 |
| API 攻击检测与防御 | 外部攻击者通过 API 接口实施注入、越权、滥用等攻击，需实时检测与告警 |
| API 漏洞风险排查 | API 存在设计缺陷与错误配置（未鉴权、弱口令、不必要的 HTTP 方法），需持续扫描与跟踪 |
| 合规审计支撑 | 数据安全法、个人信息保护法等法规要求 API 数据传输可审计可追溯，需完整日志与报告 |
| 安全运营闭环 | 告警产生后需快速处置与联动封禁，避免人工响应延迟导致风险扩散 |

## 典型用户

- **金融机构**：银行、证券、保险——API 接口承载大量用户敏感数据，对数据泄露与合规审计有严苛要求
- **互联网与云服务企业**：API 是业务核心通道，数量多、迭代快，需自动化资产发现与持续监控
- **政务与公共服务**：政务 API 对外开放，需保障接口安全与数据合规
- **运营商与大型企业**：内部 API 数量庞大，需统一梳理与风险治理
- **医疗与教育**：患者信息与学生数据通过 API 传输，需敏感数据识别与追踪

## 主要价值

| 价值维度 | 收益 |
|----------|------|
| **资产可视** | 自动发现 API 资产，消除"影子 API"盲区，建立完整资产清单与持续变更监控 |
| **数据可控** | 识别 API 中的敏感数据并追踪传输路径，支持分类分级管理，防止数据泄露 |
| **风险可知** | 实时检测 Web 攻击与 API 漏洞，结合漏洞情报提前预警已知风险 |
| **处置闭环** | 告警规则 + 联动封禁 + 多通道通知 + 处置审计，实现从发现到响应的完整闭环 |
| **合规可证** | 完整日志留存、操作审计、报告模板，满足数据安全法与个人信息保护法审计要求 |
| **运维高效** | 可视化仪表盘一页掌握全局态势，OpenAPI 接口支持自动化运维与第三方系统集成 |
