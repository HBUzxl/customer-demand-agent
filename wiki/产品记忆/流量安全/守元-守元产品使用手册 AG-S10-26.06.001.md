## 1. 产品概述

长亭大模型安全围栏（守元）是一款专为大模型安全打造的防护系统，秉承"以模型守护模型"的创新理念，融合智能识别判断、风险内容筛查、敏感问题过滤等前沿技术，确保大模型在处理输入输出内容时的安全性，防护常见的注入攻击，确保其价值观与业务要求对齐，为企业构筑坚实可靠的内容安全防线。

守元通过大小模型、语义相似度、敏感词匹配、规则检测等技术，降低大模型与智能体因提示注入攻击、生成内容违规、恶意意图利用、数据泄漏等产生的问题风险，覆盖 OWASP LLM 应用的 TOP 10 风险以及合规要求，实现对大模型和智能体的实时安全检测和防护。系统支持多模态内容检测（文本/图片/语音/视频/文档）、模型攻击防护、Agent 安全防护、敏感数据识别、流量接入管理、数据飞轮、SKILL 安全扫描等核心能力。

**为什么需要守元？**

大模型虽然强大，但也存在安全风险：
- 用户可能发送恶意提示试图绕过模型安全策略，导致模型生成不当内容
- 模型可能生成违规内容（涉政、涉黄、涉暴等），带来合规风险
- 用户输入可能包含敏感信息（手机号、身份证号等），存在数据泄漏风险
- 恶意 Agent 可能执行危险操作，影响系统安全

守元就是为了解决这些问题而设计的。它通过敏感词匹配、规则检测、大小模型语义计算等技术，对大模型进行综合的实时安全检测和防护。

## 2. 快速入门

本章介绍从首次登录到基础防护配置的全流程。

### 2.1 上传许可证

首次访问守元时，系统要求用户上传许可证（License）文件完成初始化。没有许可证，系统无法运行。

**操作步骤**：

**步骤 1**：在浏览器中访问守元地址，系统自动跳转到许可证上传页面。若当前页面不是上传页面，可能是许可证已经上传过，可以直接使用 URL 后添加 /license 访问

**步骤 2**：点击「上传许可证」按钮，选择 License 文件上传。支持 .lic 格式的许可证文件

![图2-1 上传许可证界面](./images/2b44b50997f9f021269b0a742dadf54d32360e53.png)

**步骤 3**：上传成功后，系统会显示初始密码（默认用户名为 admin）

![图2-2 初始密码显示](./images/2997007188eca8f6294a0b2f63a93ab4e089cd94.png)

**注意**：请务必复制保存初始密码。如果忘记保存，可以在 URL 后添加 /license 重新上传许可证（例如：https://10.2.101.16:9443/license）。

### 2.2 登录系统

许可证上传完成后，使用管理员账号登录。

**步骤 1**：在登录页面输入用户名和密码。用户名是创建系统时分配的，密码是初始密码或用户修改后的密码

**步骤 2**：点击「登录」按钮进入系统。如果密码错误，会提示重新输入

![图2-3 登录系统](./images/3f722294349ab220162447bfd0c7d602d66ee8b5.png)

**步骤 3**：点击「登录」按钮进入系统。如果密码错误，会提示重新输入。连续多次密码错误后账号可能被锁定，请联系管理员解锁。

### 2.3 基础操作流程

守元的典型使用流程是：**创建接入点 → 配置防护策略 → 验证防护效果**。

#### 2.3.1 创建接入点

接入点是守元接收和转发流量的入口。用户需要先创建接入点，即配置守元"从哪里接收流量"以及"转发到哪里"。未配置接入点时，守元无法接收和处理任何流量。

**步骤 1**：进入「流量接入 → 接入点」菜单

**步骤 2**：点击右上角的「新增接入点」按钮

**步骤 3**：填写接入点名称、接入类型（SDK 接入或透明代理）、监听地址、转发地址

**步骤 4**：选择关联的防护策略。如果没有现成的策略，可以先创建一条

**步骤 5**：点击「保存」完成配置。保存后，接入点开始接收流量

#### 2.3.2 配置防护策略

防护策略定义了守元对流量"怎么检查"和"检查到违规怎么办"。

**步骤 1**：进入「防护策略」菜单

**步骤 2**：点击「添加策略」按钮，输入策略名称和默认拦截响应内容

**步骤 3**：创建后在列表中点击「编辑」按钮，进入详细配置页面

**步骤 4**：依次配置多模态检测、模型攻击识别、Agent 防护、关联规则等内容

**步骤 5**：每个 Tab 页配置完成后，点击「确定修改」保存

#### 2.3.3 验证防护效果

**步骤 1**：进入「在线测试」菜单

**步骤 2**：选择刚才配置的防护策略，输入测试内容

**步骤 3**：点击「开始测试」，查看检测结果和防护动作

## 3. 功能介绍


### 3.1 仪表盘

仪表盘是守元的首页，提供全局视角的安全态势概览。

**它展示什么：**

| **统计项** | **说明** |
|------------|----------|
| 请求数 | 当天收到的总请求量 |
| 拦截数 | 当天被守元拦截的请求数量 |
| 提问次数 | 当天的总提问次数 |
| 风险次数 | 当天检测到的风险次数 |
| Token 消耗 | 输入、输出、总 Token 的消耗量 |
| 违规类型分布 | 各类违规内容的占比（饼图） |
| 模型攻击类型分布 | 各类模型攻击的占比（饼图） |
| 每分钟处理请求数 | 系统实时处理能力（折线图） |
| 防护趋势图 | 按时间维度的请求/拦截趋势（折线图） |
| Token 消耗趋势 | 按时间维度的 Token 消耗趋势 |
| 站点请求/拦截分布 | 各接入点的请求量和拦截量排名（TOP 10） |

仪表盘顶部提供「转发流量安全」和「Agent 安全」两个视图切换按钮：

• **转发流量安全**：展示与传统流量安全相关的数据，包括请求数、拦截数、违规类型分布、防护趋势等

• **Agent 安全**：展示与 Agent 相关的安全数据，包括 Agent 攻击次数、Agent 行为异常、Agent 资产状态等

点击对应按钮即可切换视图，展示不同类型的安全态势数据。

**时间范围筛选：**

仪表盘右上角提供时间范围筛选功能，可选择开始日期和结束日期。筛选后所有统计数据将更新为所选时间范围内的数据。默认展示当天数据（00:00:00 至 23:59:59）。

### 3.2 在线测试

在线测试用于验证检测规则和防护策略和防护策略是否按预期工作。在正式启用某条规则之前，建议先用在线测试确认它的行为。

**为什么要用在线测试：**
- 避免配置错误的规则影响生产流量
- 确认阈值设置是否合理
- 测试新的检测规则是否生效

**操作步骤：**

**步骤 1**：进入「在线测试」菜单

**步骤 2**：在页面顶部的策略选择器中选择要测试的防护策略

**步骤 3**：在「用户输入」框中填写模拟的用户提问，在「模型输出」框中填写模拟的模型回答

**步骤 4**：点击「开始测试」按钮

**步骤 5**：查看测试结果，确认是否触发了预期的检测规则和处理动作（拦截或放行）

![图3-2 在线测试](./images/图3-2_在线测试.png)

**测试结果说明：**
- **检测结果**：显示是否触发检测。如果未触发，说明当前内容未命中任何规则
- **命中规则**：显示具体触发了哪条规则。便于确认是哪条规则在起作用
- **处理动作**：显示系统执行的动作（拦截或放行）

### 3.3 数据飞轮

数据飞轮提供从数据标注、数据集构建、模型训练到模型部署的完整闭环。通过持续标注和训练，可以提升安全检测的准确率。

**数据飞轮工作流程：**

```plaintext
会话日志（标注数据） → 标注记录 → 数据集 → 训练任务 → 模型管理（部署）
```

**核心思路：** 在会话日志中，对守元误报（正常内容被拦截）或漏报（风险内容被放行）的内容进行人工标注，将这些标注数据汇入数据集，再用数据集训练新模型版本，最终部署到生产环境——形成"检测 → 反馈 → 训练 → 提升"的持续优化闭环。

#### 3.3.1 如何进行标注

标注是数据飞轮的起点。所有标注操作都在「会话日志 → 会话详情」中完成。

**开启标注模式：**

进入「会话日志 → 会话列表」，点击某条会话的「详情」按钮，在会话详情页中开启「标注模式」开关。开启后，对话记录中的文本变为可选中状态。

**标注操作步骤：**

**步骤 1**：在对话记录中，用鼠标选中需要标注的文本片段（可以是用户输入或模型输出）

**步骤 2**：选中文本后，上方会自动弹出标注工具栏，选择合适的标签：

| **标签** | **含义** | **适用场景** |
|----------|----------|--------------|
| 误报 | 正常内容被守元错误拦截 | 守元判定为违规但实际安全的内容 |
| 漏报 | 风险内容未被守元检测到 | 守元放行但实际存在风险的内容 |
| 内容违规 | 标注具体违规类型（如涉政、涉黄等） | 明确违规但未被识别的恶意内容 |

**步骤 3**：选择标签后，标注自动保存。标注数据会同步到「数据飞轮 → 标注记录」中，供后续构建数据集使用。

![图3-23 标注记录列表](./images/C28C200F-64C9-4D0D-A5C9-D508AE5688B8.png)


![图3-22 会话日志标注操作](./images/2DA1C2DB-DCB9-493F-9BF2-822314051B7B.png)

**标注建议：**

- **优先标注误报和漏报**：这两类数据对模型优化价值最大
- **标注典型样本**：选择具有代表性的内容，而非极端边界案例
- **持续标注**：建议在日常使用中养成标注习惯，积累高质量训练数据

#### 3.3.2 标注记录

标注记录管理从会话日志中产生的数据标注。用户在会话日志中对某条会话进行了标注，该标注会同步到这里。


**操作步骤：**

**步骤 1**：进入「数据飞轮 → 标注记录」菜单

**步骤 2**：查看标注记录列表，包含「内容合规」和「模型攻击」两个标签页

**步骤 3**：点击「详情」按钮可以查看标注详情，并快速跳转至关联的会话列表和攻击检测日志

**筛选条件：** 支持按时间范围、标签类型（内容合规/模型攻击）、标注状态筛选。

**标注记录来源：** 标注记录来源于会话日志中的会话数据。用户在会话日志中对某条会话进行了标注操作后，该标注会自动同步到标注记录列表中。标注记录的数据可用于构建训练数据集，提升安全检测能力。

#### 3.3.3 数据集

数据集是模型训练的输入数据，从标注记录中选择数据组成，支持版本管理。

![图3-26 数据集列表](./images/图3-23_数据集列表.png)

**创建数据集：**

点击「创建数据集」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 数据集名称，便于识别 |
| 描述 | 数据集描述说明，建议写明数据集的用途和包含的数据类型 |
| 类型 | 攻击识别（用于训练模型攻击检测能力）或内容合规（用于训练内容合规检测能力） |

**添加数据与版本管理：**

**步骤 1**：在数据集详情页点击「添加数据」

**步骤 2**：从标注记录中选择数据。可以选择单条或多条标注记录

**步骤 3**：数据添加完成后，点击「提交新版本」进行版本管理。每次提交会生成一个新的数据集版本，方便追踪数据变化和回滚

**版本管理说明：**

数据集支持版本管理，每次提交新版本会记录该版本包含的数据列表和提交时间。用户可在版本列表中查看各版本的数据差异，并在需要时回滚到历史版本。

#### 3.3.4 模型管理

模型管理用于管理模型的各版本，可设置应用版本。

![图3-27 模型列表](./images/图3-24_模型管理.png)

**模型管理说明：**

模型管理用于管理模型的各版本，可设置应用版本。在模型详情页，可查看模型的所有版本列表，并将某个版本设置为应用版本。设置应用版本后，守元将使用该版本进行安全检测。

**版本管理建议：**

- 每次训练完成后会生成新的模型版本，建议在确认新版本效果后再设置为应用版本
- 可在版本列表中查看各版本的训练时间、使用的数据集等信息
- 如新版本效果不佳，可随时回滚到之前的版本

#### 3.3.5 训练任务

训练任务用于使用数据集训练模型，生成新的模型版本。

![图3-25 训练任务列表](./images/图3-25_训练任务列表.png)

![图3-26 创建训练任务](./images/3.png)

**创建训练任务：**

点击「创建训练任务」按钮，在弹窗中填写：

**基础配置：**

| **配置项** | **说明** |
|------------|----------|
| 任务名称 | 训练任务名称，便于识别和查找。建议包含训练目标，如"内容合规模型-误报优化" |
| 描述 | 任务描述说明，建议写明训练目的和预期效果 |
| 训练对象 | 选择要训练的模型。从模型管理列表中选择已有模型 |
| 起始版本号 | 模型的起始版本号（基座版本），训练将基于此版本进行 |
| 新版本号 | 生成的新版本号，用于标识训练后的模型版本。建议使用递增编号，如 v1→v2 |
| 训练数据集 | 选择用于训练的数据集及版本。数据集需要事先在「数据飞轮 → 数据集」中创建并提交版本 |

**高级配置：**

| **配置项** | **说明** |
|------------|----------|
| 训练轮数（epoch） | 模型完整遍历训练数据集的次数。轮数越多，模型对训练数据拟合越充分，但过拟合风险也越高。通常从 3~5 轮开始尝试 |
| 批量大小（batch size） | 每次送入模型训练的样本数量。较大的批量训练更快但消耗更多显存，较小的批量更省显存但训练较慢 |
| 学习率（learning rate） | 模型参数更新的步长。学习率过大可能导致模型无法收敛，过小则训练速度慢。建议使用默认值 |
| 验证集比例 | 从训练数据集中划分出一部分作为验证集的比例，用于评估训练效果。例如 0.2 表示 20% 数据用于验证 |

> ⚠️ **重要提示**：训练过程需要 GPU 显存资源，训练启动前请确保 GPU 有足够可用显存。如果显存不足，训练任务会失败。建议在训练前通过节点状态页面确认 GPU 负载情况，或适当降低批量大小（batch size）以减少显存占用。

**任务状态说明：**

| **状态** | **说明** |
|----------|----------|
| 进行中 | 任务正在执行，此时请耐心等待。训练时长取决于数据集大小和硬件配置 |
| 完成 | 任务执行成功，已生成新模型版本。可在模型管理中查看和新版本 |
| 失败 | 任务执行失败。通常原因是显存不足、数据集为空或服务异常，可查看失败原因，修正后重新提交 |

**新增接入点：**

点击「新增接入点」按钮，在弹窗中填写：

![图3-19 新增接入点](./images/弹窗-新增接入点.png)

**步骤 3**：在弹窗中填写以下信息

| **配置项** | **说明** |
|------------|----------|
| 名称 | 接入点名称，便于识别和管理 |

| **配置项** | **说明** |

>
> • 从 HTTP 头的指定 Key 获取

**步骤 8**：配置会话设置

| **配置项** | **说明** |
|------------|----------|
| 会话 ID 生成方式 | 判断对话范围的依据。部分模型（如 OpenAI）提供会话 ID，无则系统自动生成 |
| 请求内容提取方式 | 选择解析器，用于解析请求内容的 API 格式。解析器来自「系统管理 → 解析器配置」 |

**步骤 9**：配置检测行为

| **配置项** | **说明** |
|------------|----------|
| 转发 Bypass | 检测异步执行，不等待检测结果直接转发给客户端，提高流式交互体验 |

| 单次送检长度 | 一次检测的字符串长度 |

| 代理地址 | 代理服务器地址 |

**注意**：「全站 Bypass」和「自动 Bypass」功能建议在充分评估风险后开启。全站 Bypass 会跳过所有鉴权与检测直接透传；自动 Bypass 用于配合上游 URI 重写场景。

### 3.7 防护策略

防护策略是守元的核心配置，它定义了系统"检查什么"和"怎么处理"。一个策略可以关联多个接入点，不同接入点可以共用同一个策略。

**策略的作用：**

- 定义多模态检测的内容类型和阈值
- 配置模型攻击识别的规则
- 开启 Agent 行为防护
- 关联全局规则（检测规则、限频规则、违禁词库、敏感数据、知识产权、安全代答）

一个策略创建后，可以在多个接入点中复用。避免为每个接入点重复配置为每个接入点重复配置相同的检测规则。

#### 3.7.1 查看策略列表

进入「防护策略」菜单后，页面展示所有已创建的防护策略。

![图3-3 防护策略列表](./images/图3-3_防护策略列表.png)

列表显示策略名称、关联的接入点、创建时间。顶部的搜索框可以按策略名称筛选。

#### 3.7.2 创建防护策略

点击「添加策略」按钮，填写策略名称和默认拦截响应内容。

![图3-4 添加策略](./images/图3-4_添加策略.png)

**重要提示**：创建时只需要填写基础信息。详细的检测规则配置需要在创建后进入编辑页面完成。

**默认拦截响应内容**：当检测到不安全内容时，守元会将这段内容返回给客户端。支持使用模板变量，比如 `{{EventID}}` 会自动替换为实际的事件 ID。

#### 3.7.3 编辑防护策略

在策略列表中点击「编辑」按钮进入编辑页面。这是配置策略最核心的页面，包含以下 10 个配置模块：

![图3-5 编辑策略页面](./images/图3-5_编辑策略页面.png)

**基础信息**：修改策略名称、查看关联接入点、修改默认拦截响应内容。

**多模态检测配置**：配置文本、图片、语音、视频、文档各模态的检测。每个模态可以分别开启用户请求检测和模型响应检测，并为每个违规类别设置检测阈值和拦截阈值。

• **用户请求检测**：开启后，守元会对用户发送给大模型的内容进行合规检测

• **模型响应检测**：开启后，守元会对大模型返回的响应内容进行合规检测

• **检测阈值**：触发检测的阈值，超过此阈值的内容会被标记为可疑

• **拦截阈值**：触发拦截的阈值，超过此阈值的内容会被直接拦截

**检测类别**：违反社会主义核心价值观、歧视性内容、商业违法违规、侵犯他人合法权益、无法满足特定服务类型的安全需求

**模型攻击识别**：开启/关闭各类攻击类型检测，设置每类的动作（拦截或观察）。

| **攻击类型** | **描述** |
|--------------|----------|
| 身份与情景操纵 | 通过构建虚假身份或场景，欺骗模型绕过其既定角色和安全策略 |
| 规避与混淆 | 使用编码、格式化或其他技巧隐藏恶意指令，绕过输入过滤器和检测器 |
| 指令与逻辑注入 | 将恶意指令注入到提示词或外部数据中，劫持模型的控制流 |
| 利用模型固有弱点 | 利用大模型自身在训练、推理或设计上存在的根本性缺陷 |
| 服务滥用与资源耗尽 | 通过构造高消耗的请求，耗尽系统资源，导致服务不可用 |
| 恶意知识生成 | 将LLM作为生成恶意内容的强大工具，用于后续的攻击或非法活动 |
| 直接的恶意内容 | 恶意，但没有尝试使用特殊攻击手法的输入 |

**Agent 防护**：开启 Agent 行为防护，防止恶意 Agent 操作。启用开关控制是否启用，动作可设置为拦截或观察。

**检测规则匹配**：关联全局检测规则，按顺序从上往下依次匹配。点击「添加检测规则」按钮可关联已有的检测规则。

**频率限制**：关联全局限频规则，限制某个 IP 或用户的访问频率。点击「添加限频规则」按钮可关联已有的限频规则。

**违禁词识别**：关联全局违禁词库，对包含违禁词的内容进行拦截。点击「添加违禁词库」按钮可关联已有的违禁词库。

**敏感数据识别**：关联全局敏感数据规则，识别身份证号、手机号等敏感信息。点击「添加敏感数据」按钮可关联已有的敏感数据规则。

**知识产权&版权识别**：关联全局知识产权规则，保护知识产权内容。点击「新增知识产权信息」按钮可关联已有的知识产权规则。

**安全代答**：关联全局安全代答规则，在检测到特定内容时返回预设的自定义响应。点击「添加安全代答」按钮可关联已有的安全代答规则。

**注意**：每个模块配置完成后，必须点击该模块底部的「确定修改」按钮才能保存。

### 3.8 规则配置

规则配置模块包含四类全局规则：检测规则、限频规则、违禁词库、安全代答。这些规则对系统全局生效，可以在防护策略中关联使用。

#### 3.8.1 检测规则

检测规则用于对请求内容进行规则匹配，比如通过正则表达式或关键词匹配来识别违规内容。

**查看规则列表：**

进入「规则配置 → 检测规则」菜单，可以看到所有已创建的检测规则。规则列表的顺序就是匹配顺序——从上往下依次匹配。排在前面的规则优先匹配。

![图3-6 检测规则列表](./images/图3-9_检测规则列表.png)

**规则匹配逻辑：**

系统会按照规则列表从上往下的顺序依次匹配。一旦某条规则命中，就会执行该规则定义的动作（拦截或放行），后续的规则不再匹配。因此，规则的顺序很重要——建议将优先级高的规则放在前面。

**创建检测规则：**

点击「添加规则」按钮，在弹窗中填写规则名称、匹配位置（Request 请求或 Response 响应）、匹配方式（正则匹配或关键词匹配）、匹配内容，以及触发动作（拦截或放行）。

![图3-7 添加检测规则](./images/弹窗-添加检测规则.png)

**调整规则顺序：**

规则按列表顺序从上往下依次匹配，优先级由上到下递减。点击规则操作栏的「更多 → 修改顺序」，在弹窗中拖拽规则调整顺序。

#### 3.8.2 限频规则

限频规则用来限制某个 IP 或用户的访问频率，超出限制后自动拦截，防止服务被打挂。

**查看规则列表：**

![图3-8 限频规则列表](./images/图3-10_限频规则列表.png)

**创建限频规则：**

点击「添加规则」按钮，在弹窗中配置以下内容：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 规则名称，便于识别 |
| 限频对象 | 选择 IP 或用户。IP 限制的是某个 IP 地址的访问频率，用户限制的是某个用户账号的访问频率 |
| 限频统计单位 | Question（提问次数） |
| 统计范围 | 统计全部地址（对所有请求进行统计）/ 统计 URL 地址（对指定域名和匹配路径的请求进行统计）/ 统计检测规则（对指定检测规则命中的请求进行统计） |
| 触发条件 | 时间区间（统计时间范围，如 60 秒内）和次数限制（超过此次数触发限频） |
| 处理方式 | 拦截，以及拦截时长（永久或指定时间） |

![图3-9 添加限频规则](./images/弹窗-添加限频规则.png)

**使用场景举例：**
- 防止恶意刷接口：设置某 IP 在 60 秒内最多提问 10 次，超出后永久拦截
- 保护后端模型：限制某用户在一定时间内的请求频率，防止模型服务被打挂

#### 3.8.3 违禁词库

违禁词库用于敏感词过滤。系统内置了 10 类违禁词库，也支持用户自定义词库。

**内置词库包括：**
- GFW 补充词库
- 涉枪涉爆类词库
- 高风险类词库
- 民生类词库
- 政治类词库
- 色情类词库
- 反动类词库
- 暴恐类词库
- 侵权类词库
- 非法地址词库

![图3-10 违禁词库列表](./images/图3-11_违禁词库列表.png)

**创建自定义词库：**

点击「新建违禁词库」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 词库名称，便于识别 |
| 违禁词列表 | 词库包含的敏感词，每行一个，支持批量添加。例如输入"xxx"，每行一个敏感词 |
| 备注 | 词库描述说明，方便后续管理 |

#### 3.8.4 安全代答

安全代答用于配置检测触发后返回的自定义响应内容。比如检测到敏感内容时，不直接拦截，而是返回一条友好的提示信息。

![图3-11 安全代答列表](./images/图3-12_安全代答列表.png)

**创建安全代答规则：**

点击「添加安全代答」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 规则名称，便于识别 |
| 回答内容 | 返回给用户的预设响应内容。当检测到用户输入与已配置的安全代答规则语义相似时，返回该预设内容 |

### 3.9 数据安全

数据安全模块包含敏感数据规则和知识产权规则，用于保护敏感信息和知识产权内容。

#### 3.9.1 敏感数据

敏感数据规则用于识别和保护敏感信息，如身份证号、手机号、银行卡号等。系统支持两种类型的敏感数据：

| **类型** | **说明** | **识别方式** |
|----------|----------|--------------|
| 内置敏感数据 | 系统预置的类型（手机号码、身份证号、中文姓名等） | NER 小模型 + 正则表达式双重识别 |
| 自定义敏感数据 | 用户自定义的类型 | 仅通过正则表达式匹配 |

**注意**：内置敏感数据不可删除，只能编辑。

![图3-12 敏感数据规则列表](./images/图3-13_敏感数据规则列表.png)

**创建自定义敏感数据规则：**

点击「添加自定义敏感数据」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 规则名称，便于识别 |
| 描述 | 规则描述说明 |
| 匹配规则 | 正则表达式，用于匹配敏感数据。例如匹配手机号码的正则：`1[3-9]\d{9}` |
| 触发动作 | 拦截（直接阻止包含敏感数据的请求）或观察（只记录不拦截） |

**注意**：自定义敏感数据仅通过正则表达式匹配识别，如需更智能的识别能力，请使用内置敏感数据。内置敏感数据使用 NER 小模型 + 正则表达式双重识别，准确率更高。

#### 3.9.2 知识产权

知识产权规则用于检测和保护知识产权相关图片内容，防止侵权风险。该功能仅支持图片模态检测。

![图3-13 知识产权规则列表](./images/图3-14_知识产权列表.png)

**创建知识产权规则：**

点击「添加知识产权」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|
| 名称 | 规则名称，便于识别 |
| 描述 | 规则描述说明，建议写明保护的知识产权类型 |
| 动作 | 拦截（阻止包含知识产权内容的请求）或观察（只记录不拦截） |

### 3.10 系统管理

系统管理模块提供用户管理、解析器配置、系统设置、数据订阅、数据备份、系统审计、产品信息等功能。

#### 3.10.1 用户管理

用户管理用于管理系统中的所有用户账号，支持增删改查和角色权限配置。

**查看用户列表：**

![图3-29 用户列表](./images/图3-15_用户列表.png)

**新建用户：**

点击「新建用户」按钮，在弹窗中填写：

| **配置项** | **说明** |
|------------|----------|

| 密码 | 登录密码，需符合密码复杂度要求 |
| 姓名 | 用户姓名 |
| 邮箱 | 用户邮箱，用于接收通知和重置密码 |
| 角色 | 分配的角色。角色决定了该用户可以访问哪些功能和执行哪些操作 |

![图3-30 新建用户](./images/弹窗-新建用户.png)

**角色管理：**

切换到「角色列表」标签页，可以创建、编辑、删除角色，并为每个角色配置权限。

**权限配置说明：**

角色权限可细化到按钮级别。例如：
- 勾选「会话列表」权限后，用户可以查看会话列表

建议在分配角色时遵循最小权限原则——只授予用户完成工作所需的最小权限。

![图3-31 角色管理](./images/弹窗-角色列表.png)

#### 3.10.2 解析器配置

解析器配置用于管理 Lua 解析器插件。不同的模型 API 有不同的数据格式，解析器负责正确解析这些格式，确保守元能理解请求和响应的内容。

![图3-32 解析器列表](./images/图3-17_解析器列表.png)

**解析器配置说明：**

解析器使用 Lua 脚本编写，用于解析不同模型 API 的请求和响应格式。在创建解析器时：

• **名称**：填写解析器名称，建议包含模型名称，如 "OpenAI"、"阿里云百炼"

• **图标**：上传 SVG 格式的图标，用于在接入点配置中展示

• **Lua 脚本**：编写解析逻辑，需要正确提取请求中的用户输入和模型响应内容

**测试解析器：**

在创建或编辑解析器时，可使用「测试」功能验证解析器脚本是否正确。在测试页面输入模拟的请求或响应数据，点击「测试」按钮查看解析结果。确保解析器能正确解析目标模型 API 的数据格式后再保存。

**内置解析器：**

系统内置以下解析器：

• **OpenAI 解析器**：用于解析 OpenAI 标准 API 格式的请求和响应

• **阿里云百炼解析器**：用于解析阿里云百炼平台 API 格式的请求和响应

如需支持其他模型 API 格式，可以点击「新建解析器」自定义解析器。

#### 3.10.3 系统设置

系统设置包含节点状态和 SKILL 检测配置两个模块。

**节点状态：** 查看系统节点的 CPU 负载、内存负载、运行时间等运行信息。如果节点负载过高，建议检查系统资源使用情况，必要时进行扩容。

![图3-33 系统设置](./images/图3-18_系统设置.png)

**SKILL 检测配置：** 配置外部大模型检测服务，为扫描任务提供智能检测能力。

| **配置项** | **说明** |
|------------|----------|
| 启用状态 | 是否启用大模型检测 |
| 模型地址 | 大模型服务地址，格式如 https://example.com/v1/chat/completions |
| Token | 鉴权 Token，用于访问大模型服务 |
| 模型名称 | 使用的模型名称 |
| 超时时间 | 检测超时秒数，默认 300 秒 |

**注意**：启用大模型检测前，必须先完成 SKILL 检测配置。否则在扫描任务中无法使用大模型检测功能。

#### 3.10.4 数据订阅

数据订阅用于配置系统告警和通知，支持 Syslog 和 Email 两种方式。

![图3-34 数据订阅](./images/图3-19_数据订阅.png)

**配置 Syslog：** 在 Syslog 标签页中启用 Syslog，填写服务器地址、端口、协议（TCP/UDP），选择需要发送的告警类型后点击「保存」。

**配置 Email：** 在 Email 标签页中填写 SMTP 服务器、端口、发件人邮箱、授权码，配置收件人和告警类型后点击「保存」。

**告警类型说明：**

| **告警类型** | **说明** |
|--------------|----------|
| 攻击告警 | 当检测到攻击行为时发送告警通知 |
| 系统告警 | 当系统发生异常时发送告警通知 |
| 升级告警 | 当系统升级完成或升级失败时发送通知 |

**使用建议：** 建议至少配置一种告警通知方式（Syslog 或 Email），以便在系统发生异常时及时收到通知。对于重要系统，建议同时配置两种通知方式，确保告警信息不丢失。

#### 3.10.5 数据备份

数据备份用于系统配置的备份和还原，支持导入导出。当需要迁移系统或恢复配置时，可以使用此功能。

![图3-35 备份列表](./images/图3-20_数据备份.png)

**创建备份：** 点击「创建备份」按钮，填写备份名称和描述，系统会自动备份当前的系统配置。建议定期备份，特别是在修改重要配置后立即备份。

**恢复配置：** 点击备份记录的「恢复」按钮，确认恢复操作。恢复后，系统配置会回滚到备份时的状态。

**下载/上传备份：** 支持将备份文件下载至本地保存，或从本地上传备份文件到系统。

**备份建议：** 建议定期进行系统配置备份，特别是在修改重要配置后立即备份，以便在需要时快速恢复。建议将备份文件下载到本地保存，防止系统故障导致备份数据丢失。

#### 3.10.6 系统审计

系统审计记录所有用户的操作日志，供审计溯源。若需要追溯"谁在什么时间做了什么操作"，可进入此页面查看查。

![图3-36 审计日志列表](./images/图3-21_系统审计.png)

**查看审计日志：**

进入「系统管理 → 系统审计」菜单，可以看到所有用户的操作记录。每条记录包含操作时间、操作用户、操作类型、操作结果等信息。

**筛选条件：**

| **筛选条件** | **说明** |
|--------------|----------|
| 时间范围 | 按时间区间筛选操作记录 |
| 操作用户 | 按操作用户筛选 |
| 操作类型 | 按操作类型筛选（如登录、创建、编辑、删除等） |
| 操作结果 | 按操作结果筛选（成功/失败） |

**使用场景：**
- 安全审计：追溯某段时间内的所有操作记录
- 问题排查：当系统出现异常时，查看是否有不当操作
- 合规要求：满足审计合规要求

#### 3.10.7 产品信息

产品信息页面展示当前产品版本信息和许可证信息，支持系统在线升级。

![图3-37 产品信息](./images/图3-16_产品信息.png)

**版本信息 Tab 页包含三个模块：**

**当前版本信息**：展示各类型安装包当前版本号，包括管理平台系统、模型检测服务、文本检测模型、图片检测模型、音频检测模型。

**更新升级**：用于上传安装包文件，系统自动判断更新包类型并执行升级操作。

| **步骤** | **说明** |

| 步骤 2 | 系统自动校验更新包，弹出「版本说明」弹窗 |

**升级历史记录**：以列表形式展示各更新包的记录。

| **字段** | **说明** |
|----------|----------|

**升级历史操作：**

| **操作** | **说明** |

**升级注意事项：**
- 上传的更新包版本不可高于系统当前版本，否则将提示版本错误
- 文件格式错误：请确认上传的是正确格式的更新包文件
- 磁盘空间不足：请先清理磁盘空间后再重试
- 网络断开：请检查网络连接后重试
- 有其他更新包正在更新时：请等待当前更新完成后再上传
- 升级过程中请勿关闭浏览器或断开网络连接

### A. 常见问题

**A.1 忘记密码怎么办？**

请联系系统管理员重置密码。系统管理员可以在「系统管理 → 用户管理」中为用户重置密码。

**A.2 如何添加新的接入点？**

进入「流量接入 → 接入点」，点击「新增接入点」，填写配置信息后保存。

**A.3 防护策略不生效怎么办？**

请检查以下几点：
1. 防护策略是否已启用。在策略列表中查看策略状态
2. 接入点配置是否关联了该防护策略。在接入点的编辑页面查看
3. 接入点是否已启用。禁用状态的接入点不会应用防护策略

**A.4 如何查看某个会话的详细检测记录？**

进入「会话日志 → 会话列表」，点击会话的「详情」，在检测记录列表中点击「详情」跳转到攻击检测日志详情页。

**A.5 自动 Bypass 功能有什么作用？**

自动 Bypass 用于配合上游 URI 重写场景。当启用自动 Bypass 且开启"使用上游路径"选项时，转发请求会使用 X-Rewrite-URI 请求头中指定的路径作为重写目标，实现动态路径转发。

**A.6 如何配置模型攻击识别？**

进入「防护策略 → 编辑策略 → 模型攻击识别」Tab 页，开启各类攻击类型的检测开关，并设置每类攻击的动作（拦截或观察）。配置完成后点击「确定修改」保存。

**A.7 如何创建自定义违禁词库？**

进入「规则配置 → 违禁词库」，点击「新建违禁词库」按钮，填写词库名称和违禁词列表（每行一个敏感词），点击「创建」保存。

**A.8 数据飞轮有什么作用？**

数据飞轮提供从会话日志到数据标注、数据集构建、模型训练、模型部署的完整闭环。通过持续标注和训练，可以提升安全检测模型的准确率和覆盖率。

**A.9 如何查看系统节点运行状态？**

进入「系统管理 → 系统设置」，在「节点状态」标签页可查看系统各节点的 CPU 负载、内存负载、运行时间等运行状态。

**A.10 如何配置 SKILL 检测？**

进入「系统管理 → 系统设置 → SKILL 检测配置」，启用大模型检测开关，填写模型地址、Token、模型名称和超时时间后点击「保存」。配置完成后即可在扫描任务中使用大模型检测功能。

**注意**：模型地址需要是可访问的服务地址，Token 需要有效的鉴权凭证。

**A.11 上传许可证后无法访问系统怎么办？**

请检查：
1. 许可证文件是否有效。确认许可证文件未过期
2. 网络是否正常。尝试 ping 系统地址确认网络连通性
3. 浏览器是否支持当前系统版本。建议使用 Chrome 或 Edge 浏览器

**A.12 如何配置角色权限？**

进入「系统管理 → 用户管理 → 角色列表」标签页，点击「新建角色」按钮，填写角色名称和描述，然后在权限配置页面勾选该角色可访问的菜单和功能。勾选后点击「保存」。

**A.13 数据飞轮的训练任务执行失败怎么办？**

请检查以下几点：
1. 训练数据集是否包含有效数据。如果数据集为空，训练会失败
2. 模型服务是否正常运行。检查系统设置中的节点状态
3. 系统资源是否充足（CPU、内存）。如果资源不足，训练可能会超时失败
4. 查看任务详情中的失败原因，根据具体错误信息进行处理

**A.14 如何查看当前系统版本？**

进入「系统管理 → 产品信息」，在「版本信息」Tab 页的「当前版本信息」模块中，可以查看各类型安装包的当前版本号，包括管理平台系统、模型检测服务、文本检测模型、图片检测模型、音频检测模型。

### B. 术语表

| **术语** | **说明** |
|----------|----------|
| 接入点 | 守元接收和转发流量的入口配置。相当于守元的"大门"，所有需要被防护的流量都要从这里进来 |
| 防护策略 | 安全检测策略配置，定义系统"检查什么"和"怎么处理"，需关联接入点生效 |
| 检测规则 | 内容检测规则，对系统全局生效。通过正则或关键词匹配来识别违规内容 |
| 限频规则 | 访问频率限制规则，对系统全局生效。超出限制后自动拦截，防止服务被打挂 |
| 违禁词库 | 敏感词词库，用于过滤包含违禁词的内容。系统内置 10 类词库，也支持自定义 |
| 安全代答 | 检测触发后的自定义响应内容。检测到特定内容时返回预设的提示信息而非直接拦截 |
| 敏感数据 | 需要保护的敏感信息类型，如手机号、身份证号、银行卡号等 |
| 知识产权 | 需要保护的知识产权图片内容，使用图像嵌入相似度比对，仅支持图片模态 |
| 会话 | 一次完整的对话过程，包含用户输入和模型输出 |
| 标注记录 | 对会话数据的人工标注，用于构建训练数据集 |
| 数据集 | 用于模型训练的数据集合，支持版本管理，可从标注记录中选择数据组成 |
| SKILL | Agent 的能力扩展包（如插件、工具包等），SKILL Hub 对其内容进行安全检测，识别潜在风险 |
| 解析器 | Lua 插件，用于解析不同模型 API 的请求和响应格式。系统内置 OpenAI、阿里云百炼等 |
| Agent | 基于大模型的智能体应用 |
| 自动 Bypass | 配合 X-Rewrite-URI 头进行上游 URI 动态重写的转发机制 |
| 全站 Bypass | 守元自身异常时保证业务不中断的逃生开关，跳过所有鉴权与检测直接透传 |
| 上游供应商 | 被防护的上游模型服务提供方 |
| 消费者 | 调用 API 的客户端身份，用于身份认证和权限控制 |
| 模型路由 | 网关中模型请求的路由规则，根据路由规则将请求转发到对应的上游服务 |
| 数据飞轮 | 数据标注 → 数据集 → 训练 → 模型部署的完整闭环，持续提升检测能力 |
| Token | 大模型计费的单位，分为输入 Token（用户输入）和输出 Token（模型输出） |
| QPS | Queries Per Second，每秒查询数，表示系统的处理能力 |
