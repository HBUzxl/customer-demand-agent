# 软件流量镜像版安装手册
**确保已完成[部署前准备](../0.部署前准备/1.部署前准备.md)中的所有操作，否则会导致安装失败**
## 操作流程
1. 初始化部署模式：`minion setup -p /data/safeline -t TrafficMirror`
   - 如果需要使用国产化数据库(kingbase 东方通，highgo 瀚高)，则命令需要替换为：`minion setup -p /data/safeline -t Software --database-engine highgo`，可选参数包含 `highgo`，`kingbase`。**注意，不允许在选择国产化数据库后，不重置模式进行数据库切换，否则会导致存储数据异常；国产化数据库只在 23.01.009 版本及之后版本支持，请勿在非支持版本执行此命令**
   - 如果需要使用国产化内存 kv 存储（redis），则需要增加 `--redis-engine` 参数，可选项有（`tong_rds`），`minion setup -p /data/safeline -t Software --redis-engine tong_rds`**注意，不允许在选择国产化 KV 存储后，不重置模式进行 KV 存储切换，否则会导致存储数据异常；国产化KV 存储只在 25.03.001 版本及之后版本支持，请勿在非支持版本执行此命令**
   - 如果需要部署多租户模式，则命令需要调整为`minion setup -p /data/safeline -t TrafficMirror --tenant`**注意，多租户模式在 21.03 版本后就不再支持，请不要在 21.03 版本以后执行多租户部署安装**
2. 输入接收镜像流量的网口名称，例如：`eth1.1`，当需要多个网口时，每个网口之间用`,`分隔
3. 启动基础平台服务：`systemctl start minion`
   - 当 WAF 版本小于 22.09.001 并且大于 22.01.001_preview 版本时，需再多执行一次`systemctl start minion-upgrader`命令
4. 检查 WAF 各服务启动状态，当所有服务的 `status` 值都为 `up`，并且没有`unhealthy`出现时，证明安装成功
5. 浏览器打开 https://当前机器 IP:9443 页面，上传产品证书，登录后打开「系统信息-节点状态」页面，查看节点是否正常
