# AG-S10-26.06.001

1. 增加 ARM 架构安装包，扩展部署环境适配范围，适配鲲鹏 CPU 和 晟腾 NPU 的国产化版本。
2. 智能体安全能力强化，Agent 运行全流程监控，生成 Agent 资产画像，并统计其运行情况、风险情况和资源消耗。
3. 升级 Agent 安全防护模型，增强对提示注入、越狱、工具调用风险、Agent 行为异常等场景的识别能力。
4. 支持通过安装插件的形式精细化监控 Agent 运行状态并获取更完善的资产数据，本期支持 LangChain 和 Opencode  插件。
5. Agent 框架纳管与追踪能力扩展，支持纳管和追踪 Codex、Claude Code、LangGraph、OpenCode 等Agent 框架
6. 大模型消息格式解析增强，新增对 Chat Response、Anthropic Message 等主流消息格式的解析支持，提升不同模型协议下的会话识别与内容检测能力。
7. Tool Call 解析能力增强，支持更完整地识别、记录和展示 Agent 运行过程中的工具调用链路。
8. 优化会话自动追踪机制，提升多轮对话、工具调用、子任务执行等复杂场景下的会话关联准确性。
9. 流量接入配置优化，完善接入点、模型供应商、消费者、Token 等配置管理能力，提升接入灵活性和可维护性。
10. 性能与架构优化，提升大规模日志写入、查询与统计性能，重构检测服务 GoalKeeper，优化检测链路、服务稳定性和扩展能力。


# AG-S10-26.04.001

1. 新增：实现 SKILLS 扫描检测能力，通过渗透测试智能体完成扫描，支持大模型检测和静态检测，对 SKILL 文件进行全面摸底。
2. 新增：实现 Agent 防护能力，判断 Agent 行为的安全性，拦截危险并分析其风险来源。
3. 新增：会话与日志详情增加工具调用展示。
4. 新增：支持解析 response 类对话协议。
5. 新增：支持配置系统状态告警阈值。
6. 优化：优化会话追踪与还原。
7. 优化页面交互，修复已知问题。


# AG-S10-26.03.001

1. 新增：实现“数据飞轮”机制，打通大模型应用效果到大模型训练的反馈链路，在线迭代模型，将符合预期的模型投入到实际使用中。
2. 新增：对话上下文自动关联，支持自动关联超过 API 调用时传递的上下文信息 。
3. 新增：支持数据订阅，以 Syslog 和 Email 通知的方式外发数据。
4. 新增：支持系统状态监控，实时监控管理节点的CPU、内存负载状态。
5. 新增：支持登录安全配置，包括设置用户密码更新周期以及密码复杂度等。
6. 新增：支持对系统数据进行备份。
7. 优化：用户权限控制优化。
8. 优化页面交互，修复已知问题。


# AG-S10-25.12.001

1. 新增：支持多模态检测，包括文本、图片、语音、视频、文档，并支持对不同类型数据设置不同检测策略。
2. 新增：支持攻击类型识别，对用户的输入输出进行检测，并支持对不同攻击类型设置不同处置动作。
3. 新增：支持设置敏感数据和知识产权，对识别到的敏感数据和知识产权设置相应动作。
4. 新增：支持自定义配置安全代答，检测到输入的内容存在有害内容时，由合规内容来替代原有大模型的回答。
5. 新增：支持自定义配置解析器。
6. 优化：站点配置支持设置 SSL 证书。
7. 优化：会话日志及攻击检测日志展示信息优化。
8. 优化页面交互，修复已知问题。
