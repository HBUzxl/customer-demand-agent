## 2 产品概述

雷池（SafeLine） 是长亭科技自研的下一代 Web 应用防火墙（WAF），核心基于智能语义分析引擎，颠覆传统规则匹配模式，主打 “AI 驱动、零规则维护、低误报漏报、高性能高可用”，为 Web 应用、API 与业务系统提供全栈安全防护，是国内 WAF 市场的标杆产品。。

雷池接入企业网络边界，接收外部 Web 访问流量，进行 HTTP 协议解析与深度解码，调用语义分析、访问控制和自定义插件引擎进行攻击分析，并对结果进行恶意打分，最终阻断攻击流量。

雷池采用智能语义分析算法，能够实现基于上下文逻辑的攻击检测，在降低误报率的同时，将攻击拦截性能提升至顶尖水平，实现了对于 Web 攻击检测的极准拦截和极低误报。

## 3 快速操作指南


### 3.1 如何登录雷池 Web 控制台

**操作步骤：**

1.  打开浏览器，在地址栏输入系统访问地址，进入雷池 Web 控制台登录页面。
2.  输入用户名 `admin` 和对应的密码。
3.  点击「登录」按钮，进入雷池控制台。

![Web 控制台登录页面](images/雷池SafeLine3.0操作手册_images/login_page.png)

### 3.2 如何选择部署模式

完成设备激活后，在界面可以修改设备的部署模式，默认部署模式为反向代理，通过菜单「系统管理 > 工作模式」来选择需要运行的模式。

雷池支持以下四种部署模式：

| 模式  | 说明  |
| --- | --- |
| 反向代理 | WAF 作为反向代理接收客户端请求，转发到业务服务器 |
| 路由模式 | WAF 作为网关进行路由转发 |
| 透明模式 | WAF 透明桥接在网络中，无需修改网络拓扑 |
| 镜像模式 | WAF 仅接收镜像流量进行检测，不阻断 |

![工作模式配置页面](images/雷池SafeLine3.0操作手册_images/workMode.png)

**说明：** 目前软件版本不支持界面修改部署模式，请在部署前与技术支持工程师确认好部署模式。

### 3.3 如何配置防护对象

配置防护对象的前提是完成部署模式、集群配置及网络配置。完成上述配置阶段后，切换到「防护对象」页面下，点击「添加防护对象」进行防护对象的配置。

**操作步骤（反向代理模式为例）：**

1.  进入「防护对象」页面，点击「添加防护对象」按钮。
2.  基础类配置：填写防护对象名称、选择节点组/分组、备注信息（选填）、标签（选填）、状态。
3.  域名配置：以需要防护的 IP 或域名为防护对象。若防护对象为 HTTPS 类型，需要配置该域名匹配的证书。
4.  监听配置：配置 WAF 监听的网络地址和端口。若监听流量为 HTTPS 类型流量，需要勾选启用 SSL 端口。
5.  配置默认应用：默认应用为 `/` 路径，用于匹配域名下的所有流量匹配。
6.  点击「确定」完成防护对象创建。

![添加防护对象页面](images/雷池SafeLine3.0操作手册_images/object.png)

## 4 WAF 登录


### 4.1 Web 控制台登录

打开浏览器，输入系统访问地址 `https://10.9.34.170:9443/`，进入雷池 Web 控制台登录页面。

![Web 控制台登录页面](images/雷池SafeLine3.0操作手册_images/login_page.png)

### 4.2 密码认证登录

账户未启用二步验证时，在雷池管理后台登录页面输入用户名和密码即可登录。

**操作步骤：**

1.  在登录页面输入用户名和密码。
2.  点击「登录」按钮进入控制台。

![密码认证登录](images/雷池SafeLine3.0操作手册_images/login_page.png)

若账户已启用二步验证，则需额外输入绑定的二步验证程序提供的 6 位验证码（30 秒内有效）。

**忘记密码：** 若忘记登录密码，点击「忘记密码」，上传 License 即可重置密码。

### 4.3 证书认证

**操作步骤：**

1.  本地成功安装创建该账号时下载的证书。
2.  在登录页切换至证书登录，点击「登录」即可使用已成功安装的证书进行登录。

![证书认证登录](images/雷池SafeLine3.0操作手册_images/login_page_1.png)
## 5 防护总览

"防护总览"页面通过各类图表可视化展示雷池对所保护应用的防护数据，支持导出防护报告以便分析总结。用户可通过该页面及时、准确、直观、全面地查看当前所保护应用的访问及防护情况。

防护总览页面支持查看最近 90 天的防护数据，所有的攻击统计都不包含自定义规则中"非攻击"的数据，部分模块支持快捷跳转功能，方便用户深入分析数据详情。

![3a161177329423c925de6273436fb9b4.png](images/雷池SafeLine3.0操作手册_images/3a161177329423c925de6273436fb9b4.png)

### 威胁分析

点击饼图或标签数据，可跳转至"攻击检测日志"页面并自动筛选风险等级，方便查看分析威胁。

### 部署节点状态

点击部署节点状态中的「详情」按钮，单机模式下将会跳转至"设备运行状态 > 负载状态"页面，集群模式下将会跳转"工作模式 > 集群管理页面"，方便查看更多节点信息。

### 防护数据总览与趋势图

防护数据总览展示防护趋势图的各数据总数。防护趋势图可点击折线图右上角图例，隐藏请求数、攻击数、攻击拦截、攻击放行在折线图上的展示；鼠标悬浮至图例上，可隐藏其他图例项，方便清晰查看关注数据。

### 攻击者地理位置分布

可在地图右上角切换查看中国或世界地图；点击具体的地区模块时，将会跳转至"攻击检测日志"页面并自动筛选国家地区。

### 攻击类型分布

点击饼图，可跳转至"攻击检测日志"页面并自动筛选攻击类型，方便查看分析威胁数据。

### 攻击分类统计

鼠标悬浮至攻击分类柱状图上时，可具体查看该攻击类型的各个威胁等级日志的数量；点击柱状图右上角，可隐藏高危、中危、低危、无威胁在饼图上的展示；当攻击分类有多个时，可点击"&lt;"、"&gt;"查看更多数据。

### 黑名单拦截趋势

可查看最近 7 天的黑名单拦截趋势，鼠标悬浮至折线图中，可查看当前时间的拦截数量。

### 黑名单拦截 IP（TOP10）

点击板块右上角的"展开"图标，可全屏查看该板块信息。同时，支持切换查看 TOP20、TOP30 等更多排名数据。

### BOT 防护验证趋势

点击折线图右上角图例，可隐藏总数据、WEB、微信小程序、支付宝小程序、APP 在折线图上的展示；鼠标悬浮至图例上，可隐藏其他图例项，方便清晰查看关注数据。

### 攻击事件

在攻击事件板块右上方，可切换威胁等级查看相关攻击事件；开启「自动刷新」按钮，可实时刷新攻击事件。

![50e6a1ea69fa40b61aa2f9e48278bfe9.png](images/雷池SafeLine3.0操作手册_images/50e6a1ea69fa40b61aa2f9e48278bfe9.png)
### 被攻击防护对象（TOP10）

点击「查看防护对象」，可跳转至"防护对象"页面；点击列表信息，可跳转至攻击检测日志页面并筛选定位至此被攻击的防护对象；鼠标悬浮至主要攻击 IP（TOP1）上，可快捷封禁攻击 IP；点击板块右上角的"展开"图标，可全屏查看该板块信息。

### 攻击 IP 分析（TOP10）

点击列表信息，可跳转至攻击检测日志页面并筛选定位此攻击 IP；鼠标悬浮至攻击 IP 上，可快捷封禁攻击 IP；点击板块右上角的"展开"图标，可全屏查看该板块信息。

### 生成防护报告

点击页面右上方「生成报告」按钮，系统将会自动跳转至"统计分析 > 防护报告"页面。在此页面中，可自定义报告的内容、时间范围等，高效生成贴合需求的防护报告。

## 6 统计分析

### 6.1 防护报告

#### 防护报告列表

在"防护报告列表"页面，可生成防护总览、节点状态、PCI-DSS 合规性及基线检查等类型报告。该页面集中管理手动生成的报告和定时任务自动生成的报告，便于用户统一查看、下载和管理。

**操作步骤：**

1.  点击页面右上方「手动生成一个报告」按钮。

支持对报告 ID、报告名称、报告类型、生成时间等进行筛选。点击操作列中的「预览」，可预览生成的报告数据；点击「更多」，可对防护报告进行外发、下载、删除操作。

3.  配置完成后，系统将按预设规则自动生成报告，并同步展示在"防护报告列表"页面。

## 7 防护日志

### 7.1 攻击检测日志

在雷池检测到攻击之后会根据触发的防护策略/规则配置生成对应的攻击检测日志，在日志列表中可查看相关的攻击信息，并通过分析来研判请求处理结果，后续在详情或规则中调整优化防护策略。

![攻击检测日志列表](images/雷池SafeLine3.0操作手册_images/detect_log_list.png)

页面右上角支持调整日志可查看的时间范围，可查看历史日志或通过精准的时间筛选定位攻击日志。

#### 快速筛选与高级筛选

**快速筛选：** 可快捷、方便的筛选数据，满足日常快速定位需求，筛选时支持选择"="、"≠"等条件。输入或选择要筛选的内容后，点击「确定」进行筛选，点击「重置」将会清空所有筛选内容。

![307aebf8661d25b7589ee11d5f274719.png](images/雷池SafeLine3.0操作手册_images/307aebf8661d25b7589ee11d5f274719.png)

**高级筛选：** 可进行复杂逻辑的多字段组合筛选，可配置"or"或"and"的条件关系，当筛选语句配置正确时，系统将显示"对钩"图标作为正确的提示。

![0d0ff0c1eb09c77bdb6a439c1c77e9b4.png](images/雷池SafeLine3.0操作手册_images/0d0ff0c1eb09c77bdb6a439c1c77e9b4.png)

#### 筛选模板

将常用筛选内容保存为筛选模板进行快捷查询配置：

1.  设置好常用筛选项后，点击「保存筛选」填写筛选器的名称，可将已选择的筛选条件保存为一个筛选模板。
2.  鼠标悬浮至"保存筛选"的下拉，可点击「筛选历史」查看筛选器的使用历史，点击「筛选器」可选择已保存的筛选条件进行筛选。

![2fc3425536d3115d9bd342cf0f7d0358.png](images/雷池SafeLine3.0操作手册_images/2fc3425536d3115d9bd342cf0f7d0358.png)

对筛选器进行顺序调整和启用禁用的配置：点击"筛选器设置"图标，可调整筛选器的展示顺序和配置是否进行启用。
![c5b71b7401de3d5f297875c0aaedfc8d.png](images/雷池SafeLine3.0操作手册_images/c5b71b7401de3d5f297875c0aaedfc8d.png)

#### 列表操作

**手动/自动刷新：** 点击"刷新"图标将刷新页面请求最新数据，切换「不自动刷新」为「每 X 秒/分钟」将根据选择自动刷新页面数据。

![90b267716478d287dff216049e1e92d7.png](images/雷池SafeLine3.0操作手册_images/90b267716478d287dff216049e1e92d7.png)

**列表展示设置：** 点击列表中的"设置"图标，可调整列表展示的字段和展示顺序。点击弹窗右下角的「默认配置」，将恢复至默认列表展示字段。

**快捷筛选：** 部分字段支持在列表数据处快捷筛选，鼠标悬浮至列表数据将显示"筛选条件"、"复制"。点击"筛选条件"，将自动对所悬浮数据进行条件筛选；点击"复制"可快捷复制所悬浮的数据。

**批量操作：** 列表勾选多条日志时，可进行批量删除和批量下载。

#### 日志详情

点击「详情」可查看该攻击日志的更多详细数据。攻击检测信息中展示了最主要的信息，方便进行威胁分析；请求处理信息中展示了较全的请求信息，方便更全面的了解攻击信息。

![攻击检测日志详情](images/雷池SafeLine3.0操作手册_images/detect_log_detail.png)

详情顶部点击"&lt;"、"&gt;"可快捷切换查看日志。

**操作按钮说明：**

| 按钮  | 功能  |
| --- | --- |
| 请求重放 | 对当前攻击进行重放演示，仅重新执行防护策略检测，不会发起真实攻击 |
| 误报反馈 | 填写反馈并提交 |
| 消除误报 | 对当前日志触发的规则进行编辑，使自定义规则更准确 |
| 删除日志 | 删除当前日志 |
| 下载日志 | 下载原始数据查看分析 |

在攻击检测信息中，点击"攻击类型"旁边的图标，可查看此攻击类型的检测原理、检测流程、举例说明和参考链接信息。

在攻击检测信息的检测详情中，可展开查看请求或响应命中的全部策略和规则。

在攻击检测信息的原始报文中，可查看 HTTP 请求和响应的原始报文，点击「尝试解码」将尝试根据攻击命中时的检测方式进行解码；切换解码方式，将根据选择的解码方式进行解码。

### 7.2 访问控制日志

访问控制检测产生的日志将会展示在访问控制日志页面中，用于帮助用户追溯访问行为、排查安全事件。

![342cfa88380edfbaa4c13e2bce318827.png](images/雷池SafeLine3.0操作手册_images/342cfa88380edfbaa4c13e2bce318827.png)

- 支持对数据进行快捷筛选。
- 手动或者自动刷新列表数据。
- 列表勾选多条日志时，可进行批量删除。
- 日志数据根据规则聚合进行展示，展开可查看具体的控制对象。
- 点击「删除日志」可删除当前日志。
- 点击"更多"中的「下载日志」，可选择日志格式进行下载。

### 7.3 BOT 防护日志

## 8 防护对象

防护对象为雷池配置防护的核心部分，其核心概念包括：防护对象、应用、全局配置、配置文件等。

防护对象即为被 WAF 保护的用户"资产"，通常在 WAF 中，防护对象是 HTTP/s 协议下的网站服务器；反代模式下是一组域名+监听配置、路由模式下为一组域名、透明和镜像模式下为地址+域名。

应用即为防护对象的子层级，被防护的网站服务器可能存在很多不同的网站服务功能或页面，不同的页面对应的实际的业务服务器地址也不同。

## 9 防护设置


### 9.1 攻击检测引擎

攻击检测引擎为雷池防护引擎的核心防护组件，提供了最主要的防护检测能力，目前可检测的攻击类型覆盖：SQL 注入、XSS、情报检测、CSRF、SSRF、反序列化（Java 反序列化、PHP 反序列化）、代码注入（PHP 代码注入、Java 代码注入、ASP 代码注入）、文件上传、文件包含、命令注入、机器人、服务器响应共 15 类攻击类型检测。

在攻击检测引擎模块默认包含以下六类防护策略：

| 策略名称 | 说明  |
| --- | --- |
| 引擎防护配置默认模板 | 推荐配置，不可删除，按照最通用的防护策略原则提供 |
| 金融类客户 | 按照金融类客户防护需求提供的推荐防护配置 |
| 互联网客户 | 按照互联网类客户防护需求提供的推荐防护配置 |
| 观察模式 | 仅检测流量中的攻击信息并生成日志，不对流量进行阻断 |
| 高防模式 | 严格的攻击检测模式，阻断所有符合引擎判断标准的请求 |
| 高性能模式 | 优化的检测模式，在保持高检测率的同时提升处理性能 |

### 9.3 BOT 防护

在进行业务运营时，运营的网站会被恶意脚本程序、各种扫描器、爬虫等自动化工具扫描、非法爬取数据以及资源占用等，导致正常的运营服务被滥用或者利用。雷池 BOT 防护采用人机验证、动态防护两类防护主动手段来对所管理的防护对象应用进行防护。

> **注意事项：**
>
> 1.  BOT 防护的动态令牌、请求混淆、POW 等防护能力依赖前端模块实现，前端模块对浏览器版本有要求；
> 2.  响应混淆对业务熟悉要求较高，启用前需做严格的业务可用性测试；
> 3.  POW 功能可能被 EDR 产品认为是挖矿程序，请注意合规风险；
> 4.  自定义数据采集仅支持 json 格式的请求 body；
> 5.  支持对 WEB 应用、微信小程序、支付宝小程序及 APP 场景进行 BOT 防护。

#### WEB 防护

WEB 防护可阻断恶意自动化攻击、保护用户与系统安全、优化资源，用户可根据实际场景配置防护策略。

**单数据操作：** 在操作列中，点击「编辑」可直接修改数据内容；点击「更多」可展开操作菜单，支持启用策略、禁用策略及删除策略操作。

#### VRRP

VRRP（Virtual Router Redundancy Protocol），即虚拟路由器冗余协议，是一种用于提高网络可靠性的容错协议。它通过将多台物理路由器组织成一个虚拟路由器组（VRRP 组），对外呈现为一个统一的虚拟路由器。

| 配置项 | 说明  |
| --- | --- |
| 节点名称 | 显示当前配置所属的物理设备节点，系统自动识别 |
| 启用  | 控制当前 VRRP 实例的开启或关闭状态 |
| 初始角色 | 设定设备在 VRRP 组中的初始角色（主设备/备设备） |
| 绑定接口 | 指定承载 VRRP 协议报文的物理网络接口 |
| VRID | 虚拟路由器的唯一标识符（1-255 之间的整数），同一 VRRP 组必须相同 |
| 优先级 | 用于选举主设备（1-254），数值越大优先级越高 |
| 虚拟 IP | 设置虚拟路由器的 IP 地址和子网掩码 |
| 检查间隔 | 主设备发送 VRRP 通告报文的时间间隔（秒） |
| 流量抢占 | 更高优先级设备恢复后是否自动抢占回主设备角色 |
| 认证密码 | VRRP 组认证密码（最多 8 位，可选） |
| 跟踪接口 | 监控指定接口状态，故障时自动降低优先级 |
