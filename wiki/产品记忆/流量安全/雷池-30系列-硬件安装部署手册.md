# 雷池 SafeLine 3.0 硬件安装部署手册

## 1 部署前准备

### 1.1 安装部署手册说明

**在执行实际部署前，需要提前进行安装环境检查与设置。**

### 1.2 安装说明

#### 1.2.1 名词定义

##### 1.2.1.1 节点

- 指一台服务器，可以是物理服务器、云服务器

- 一套软件版部署可以包括多个节点，在管理界面的「状态监控-设备运行状态」可以查看各个节点状态

- 节点的数量由 License 进行限制，管理节点、检测节点无异，都包括在节点限制中

##### 1.2.1.2 安装目录

- 指雷池资源主要保存目录，默认值为 /data/safeline

##### 1.2.1.3 数据盘

- 指安装目录所在的硬盘（此概念一般出现在硬件 WAF 中）

#### 1.2.2 常用工具列表

Linux 下常用工具列表，可以参考进行安装：

##### 1.2.2.1 工具说明

tcpdump：网络抓包工具

curl：HTTP 请求工具

vim：编辑文件工具

strace：跟踪系统调用工具

tmux：终端窗口工具

net-tools：其他网络工具

sysstat：性能监控

##### 1.2.2.2 工具安装命令

Ubuntu：`apt install -y tcpdump curl vim strace net-tools sysstat`

CentOS：`yum install -y tcpdump curl vim strace net-tools sysstat`

### 1.3 硬件要求

节点基本要求：

- CPU：≥ 8 核，且必须支持 SSSE3 和 AVX2 指令集，可通过 `lscpu | grep -E 'ssse3|avx2'` 命令确认

- Docker 版本：≥ 20.10

- 内存：≥ 16 GB

- 数据盘容量：≥ 500 GB。对于云服务器，需要检查所选数据盘的 IOPS 值是否大于 1000；集群模式下，非管理节点容量可以减少，但不应低于 200 GB

- 操作系统：Ubuntu ≥ 16.04、CentOS ≥ 7.4、Debian ≥ 8；其他 Linux 系统需实际测试，通常都可以安装。推荐使用 Ubuntu 22.04

### 1.4 安装前准备

以下操作需在 root 权限下执行

**步骤 1**：将安装包拷贝到待安装节点。安装文件通常命名为 `safeline-3-software-installer-*.bin`；定制版本或 ARM 版本的文件名可能不同，但安装方式基本一致。安装包文件名通常包含 MD5 校验值，可执行 `md5sum safeline-3-software-installer-*.bin` 核对校验值

**步骤 2**：执行安装包加载。由于执行安装包会自解压安装包内容，所以建议将安装包放入一个单独的文件夹运行：

   - 创建安装目录：`mkdir -p /data/safeline`
   - 将安装包移动到临时目录并重命名：`mv safeline-3-software-installer-*.bin /data/safeline/safeline-3-software-installer.bin`
   - 进入临时目录：`cd /data/safeline`
   - 赋予执行权限：`chmod +x safeline-3-software-installer.bin`
   - 运行安装程序：`./safeline-3-software-installer.bin -p 安装包密码`

如果执行过程中，安装程序提示是否升级引擎，则默认回车为进行引擎升级（推荐操作）

**步骤 3**：校准操作系统时间。使用 `date` 命令查看操作系统时间，如果时间不正确，可以通过以下两种方式修改：

- 方案一：无法访问公网但内网有 NTP Server 时，由客户提供 NTP Server 地址，在 WAF 中配置自动同步时间

- 方案二：客户没有 NTP Server 且无法访问公网时，执行 `timedatectl set-time '2025-11-20 16:10:40'` 手动修改时间

**步骤 4**：执行安装前检查。运行 `minion check run before-install` 查看检查结果，所有 Failed 项目都需要修复后才能继续安装

**步骤 5**：如果 Failed 项中出现 `system do not support ipv6`，必须停止安装并执行 `reboot` 重启系统。系统启动后，再次执行 `minion check run before-install`，确认该 Failed 项已消失后再继续安装

## 2 硬件部署

### 2.1 制作装机 U 盘

#### 2.1.1 macOS 制作 U 盘方法（单文件小于 4G）

**步骤 1**：插入 U 盘，打开系统自带的「磁盘工具」程序，在磁盘列表中找到 U 盘，选中

![截图](images/雷池SafeLine3.0安装部署手册_images/image12.png)

**步骤 2**：单击工具栏中的「抹掉」按钮，弹出对话框中选择 MS-DOS (FAT) 格式和 MBR（主引导记录） 分区表

![截图](images/雷池SafeLine3.0安装部署手册_images/image13.png)

**步骤 3**：单击对话框中的「抹掉」按钮，等待完成擦除

![截图](images/雷池SafeLine3.0安装部署手册_images/image14.png)

**步骤 4**：关闭磁盘工具，将 safeline-installer 安装包解压，其中的内容拷贝到 U 盘根目录

![截图](images/雷池SafeLine3.0安装部署手册_images/image15.png)

**步骤 5**：需确保 safeline-3-software-installer.bin 在 U 盘根目录下；单击左边 U 盘挂载处上箭头，安全弹出 U 盘

#### 2.1.2 macOS 制作 U 盘方法（单文件大于 4G，一般为软件安装包过大的情况）

**步骤 1**：执行 `diskutil list` 命令，查看 U 盘名称

![截图](images/雷池SafeLine3.0安装部署手册_images/image16.png)

**步骤 2**：执行多分区创建命令：`sudo diskutil partitionDisk /dev/disk2 MBR FAT32 SYSTEM 30% exFAT "EXFAT_PART" R`

![截图](images/雷池SafeLine3.0安装部署手册_images/image17.png)

**步骤 3**：创建完成后可以在访达内看到两个分区，其中 SYSTEM 分区存放除 safeline-3-software-installer.bin 与 safeline-3-software-installer.bin.password 外的所有文件；EXFAT_PART 存放 safeline-3-software-installer.bin 与 safeline-3-software-installer.bin.password 文件。

### 2.2 硬件准备

上电：硬件背部通常有双电源接口，测试情况下如果只接单个电源，可以通过按下旁边的红色按钮消除警报声。

开启：通常硬件背部有对应的启动开关，需要拨至打开，正常情况下打开后可以听到风扇声音。

### 2.3 使用串口连接硬件

#### 2.3.1 接口位置

硬件前面板左下角上标有 CONSOLE 字样的网线插口；注意不要和 MGMT 等网口弄混

#### 2.3.2 连接方式

连接线 USB 侧连接计算机，RJ45 侧连接硬件，常用的连接线有

- USB 转 DB9 线缆 + DB9 转 RJ45 线缆

- USB 转 RJ45 线缆

注：部分机型随机赠送 DB9 转 RJ45 线缆

#### 2.3.3 使用终端模拟器连接

##### 2.3.3.1 Windows

使用 PuTTY 或 SecureCRT。首先在 Windows 设备管理器中找到串口设备，串口名一般为 COM3、COM4 等格式。以下假设串口设备为 COM3，以 PuTTY 为例：

![截图](images/雷池SafeLine3.0安装部署手册_images/image18.png)

按照图上配置输入设备名（COM3），波特率（115200），最后单击 Open 即可连接串口

##### 2.3.3.2 macOS

在 macOS 自带的「终端」软件内使用 screen 命令打开串口，执行以下命令：

`screen /dev/tty.usbserial-A106TEQN 115200`

其中 `/dev/tty.usbserial-A106TEQN` 是转接线的设备名称，一般可以在输入 /dev/tty.u 后按 Tab 键自动补全；如果不清楚转接线设备名称，可以通过 `ls -l /dev/tty.*` 命令查看

注意：

- 如果波特率 115200 无法进入串口，可尝试 38400、9600 等波特率

- 退出串口可以直接拔掉线缆的 USB 接口；也可以按 `Ctrl+A`，再输入 `:quit`

- 如果在打开串口时出现以下错误信息，可能是由于没有正确关闭 screen 导致，可重新插拔线缆的 USB 接口一侧

`Cannot open line '/dev/tty.usbserial-A106TEQN' for R/W: Resource busy`

`Sorry, could not find a PTY.`

#### 2.4.1 重置 BIOS

对于第一次安装的设备，建议重置 BIOS

![截图](images/雷池SafeLine3.0安装部署手册_images/image19.png)

### 2.5 U 盘安装

以下示例使用 Ubuntu 系统。

**步骤 1**：选择 SafeLine Installer，按回车键继续

![截图](images/雷池SafeLine3.0安装部署手册_images/image20.png)

![截图](images/雷池SafeLine3.0安装部署手册_images/image21.png)

#### 2.5.1 不分盘安装

**步骤 1**：`lsblk` 查看系统中的块设备信息

**步骤 2**：运行 U 盘中的安装程序，将系统部署到数据磁盘

![截图](images/雷池SafeLine3.0安装部署手册_images/image22.png)

**步骤 3**：选择部署模式：

- Deploy type 选择 Hardware，默认值为 Hardware

- Node type 按部署场景选择，默认值为 Single

#### 2.5.2 分盘安装

**步骤 1**：`lsblk` 查看系统中的块设备信息

**步骤 2**：手动挂载 WAF 软件安装包。例如，系统分区 `sdc1` 已挂载到 `/media/sdc1`，安装包所在分区为 `sdc2`，则执行 `mkdir -p /media/sdc2 && mount /dev/sdc2 /media/sdc2`

**步骤 3**：手动设置 BIN_MOUNT_POINT 环境变量后再执行安装，例如：`BIN_MOUNT_POINT=/media/sdc2 /media/sdc1/install.sh sda sdb`

> 按照当前分盘流程，执行脚本时必须遵循“小盘在前、大盘在后”的磁盘参数顺序。例如，`sda` 为 119.2 GB 系统盘，`sdb` 为 1.8 TB 数据盘，则参数顺序应为 `sda sdb`。

![截图](images/雷池SafeLine3.0安装部署手册_images/image23.png)

**步骤 4**：选择部署模式：

- Deploy type 选择 Hardware，默认值为 Hardware

- Node type 按部署场景选择，默认值为 Single

### 2.6 部署命令

#### 2.6.1 硬件单机

##### 2.6.2.3 软件承载管理节点

> **版本要求：此部署方式仅在 26.06.002 及之后版本中支持。**

此部署方式用于将硬件集群的管理节点部署在普通软件宿主机上，业务流量由集群中的硬件工作节点处理。该管理节点仍属于硬件集群，部署时 Deploy type 必须为 `Hardware`，Node type 必须为 `Management`。

**部署前准备**：确保软件宿主机已完成本手册第 1 章的所有操作，并准备好硬件集群产品证书。此部署方式不支持管理节点 HA 或嵌入式集群。

**步骤 1**：初始化软件承载的硬件集群管理节点：`minion setup -p /data/safeline --deploy-type Hardware --node-type Management --management-carrier SoftwareHostedManagement`

> `--management-carrier SoftwareHostedManagement` 仅适用于 `Hardware` 部署类型的 `Management` 节点，不得用于其他部署类型或节点类型。

**步骤 2**：启动基础平台服务：`systemctl start minion`

**步骤 3**：输入 `docker ps` 检查 WAF 各服务启动状态，当所有服务的 status 值都为 up，并且没有 unhealthy 出现时，证明安装成功

**步骤 4**：浏览器打开 `https://<软件宿主机 IP>:9443`，上传硬件集群产品证书。登录后进入「系统管理 > 工作模式 > 集群管理」，确认管理节点状态正常

**步骤 5**：按照 2.6.2.2 节部署并注册硬件工作节点。在工作节点执行 `nodeinit` 时，Management Address with Port and Protocol 输入 `https://<软件宿主机 IP>:9443`

**步骤 5**：输入 `admin`，再输入 Admin Passcode（通过 Release 设备管理平台获取）进入 root shell。执行 `docker ps` 检查服务状态；所有服务的 status 均为 up，且没有 unhealthy 状态时，表示安装成功

![截图](images/雷池SafeLine3.0安装部署手册_images/image33.png)

**步骤 6**：浏览器打开 `https://<VIP>`，上传产品证书。登录后进入「系统管理 > 工作模式 > 集群管理」，确认节点状态正常

##### 2.6.3.2 硬件集群 HA 备用管理节点

如果设备已完成出厂灌装，可跳过步骤 1。

**步骤 1**：安装部署

- 执行 `lsblk` 列出存储设备，注意区分 U 盘和设备内的硬盘
- 本例中固态硬盘为 `/dev/sdb`，机械硬盘为 `/dev/sda`，装机 U 盘为 `/dev/sdc1`
- U盘安装：不分盘安装和分盘安装步骤参考 2.5 章节，此处以不分区安装为例
- Deploy type 选择 Hardware，Node type 选择 ManagementStandby

  > **注意**：加载镜像（Importing docker images）完成后将进入部署模式选择环节，此阶段等待耗时较长，请勿提前按下回车键；误提前回车会被读取，进而进入默认模式安装（硬件单机）

![截图](images/雷池SafeLine3.0安装部署手册_images/image37.png)

**步骤 2**：安装完成后拔下 U 盘，执行 `reboot` 重启设备。重启完成后，执行 `network addr add` 配置管理 IP，执行 `network route default set IPv4` 配置 IPv4 默认网关

**步骤 3**：执行 `nodeinit`，根据提示填写信息，然后执行 `reboot` 重启设备。部分配置项需要使用主节点部署阶段留存的信息：

- Management Address with Port and Protocol：`https://<管理节点管理 IP>:443`
- Primary Management IP Address：集群主节点 IP
- Standby Management IP Address：集群备用节点 IP

![截图](images/雷池SafeLine3.0安装部署手册_images/image38.png)

**步骤 4**：输入 `admin`，再输入 Admin Passcode（通过 Release 设备管理平台获取）进入 root shell。执行 `docker ps` 检查服务状态；所有服务的 status 均为 up，且没有 unhealthy 状态时，表示安装成功

![截图](images/雷池SafeLine3.0安装部署手册_images/image33.png)

**步骤 5**：浏览器打开 `https://<VIP>`，登录后进入「系统管理 > 工作模式 > 集群管理」，确认备用节点存在且状态正常
