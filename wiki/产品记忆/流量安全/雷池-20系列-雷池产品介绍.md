# 雷池（SafeLine）产品介绍

## 产品定位

雷池(SafeLine)是由长亭科技自主研发的全球首款基于智能语义分析技术的下一代Web应用防护产品，连续多年高速增长，2025 年以 14.4% 份额、41.6% 增速登顶中国硬件 WAF 市场，成为 IDC 认证的行业领导者。

雷池接入企业网络边界，接收外部Web访问流量，进行HTTP协议解析与深度解码，调用语义分析、访问控制和自定义插件引擎进行攻击分析，并对结果进行恶意打分，最终阻断攻击流量。

雷池采用世界前沿的智能语义分析算法，能够实现基于上下文逻辑的攻击检测，在降低误报率的同时，将攻击拦截性能提升至全球顶尖水平，实现了对于Web攻击检测的极准拦截和极低误报。

## 核心能力

### 智能语义分析

长亭科技创造性地将智能语义分析技术应用于 Web 安全防护。雷池内置涵盖常用攻击语言的编译器，对 Payload 进行深度解码后，按语言类型匹配相应语法编译器，再匹配威胁模型得到威胁评级。威胁模型来自对各类攻击数据的深度学习，随着样本增加持续精进。相比规则匹配型检测，语义分析具备准确率高、误报率低的特点，管理者无需维护庞杂的规则库。

### 0day 漏洞防护

雷池创新性检测方法摆脱了传统规则型检测必须已知攻击方式才能防御的短板。通过内置各类编程语言编译系统对 Payload 进行语义分析，识别攻击真正意图，不依赖规则而依靠威胁模型判定威胁等级，在面对突发 0day 漏洞威胁时同样具备识别和防御能力。长亭科技依托自身安全研究团队，使用海量攻击样本持续打磨检测引擎。

### 高度自定义扩展

- **OpenAPI**：开放全部管理平台 API 接口，使用者可自动化调用雷池的任何功能，方便与业务系统、安全系统联动对接
- **可编程流量分析扩展模块**：使雷池可作为统一 Web 网关实现定制化场景的流量分析需求，解决企业常见业务安全问题

### 多维防护体系

雷池防护体系由语义分析防护引擎、自定义规则防护模块、流量分析防护模块构成，提供：

- **攻击检测引擎**：语义分析 + 内置规则双引擎，覆盖 SQL 注入、XSS、命令注入、文件包含等四十余种攻击类型
- **自定义规则**：支持全局和资产级别自定义规则配置，灵活应对特殊防护需求
- **请求频率控制**：基于 IP / Session / URL 的频率控制规则与黑白名单机制
- **主动防护**：主动防护策略与自定义数据采集
- **擎雷 SafeRaise**：工作流驱动的自动化安全响应编排
- **防篡改规则**：保障网页内容不被恶意篡改
- **信誉库**：内置威胁情报与信誉列表，支持情报查询与第三方联动
- **智学习**：基于业务流量自动学习正常访问模型，持续优化防护策略

### 可视化运维

- **防护状态总览**：最近 24 小时 / 30 天 / 自定义时段的请求量、攻击量、拦截量及趋势分析
- **数据仪表盘**：防护总览、站点防护、用户行为、攻击检测日志分析四维视图
- **统计数据大屏**：攻击监控大屏 + 实时访问大屏，支持自定义配置
- **防护报告**：支持手动 / 定时生成 7 类报告（防护总览、站点防护、用户行为、攻击检测日志分析、节点状态、PCI-DSS 合规报告、基线检查），可外发为 PNG / PDF / HTML

## 适用场景

| 场景 | 说明 |
|------|------|
| Web 业务防护 | 对企业对外暴露的 Web 应用（网站、API、小程序等）进行攻击检测与拦截 |
| 0day 应急响应 | 在突发 0day 漏洞公布时，无需等待补丁即可通过语义分析具备一定防御能力 |
| API 安全防护 | 保护 RESTful / JSON-RPC 等 API 接口免受注入、越权、滥用等攻击 |
| 合规审计 | 满足 PCI-DSS 等合规要求，提供完整日志与审计报告 |
| 业务流量治理 | 通过频率控制、黑白名单、主动防护等手段治理异常访问与业务滥用 |
| 安全运营编排 | 通过擎雷 SafeRaise 工作流实现攻击检测 → 响处置的自动化闭环 |
| 态势感知 | 通过大屏、仪表盘、报告等可视化手段掌握全局安全态势 |
| 系统上线测试 | 旁路检测模式下不改变网络架构，先观察后拦截 |

## 典型用户

- **金融行业**：银行、证券、保险等机构，对 Web 安全合规与低误报率有严苛要求
- **政府与公共事业**：政务网站、公共服务平台，需保障网站可用性与内容防篡改
- **互联网企业**：大流量 Web 业务与 API 服务，需弹性扩容与高性能检测
- **运营商与能源**：关键基础设施运营方，需满足等级保护与合规审计要求
- **医疗与教育**：医院信息系统、高校网站，资源有限但安全需求不减
