# 大模型安全围栏（守元）安装文档

# 安装文件

守元包含一系列安装包：

*   ai-guard-server-installer-\*.bin
    
    *   用于安装代理转发、Web 管理、数据库等服务
        
*   ai-guard-goalkeeper-installer-\*.bin
    
    *   用于安装基于模型的检测服务
        
    *   **本文件有 16G 左右大小，建议拷贝后验证一下 md5**
        
*   **ai-guard-model-install-\*.bin**
    
    *   **用于安装模型**
        
    *   **总计大小约 23G**

## 安装步骤

单一软件环境同时部署代理转发以及检测服务，需要改环境有算力卡（如GPU）。

需要拥有 /data 目录的操作权限。umask 0022。

1.  执行 ai-guard-server-installer
![alt text](image/image-1.png)
    
2.  执行 ai-guard-goalkeeper-installer
![alt text](image/image-2.png)
    
3.  执行 aminion setup -t Software
![alt text](image/image-3.png)
    
4.  安装模型
    
    1.  执行 ai-guard-model-installer-T 安装文本检测模型
        
    2.  若需要多模态
        
        1.  执行 ai-guard-model-installer-I 安装多模态检测模型
            
        2.  执行 ai-guard-model-installer-A 安装多模态检测模型
            
5.  systemctl restart aiguard-minion

## 安装步骤

转发代理服务与带有算力的检测服务分开部署。

需要拥有 /data 目录的操作权限。umask 0022。

转发管理节点：

1.  将 ai-guard-server-installer 置于转发代理节点，
    
2.  在转发节点执行 ai-guard-server-installer
    
3.  执行 aminion setup -t SimpleMaster 期间需要输入检测节点地址，记录安装过程输出的 GOAL\_KEEPER\_TOKEN、MINION\_TOKEN
    
    1.  GoalKeeper Addresses：完整 URL 格式，http 协议与端口 5008 固定，域名为检测节点 IP，多个时可以用半角逗号分隔，形如 `http://10.9.33.102:5008,http://10.9.33.103:5008`
        
        1.  是的，目前还不支持随着算力节点增加自动扩展，后面会增加该能力
            
    2.  SeaweedFS Public URL：完整 URL 格式，http 协议与端口 8333 固定，域名为管理节点 IP，形如 `http://10.9.33.101:8333`
        
4.  systemctl restart aiguard-minion
    

检测节点 ：

1.  将 ai-guard-goalkeeper-installer、ai-guard-model-installer 置于检测节点
    
2.  在检测节点执行 ai-guard-goalkeeper-installer
    
3.  在检测节点安装模型
    
    1.  执行 ai-guard-model-installer-T 安装文本检测模型
        
    2.  若需要多模态
        
        1.  执行 ai-guard-model-installer-I 安装多模态检测模型
            
        2.  执行 ai-guard-model-installer-A 安装多模态检测模型
            
4.  aminion setup -t Compute，期间需要输入转发管理节点的 IP、GOAL\_KEEPER\_TOKEN、MINION\_TOKEN 等
    
    1.  SeaweedFS Public URL：完整 URL 格式，http 协议与端口 8333 固定，域名为管理节点 IP，形如 `http://10.9.33.101:8333`
        
5.  systemctl restart aiguard-minion

# 部署相关技术交底

## 守元包含服务

| 服务名 | 服务用处 |
| --- | --- |
| ag-server | web 管理端 |
| ag-nginx | 代理服务，由nginx对外提供代理，流量转发到 ag\_interceptor |
| ag-interceptor | 转发服务，劫持对话请求响应，发送到检测，记录日志 |
| ag-goalkeeper | 检测服务 |
| ag-file-service | 多模态文件管理服务 |
| ag-seaweedfs | 文件存储服务 |
| ag-postgres | postgres:11.16 |
| ag-redis | redis:7.0.7 |
| ag-es | elasticsearch:7.17.26 |
| ag-nsqd | 消息队列 |

## 服务配置

*   服务由 minion 统一管理，配置存储在文件 db 中，可以通过 `aminion db list` 查看
    
*   服务间配置下发通过 nsqd 同步到各个节点的 minion，minion 来访问本机服务的 API 接口等
