雷池是长亭的 Web 应用防火墙产品线。当前产品资料显示，雷池攻击检测引擎覆盖
SQL 注入、XSS、命令注入、文件包含等 Web 攻击类型，并提供语义分析能力。

对于“现有 WAF 未拦住某个伪造请求头 XSS 样本”的场景，售前可以将雷池列为
替换或补强候选，但应把结论表达为“能力方向匹配，建议使用客户原始 payload 做
POC 复测”，不能在没有测试证据时承诺一定拦截。客户对第三方厂商的描述只能
作为客户反馈记录，不应据此推断该厂商全部产品的技术架构或普遍能力。

相关产品页：雷池-20系列、雷池-30系列。
