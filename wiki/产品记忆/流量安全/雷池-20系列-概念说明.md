# 概念说明
WAF 支持如下部署模式
- 软件反代单机
- 软件嵌入式单机
- 软件流量镜像
- 软件反代集群
- 软件嵌入式集群
在执行实际部署前，需要提前进行安装环境检查与设置

# 安装说明

## 名词定义

### 节点
- 指一台服务器，可以是物理服务器、云服务器
- 一套软件版部署可以包括多个节点，在管理界面的「系统信息-节点状态」可以查看各个节点状态
- 节点的数量由 License 进行限制，管理节点、检测节点无异，都包括在节点限制中
### 安装目录
- 指雷池资源主要保存目录，默认值为 /data/safeline
### 数据盘
- 指安装目录所在的硬盘（此概念一般出现在硬件 WAF 中）

### 安装命令
#### Ubuntu：`apt install -y tcpdump curl vim strace net-tools sysstat`
#### CentOS：`yum install -y tcpdump curl vim strace net-tools sysstat`

## 硬件要求
节点基本要求：
- CPU：>= 4 核，**CPU 一定要支持 ssse3 和 avx2 两个指令集，可以通过  lscpu | grep -E 'ssse3|avx2' 命令确认**。
`lscpu | grep -E 'ssse3|avx2'`
- 内存：>= 8 GB
- 数据盘容量：>= 500 GB，对于云服务器需要检查所选数据盘 IOPS 值大于 1000；集群模式下，非管理节点容量可以减少，但不应该低于 200G
- 操作系统：Ubuntu >= 16.04、CentOS >= 7.4、Debian >= 8，其他 Linux 系统需实际测试，通常都可以安装；推荐系统 Ubuntu 18.04、CentOS 7.8

**对于 CPU、内存，节点不可低于上述基本要求，集群模式非管理节点数据盘容量可以减少，参考以下数据选择：**  
| 模式           | 节点类型   | 单核承载流量       |  
| -------------- | ---------- | ------------------ |  
| 嵌入式反向代理 | 物理服务器 | 4000 qps[^1]       |  
|                | 云服务器   | 2000 qps           |  
| 反向代理       | 物理服务器 | HTTP：2000 qps     |  
|                |            | HTTPS：250 cps[^2] |  
|                | 云服务器   | HTTP：1000 qps     |  
|                |            | HTTPS：100 cps     |  
**注意：**
- **计算时，应该满足瓶颈需求，比如 HTTPS 的 cps**
- **如果客户原来有 nginx 节点配置，也可以参考选配**
- **对于内存，数值上可以简单认为 CPU 核数的两倍**

[^1]: qps 为每秒请求数。

[^2]: cps 为每秒新建连接数。
