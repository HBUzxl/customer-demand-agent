## 产品定位

全悉（T-ANSWER）高级威胁分析预警系统是一款聚焦业务网络流量检测的新一代威胁检测与响应平台。产品融合智能语义分析、人工智能、机器学习、知识图谱、攻防模型以及大数据智能引擎等核心技术能力，面向 0Day/APT、恶意加密流量、自动化武器库、内网渗透和攻击链威胁提供全流量检测、分析、溯源与响应能力。

全悉重点解决企业南北向、东西向网络流量中的威胁监控盲区，强调低误报、低噪声、真告警、可运营，帮助安全团队提升事前风险预防、事中威胁研判、事后溯源处置效率。

## 核心优势

- **智能语义分析**：从规则匹配演进到语义分析、AI 与数据驱动结合，提升未知威胁检测能力，并提供可解释的研判依据。
- **加密流量检测**：支持 JA3/JA3S 指纹、行为特征分析、ICMP/DNS 隧道检测，以及 SSL 私钥、eBPF 主机密钥、代理等多种解密方案。
- **灵活部署架构**：支持硬件一体机、软件部署、分布式、集中管理平台、云上云下混合等部署方式。
- **生态联动处置**：可与防火墙、雷池 WAF、牧云 HIDS、谛听拟态防御、万象安全运营平台等进行联动，实现检测到处置闭环。

## 交付形态

全悉支持硬件一体机和纯软件两类交付形态，覆盖 500Mbps 到 20Gbps 等不同吞吐规格，并支持标准版、集群版、集中管控版、猎隼版（Mini 版）、MSS 版等产品版本。

部署场景包括：

- 单机一体机部署
- 多探针分布式部署
- 集中管理平台统一运维
- 云上云下混合流量采集
- 流量采集 Agent 与解密 Agent 配套部署

## 核心能力

| 模块 | 核心能力 |
|------|---------|
| 流量采集与检测 | DPDK 高速抓包、协议深度解析、TLS/加密流量分析、文件还原、流量采集过滤 |
| 威胁检测 | 智能语义分析、IDS 规则检测、威胁情报、暴力破解检测、恶意文件与沙箱检测、AI 辅助研判 |
| 威胁事件管理 | 告警筛选、告警聚合、安全事件生命周期、离线 PCAP 检测、流量元数据检索 |
| 策略管理 | 自定义情报、白名单、自定义规则、弱口令字典、沙箱检测配置、SSL 私钥管理 |
| 响应处置 | TCP RST 旁路阻断、自动响应、安全设备联动、响应白名单、威胁狩猎 |
| 资产管理 | 资产自动发现、资产分组、API 资产发现、漏洞关联检测 |
| 数据输出与报告 | 威胁分析报告、Syslog/Kafka 输出、IM 通知、邮件通知 |
| 系统管理 | RBAC、MFA、SSO、设备自检、存储配置、审计日志、OpenAPI |
