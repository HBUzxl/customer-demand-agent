# 雷池 SafeLine 3.0 — 产品介绍

## 产品定位

雷池（SafeLine） 是长亭科技自研的下一代 Web 应用防火墙（WAF），核心基于智能语义分析引擎，颠覆传统规则匹配模式，主打 “**AI 驱动、低误报漏报、高性能高可用**”，为 Web 应用、API 与业务系统提供全栈安全防护，是国内 WAF 市场的标杆产品。

---

## 核心能力

| 能力 | 说明 |
|------|------|
| **语义分析引擎** | 基于上下文逻辑的智能检测，覆盖 SQL 注入、XSS、命令注入、反序列化、文件上传/包含、CSRF、SSRF 等 15 类攻击 |
| **自定义规则** | 全局/应用级灵活规则，支持 IP、URL、Header、Body 多维度匹配，可配置惩罚封禁 |
| **BOT 防护** | 人机验证 + 动态防护，覆盖 Web、微信/支付宝小程序、APP 四端场景 |
| **API 审计** | API 资产自动发现、敏感数据异常检测、API 格式异常检测 |
| **访问控制** | 频率限制，阻断/观察双模式，自动限制异常高频访问 |
| **扩展插件** | 自定义插件扩展检测与处理逻辑，支持多系统联动 |
| **黑白名单** | 精准 IP/域名管控，支持永久封禁与限时惩罚 |

---

## 适用场景

- **Web 攻击防护** — 保护企业网站、业务系统免受注入、跨站、命令执行等攻击
- **API 安全治理** — 自动发现 API 资产，监控敏感数据泄露与格式异常
- **爬虫与自动化防御** — 阻断恶意爬虫、扫描器、自动化攻击工具
- **合规与审计** — PCI-DSS 合规报告、日志审计、数据脱敏
- **高可用防护** — 集群/单机部署，VRRP + HA 主备切换，保障业务连续

---

## 典型用户

- **金融机构** — 银行、证券、支付平台，防护要求严格，合规审计需求强
- **互联网企业** — 电商平台、社交应用、SaaS 服务，流量大、业务形态复杂
- **政府与事业单位** — 政务网站、公共服务系统，合规与安全双驱动
- **能源与制造业** — 监控系统，防护业务连续性

## 部署方式

| 模式 | 接入方式 | 阻断能力 |
|------|---------|---------|
| 反向代理 | WAF 代理转发，最常用 | 阻断 |
| 路由模式 | 网关路由转发 | 阻断 |
| 透明模式 | 桥接接入，不改拓扑 | 阻断 |
| 镜像模式 | 仅分析镜像流量 | 检测，不阻断 |

## 主要价值

**极准拦截** — 语义分析替代正则匹配，基于上下文逻辑判断攻击意图，大幅降低误报

**极低误报** — 金融级预置策略 + 观察模式先行验证，业务零干扰上线

**全面可视** — 防护总览、攻击地图、趋势图、数据大屏，攻击态势一目了然

**灵活可配** — 预置策略一键切换，自定义规则精细控制，插件扩展无限可能

**闭环处置** — 一键封禁 IP → 告警通知 → 日志溯源 → 防护报告，发现到处置全程闭环
