# 安装前准备
**以下操作需在 root 权限下执行**

1. 拷贝安装包到待安装节点

	主要为安装文件 safeline-2-software-installer-\*.bin，如果为 OEM 版本、arm 版本，名字可能有区别，但安装方式基本一致。

	通常文件名包含一个 md5 校验值，可以运行命令 md5sum 命令，校验 md5 数值是否一致。
`md5sum safeline-2-software-installer-*.bin`

2. 执行安装包加载

	由于执行安装包会自解压安装包内容，所以建议将安装包放入一个单独的文件夹运行：
	
```
mkdir safeline-installer-tmp
mv safeline-2-software-installer-*.bin safeline-installer-tmp/safeline-2-software-installer.bin
cd safeline-installer-tmp
./safeline-2-software-installer.bin -p 安装包密码
```
如果执行过程中，安装程序提示是否升级引擎，则默认回车为进行引擎升级（推荐操作）

3. 调整操作系统配置 

	在第 2 步「执行安装包加载」执行完后的目录中，进入子目录 `waf-tools`，阅读目录内 README.md 文件使用相关脚本 
   - **centos 以及基于 centos 的发行版，如果不按照说明执行优化脚本，会导致 WAF 出现性能问题或服务启动异常问题**

4. 校准操作系统时间

	使用 `date` 命令查看操作系统时间，如果时间不正确可以通过如下两种方案进行修改
   - 方案一：在无法访问公网，但内网有 NTPServer 情况下，可以让客户提供 NTPServer，在 WAF 配置 NTP 配置自动同步时间
   - 方案二：如果客户没有 NTPServer，也无法访问公网，则可以手动修改时间，命令为`timedatectl set-time '16:10:40 2015-11-20'`
   
5. 执行安装前检查

	执行 `minion check run before-install`查看安装检查结果，对于 Failed 项目，需要修复后才能执行安装。  
   - **检查Failed项中有“system do not support ipv6”时，必须停止，否则会导致雷池安装失败、不可用，执行reboot命令重启系统，待系统起来后，再次执行minion check run before-install确认Failed项中无“system do not support ipv6”**
