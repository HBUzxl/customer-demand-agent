# 软件反代集群版卸载
**注意：该操作会清除 WAF 所有数据，请明确确认不需要保留数据后谨慎操作**
## 操作流程
1. 停止 minion 服务
- 执行`systemctl stop minion`
2. 停止节点上所有容器并删除
- 执行``docker rm -f `docker ps -a -q` ``
3. 清理 WAF 安装目录
- 执行 `rm -fr 安装目录（默认为 /data/safeline）`
4. 清理老版本 WAF 遗留资源目录
- 确认老版本 WAF 遗留的升级服务是否存在：`systemctl status minion-upgrader`，如果结果**非**如图表示，则需要执行清理
![minion-upgrader 服务不存在](../images/快速开始_images/systemctl-minion-upgrader-not-existed.png)
- 清理 minion-upgrader 服务命令：
  - `systemctl stop minion-upgrader`
  - `systemctl disable minion-upgrader`
  - `rm -rf /data/safeline-upgrader`
  - `rm /etc/systemd/system/minion-upgrader.service`
5. 清理 WAF 配置文件
- `rm -r /etc/minion/`
- `rm /usr/sbin/minion`
- `rm /usr/sbin/minion.*`
- `rm /etc/systemd/system/minion.service`
- `systemctl daemon-reload`
