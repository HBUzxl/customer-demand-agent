# 雷池 SafeLine 3.0 快速使用手册

## 1 第一次使用雷池

### 1.1 登录系统

1. 打开浏览器，输入系统地址（默认 `https://<设备IP>:9443/`）。
2. 输入用户名 `admin` 和初始密码。
3. 点击「登录」进入控制台。

> 首次登录后请及时修改默认密码，可在「系统管理 > 用户管理」中操作。

![登录页面](images/雷池SafeLine3.0快速使用手册_images/login_page.png)

### 1.2 确认部署模式

进入「系统管理 > 工作模式」确认当前部署模式。不同模式决定了流量接入方式：

| 模式 | 适用场景 | 是否阻断 |
|------|---------|---------|
| **反向代理** | 最常用，WAF 代理所有 Web 流量 | 是 |
| **路由模式** | WAF 作为网关转发 | 是 |
| **透明模式** | 桥接接入，不改网络拓扑 | 是 |
| **镜像模式** | 只检测镜像流量，不影响业务 | 仅检测，不阻断 |

> 软件单机部署模式在安装时确定，不支持界面修改。如需变更请联系技术支持。

![工作模式](images/雷池SafeLine3.0快速使用手册_images/workMode.png)

### 1.3 添加第一个防护对象

防护对象就是你要保护的网站。以最常用的反向代理模式为例：

1. 进入「防护对象」页面，点击「添加防护对象」。
2. **填写名称**：给防护对象起个名字，如 `官网`。
3. **配置域名**：填入要保护的域名（如 `www.example.com`）。HTTPS 网站需上传证书。
4. **配置监听**：设置 WAF 监听的 IP 和端口（如 `0.0.0.0:80`）。HTTPS 勾选「启用 SSL」。
5. **配置默认应用**：默认应用路径 `/`，填入后端业务服务器地址（如 `192.168.1.10:8080`）。
6. 点击「确定」完成。

完成后流量路径：`用户请求 → WAF（检测+拦截）→ 业务服务器`

![添加防护对象](images/雷池SafeLine3.0快速使用手册_images/object.png)

## 2 日常防护操作

### 2.1 查看防护总览

登录后默认进入「防护总览」页面，一眼看清：

- **威胁分析**：饼图展示高/中/低危攻击分布，点击可跳转日志详情
- **攻击趋势图**：请求数、攻击数、拦截数的时序变化
- **攻击地图**：攻击来源地理位置，支持中国/世界地图切换
- **被攻击对象 TOP10**：哪些网站被攻击最多
- **攻击 IP TOP10**：哪些 IP 最活跃

![防护总览](images/雷池SafeLine3.0快速使用手册_images/3a161177329423c925de6273436fb9b4.png)

### 2.2 查看攻击日志

进入「防护日志 > 攻击检测日志」，查看所有被检测到的攻击：

- **快速筛选**：按攻击类型、风险等级、防护对象等快速过滤
- **高级筛选**：多字段组合 + AND/OR 逻辑
- **筛选模板**：保存常用筛选条件，下次一键调用
- **日志详情**：点击「详情」查看完整请求/响应报文、命中规则、攻击类型说明

> 开启「自动刷新」可实时监控新攻击。

![攻击检测日志](images/雷池SafeLine3.0快速使用手册_images/detect_log_list.png)

### 2.3 封禁攻击 IP

发现恶意 IP 后，两种快速封禁方式：

**方式一：日志中一键封禁**
在攻击检测日志详情或防护总览的攻击 IP TOP10 中，鼠标悬浮至 IP 上即可快捷封禁。

**方式二：手动添加黑名单**
进入「防护设置 > 黑白名单 > 黑名单」：

1. 点击「添加黑名单」。
2. 填入要封禁的 IP 或 IP 范围。
3. 选择阻断时间（永久或指定时长）。
4. 点击「确定」。

![添加黑名单](images/雷池SafeLine3.0快速使用手册_images/cd815dc54766f9c9941e84be18ffc7f2.png)

### 2.4 添加黑/白名单

| 类型 | 用途 | 常见场景 |
|------|------|---------|
| **黑名单** | 拦截恶意访问 | 封禁攻击 IP、屏蔽扫描器 |
| **白名单** | 放行信任来源 | 允许内网 IP、放行合作伙伴接口 |
| **惩罚列表** | 自动短期封禁 | 由自定义规则触发，自动生成 |

> 黑白名单冲突时，可在页面顶部「配置」中调整优先级。

## 3 按场景快速配置

### 3.1 场景一：发现攻击后快速处置

**典型流程：**

1. 「防护总览」发现异常 → 点击饼图/地图跳转到攻击检测日志
2. 日志中筛选出高危攻击 → 点击「详情」查看请求报文
3. 确认是真实攻击 → 鼠标悬浮攻击 IP → 一键封禁
4. 如需更精细控制 → 添加自定义规则（见 4.2）

### 3.2 场景二：切换为观察模式先看效果

新上线 WAF 时，建议先用观察模式运行，只记录日志不阻断，确认误报率后再切换为阻断模式。

**操作步骤：**

1. 进入「防护设置 > 攻击检测引擎」。
2. 点击「观察模式」策略的「配置」。
3. 将需要观察的防护对象应用绑定此策略。
4. 观察一段时间后，切换到「引擎防护配置默认模板」或「互联网客户」等阻断策略。

| 策略名称 | 特点 |
|---------|------|
| 引擎防护配置默认模板 | 推荐配置，通用防护 |
| 金融类客户 | 金融场景，更严格 |
| 互联网客户 | 互联网场景，平衡误报与拦截 |
| **观察模式** | 仅记录日志，不阻断 |
| 高防模式 | 最严格，阻断所有可疑请求 |
| 高性能模式 | 检测率略降，处理速度更快 |

### 3.3 场景三：保护 API 接口

雷池内置 API 审计能力，进入「API 审计」：

- **API 资产**：自动发现防护对象下的所有 API，查看路径、方法、调用频率
- **敏感数据异常**：检测 API 请求/响应中是否包含敏感数据泄露
- **API 格式异常**：检测不符合 API 规范的异常请求

![API 资产](images/雷池SafeLine3.0快速使用手册_images/600f2c40c1f8dc700abb2ccc435ce469.png)

### 3.4 场景四：防护爬虫和自动化攻击

进入「防护设置 > BOT 防护 > WEB 防护」：

1. 点击「添加 WEB 防护策略」。
2. 选择防护对象应用和触发条件（访问频率、UA 特征等）。
3. 配置防护动作：人机验证、动态令牌、请求混淆。
4. 点击「确定」。

还支持微信小程序、支付宝小程序、APP 的 BOT 防护，需下载对应 SDK 集成。

> 注意：响应混淆对业务影响较大，启用前需充分测试。

### 3.5 场景五：配置告警通知

**步骤一：配置接收服务**

进入「订阅 > 订阅服务配置」：

1. 点击「添加一个新的服务」。
2. 选择类型：Email、钉钉机器人、飞书机器人、企微机器人、Syslog、Kafka 等。
3. 填写服务信息，点击「测试」验证连通性。
4. 点击「确定」。

**步骤二：配置订阅规则**

进入「订阅 > 订阅配置」：

1. 选择要推送的信息类型：日志摘要、系统异常波动、运行监控信息。
2. 选择接收服务。
3. 配置推送时间和格式。

![订阅配置](images/雷池SafeLine3.0快速使用手册_images/receiver_config.png)

## 4 常用设置速查

### 4.1 防护策略选择

进入「防护设置 > 攻击检测引擎」，系统提供 6 类预置策略：

| 策略 | 何时使用 |
|------|---------|
| 默认模板 | **大多数场景直接用这个** |
| 金融类 | 金融/支付业务，要求更严格 |
| 互联网类 | 互联网业务，平衡体验与安全 |
| 观察模式 | **首次上线必用**，先看日志不阻断 |
| 高防模式 | 遭受大规模攻击时临时切换 |
| 高性能模式 | 流量极大，需优先保障性能 |

点击策略「配置」可调整：
- **语义分析引擎**：启用/禁用各类检测模块，调整拦截阈值
- **内置规则**：逐条配置漏洞防护规则的启用/禁用、执行动作、风险等级

![攻击检测引擎](images/雷池SafeLine3.0快速使用手册_images/detect_engine.png)

### 4.2 自定义规则速配

当预置策略无法满足特定需求时，添加自定义规则。

进入「防护设置 > 自定义规则」：

1. 点击「添加规则」。
2. 配置规则：
   - **匹配条件**：IP、URL、请求方法、Header、Body 等
   - **执行动作**：拦截、放行、记录、重定向等
   - **作用范围**：全局（所有防护对象）或指定应用
3. 可配置高级操作：惩罚机制（触发后自动封禁一段时间）、标记等
4. 点击「确定」。

> 多条规则按检测顺序执行，可点击「调整规则顺序」拖拽排序。

![自定义规则](images/雷池SafeLine3.0快速使用手册_images/c562e3f11a81394c07861e998c7dde2d.png)

### 4.3 生成防护报告

**手动生成：**

1. 点击防护总览右上角「生成报告」，或进入「统计分析 > 防护报告」。
2. 选择报告类型（防护总览、节点状态等）、时间范围、格式（PDF/PNG/HTML）。
3. 可指定外发邮箱。
4. 点击「确定」生成。

**定时生成：**

进入「统计分析 > 防护报告 > 定时报告任务」：

1. 点击「添加一个定时报告任务」。
2. 设置统计周期（每日/每周/每月）和内容。
3. 配置完成后系统自动生成。

![防护报告](images/雷池SafeLine3.0快速使用手册_images/6b6e1bcf927276f39075c56e3f96e39c.png)

### 4.4 数据大屏

进入「统计分析 > 数据大屏」：

1. 鼠标悬浮缩略图，点击「启动大屏」。
2. 可点击「自定义大屏标题」设置标题（最多 24 字符）。

适合投屏到安全运营中心大屏幕实时监控。

![数据大屏](images/雷池SafeLine3.0快速使用手册_images/98a193a57eb11de7afabefe2b99c0cf2.png)
