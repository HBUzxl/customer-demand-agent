# **MonkeyScan 是什么？**

MonkeyScan 是一款 **AI 源码漏洞扫描产品**，帮助用户从 GitHub 仓库或源码包中发现真正值得关注的安全风险。

它想解决的，不是“扫出更多告警”，而是 **尽量减少误报，让结果更可信**。  
相比只给出大量规则命中的传统扫描方式，MonkeyScan 更强调把问题讲清楚、把结果做扎实，帮助用户更快判断：**哪些风险真的值得处理。**

# **MonkeyScan 的核心特点**

## **1. 不是追求“报得多”，而是追求“报得准”**

很多扫描工具的问题不在于“扫不出来”，而在于结果太多、太杂、太难判断。  
MonkeyScan 更关注结果质量，希望把高价值风险尽量收敛出来，减少用户被误报淹没的情况。

## **2. 不只是告诉你“有问题”，还尽量告诉你“问题在哪里、为什么会发生”**

除了发现风险，MonkeyScan 也会尽量提供更清晰的漏洞说明，帮助用户理解问题成因、影响范围和处理优先级，让结果更容易进入后续修复流程。

## **3. 接入简单，上手门槛低**

你可以直接上传 **GitHub 仓库**，也可以提交 **ZIP 源码包** 发起扫描。  
不需要复杂部署，适合想快速验证代码风险的用户。

## **4. 更适合 AI Coding 时代的安全检查**

AI 让写代码变得更快，也让风险更容易被一起生成出来。  
MonkeyScan 关注的重点不是“能不能扫”，而是 **AI 时代生成出来的代码，到底能不能更放心地用。**

#  **谁适合使用 MonkeyScan？**

MonkeyScan 并不主要面向大团队或大企业，它更适合这些用户：

-  **独立开发者 / 个人创业者**  
在项目上线前多做一道安全检查，给自己的产品加一层保险。
-  **开源工具使用者**  
在引入开源项目或第三方代码前，先排查潜在风险。
- **白帽子 / 安全研究人员**  
更高效地筛出值得深入分析的问题线索。
-  **AI Coding 用户 / AI 技术爱好者**  
给 AI 生成的代码补一轮安全复查，降低“写得快、埋坑也快”的风险。

# **MonkeyScan 可以怎么用？**

使用方式很简单，大致分为三步：

## **1. 上传代码**

支持两种主要方式：

- GitHub 仓库接入
- ZIP 源码包上传

## **2. 发起扫描**

系统会自动分析项目结构、技术栈和关键代码逻辑，并结合静态分析与 AI 语义理解，对风险线索逐步收敛。

## **3. 查看结果**

扫描完成后，你可以查看更清晰的风险结果，包括问题位置、风险说明以及后续处理参考，帮助你更快判断哪些问题值得优先处理。

# **适合哪些场景？**

MonkeyScan 适合这些常见场景：

-  项目上线前，先做一次安全自查
-  接入开源项目或第三方代码前，先排查潜在风险
-  对 AI 生成代码补一轮安全复查
-  批量筛选开源项目中值得深入研究的问题
