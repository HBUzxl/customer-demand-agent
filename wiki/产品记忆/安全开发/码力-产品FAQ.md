# 产品 FAQ

本文用于记录码力（CodeForce）产品相关的常见问题与回答，便于在客户沟通、产品评估、方案说明和内部对齐时复用。以下内容基于当前产品文档和代码实现整理，后续版本能力以实际发布说明为准。

## 1. 码力现在是否已经支持 MCP 协议接入外部工具？如果支持，主要是作为能力扩展，还是也有 MCP Server 管理和安全管控？

当前已经支持 MCP 相关能力，主要体现在 MCP 配置托管和插件/CLI 分发侧：

- 支持维护 MCP 配置模板，包括内置 MCP 与自定义 MCP。
- 支持将 MCP 与 CLI Agent 关联，生成 Codex、Claude Code、OpenCode 等 CLI 可使用的 Agent 配置产物。
- 支持端侧自动安装 MCP Server，并自动写入 Codex、Claude Code、OpenCode 等客户端所需的 MCP 配置。
- 支持全局可见、私有可见、插件可见等基础共享与可见性管理。

因此，当前 MCP 更偏向“配置托管、能力分发、端侧安装”。码力暂时没有考虑做 MCP 网关，也不是由平台统一代理 MCP Server 的运行时调用；MCP 工具的实际运行和调用仍发生在客户本地客户端或终端侧。

## 2. 对 AI Coding Agent 的命令执行、文件读写、代码修改、Git 操作，码力现在是否已有审计、策略控制或阻断能力？做到什么粒度？

命令执行、文件读取、代码修改、Git 操作等动作，本质上是在客户本地的客户端或终端环境中执行的。因此，这类操作的允许、确认或拒绝，主要由客户终端侧的 AI Coding Agent / CLI 配置来控制。例如，终端侧可以配置为每条命令都需要确认，也可以由使用者选择同意或不同意某次操作。

码力平台侧主要负责对 AI 算力调用和 Coding Agent 使用过程做审计记录。平台会记录是谁、在什么时间、通过什么入口调用了 Coding Agent，以及发起了什么类型的研发或审计任务，便于后续追溯和管理。

因此，当前平台侧的审计粒度更偏向用户、时间、入口、任务和调用记录；具体到每一条终端命令、每一次文件读写或每个 Git 子命令的实时确认与阻断，主要依赖客户本地终端侧的 Agent / CLI 安全配置。

## 3. 码力现在是否支持 Secret / Token / 敏感代码外发风险识别？如果支持，是在编码阶段、提交阶段，还是 Agent 执行阶段？

当前支持与安全审计相关的识别和脱敏能力：

- SAST、SCA、AI 安全审计和安全规则可覆盖密钥、token、敏感配置、鉴权逻辑等风险识别。
- 内置安全审计 Skill 和目标文件抽取逻辑会关注 secret、token、password、access key、连接串等高风险内容。
- Agent / Worker 执行日志和审计元数据会对常见凭据格式进行脱敏，降低日志留存中的泄露风险。

从阶段看，当前更明确覆盖的是安全审计阶段、MR/代码变更审计阶段，以及 Agent 执行日志留存阶段。它还不是完整的数据防泄漏网关，尚未在所有编码输入、模型请求外发、MCP 参数传递、Git 提交前统一做强制阻断。

## 4. 码力是否能记录 Agent / CLI 的 Tool Call 日志，比如调用了什么工具、传了什么参数、产生了什么结果？

该能力目前正在建设中，预计在 2026 年 7 月份支持。

规划中的能力会围绕 Agent / CLI 的 Tool Call 过程进行记录，包括调用了什么工具、传入了什么参数、产生了什么结果等信息，便于企业后续进行审计追溯、问题排查和安全治理。

## 5. 对高风险动作，比如删除文件、执行 shell、读取密钥、访问私有仓库，码力是否支持告警、阻断或人工确认？

当前支持部分前置约束和审计追溯：

- CLI Agent 可通过权限组控制是否开放读取、编辑、命令、浏览器、MCP 等能力。
- Workflow 安全审计 Agent 可通过 allowed tools 限制工具范围。
- Git 仓库接入会做认证和权限校验，并记录相关平台操作日志。
- 执行日志和元数据会做敏感字段脱敏。

但对“删除文件、执行 shell、读取密钥、访问私有仓库”这类高风险动作，当前尚未形成平台统一的实时告警、阻断、人工确认和逐条审批链路。现阶段更多依赖执行环境隔离、CLI 自身能力、Agent 配置约束、任务日志和平台操作日志。

## 6. 后续 roadmap 里是否有 MCP Server 管理、Agent 行为链路追踪、高危命令阻断、AI Coding Agent 安全审计这类规划？

当前代码和文档已经体现出这些方向的基础设施：

- 能力市场已经覆盖 MCP 配置托管、IDE 智能体、CLI 智能体和 Skills。
- CLI Agent 已经有技能、MCP、权限组和多 CLI 产物生成能力。
- Workflow Agent 已经有 allowed tools、执行日志、usage 统计和策略命中记录。
- 平台已有系统操作日志、安全审计规则、SAST/SCA、AI 安全审计和报告能力。

其中，MCP 方向当前重点是 MCP 配置托管和端侧自动安装，暂时没有规划建设 MCP 网关或平台侧运行时 MCP Server 代理。
