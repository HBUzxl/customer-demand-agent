# 慧鉴（CodeInsight）产品使用手册


## 慧鉴平台介绍

### 背景介绍

随着企业研发规模扩大，代码仓库、开源依赖、构建环境和发布链路日益复杂，传统依赖人工审查和事后扫描的安全治理方式，已经难以及时发现漏洞、依赖风险和交付隐患。企业需要一套能够融入研发流程、覆盖代码扫描、依赖分析、任务执行、报告追踪和交付验证的平台，将安全能力前置到开发、合并和发布环节，提升研发效率与交付质量。

### 产品简介

慧鉴(CodeInsight)是一套面向企业研发与安全团队的代码安全与研发治理平台。产品围绕源码扫描、依赖风险识别、任务管理、Worker 执行节点、Probe 探针、报告输出和自动化流水线集成等能力，帮助企业建立可持续、可追踪、可落地的代码安全管理体系。通过与本地开发、CI/CD、私有化部署和多平台交付链路结合，CodeInsight 能够支持企业在保障研发效率的同时，持续提升软件安全与交付可靠性。


## 平台初始化

### 平台登录

#### 访问平台地址

由管理员提供平台访问地址，用户在浏览器中打开后进入慧鉴登录页。手册正文不记录真实 Demo 地址。

1. 打开浏览器访问平台地址，确认页面显示慧鉴 CodeInsight 登录界面。
![登录页](产品使用手册.assets/login-page.png)

#### 输入账号密码登录

输入已分配的账号和密码后点击登录。生产环境建议为不同人员创建独立账号，不共用管理员账号。

1. 输入账号和密码并登录，登录成功后进入平台首页或项目列表。
![填写登录信息](产品使用手册.assets/login-filled.png)

#### 登录后进入首页或项目列表

普通用户通常从项目列表进入负责的项目；管理员可从首页了解平台整体数据，再进入设置、用户、规则和下载中心。

1. 在首页或左侧菜单中进入“项目”，查看可访问项目和任务进度。
![项目列表](产品使用手册.assets/project-list.png)

### 创建扫描专用用户

#### 新建普通扫描用户

建议为自动扫描、离线探针验证和测试项目创建独立普通用户，避免长期共用管理员账号。演示环境中已使用管理员权限创建扫描专用用户，并设置为普通用户角色、启用状态、并发数量 1。

1. 进入“用户 > 用户管理”，点击“新建用户”，填写账号、密码、用户名、普通用户角色、并发数量和备注。
![新建扫描专用用户](产品使用手册.assets/admin-user-create-filled.png)

#### 确认用户创建结果

1. 提交后在用户管理列表中搜索扫描用户，确认用户来源为平台用户、角色为普通用户，并保留创建时间与备注。
![扫描专用用户创建结果](产品使用手册.assets/admin-scan-user-created.png)

### 导入授权

#### 查看当前 License 状态

License 信息用于确认授权类型、源代码分析能力、AI 功能支持、并发数量和有效期。

1. 进入“设置 > 系统信息 > License 信息”，查看授权状态、授权模块和有效期。
![License 信息](产品使用手册.assets/settings-license.png)

#### 导入 License 授权文件

当授权过期或需要扩展功能模块时，由管理员在 License 页面执行更新；演示过程中只打开页面，不点击更新或导入。

1. 在 License 页面确认“更新/导入授权”入口位置，正式环境中由管理员选择授权文件后提交。
![导入 License 授权入口](产品使用手册.assets/settings-license.png)

#### 确认授权版本与功能模块

授权更新后需要再次检查源代码分析、AI 能力、并发数和截止时间，确保任务创建和扫描执行不受限制。

1. 授权导入或更新后回到 License 信息区，复核授权模块、并发数量和有效期。
![确认授权模块与有效期](产品使用手册.assets/settings-license.png)

## 快速创建扫描任务

### 慧鉴离线分析

#### 使用方式

离线分析主要适用于将扫描所需的【分析引擎】下载至客户所在服务器，待任务扫描完成后结果上传至【服务平台】中进行结果的查看。

#### 使用流程与步骤（linux环境）

**创建项目**

- 登录慧鉴服务平台，在【项目】导航中任意创建一个“质量与安全扫描”的扫描类型、编程语言以“C/C++”为例，用户可根据实际需求进行创建。

注：扫描类型说明：质量与安全检测、敏感信息检测、IaC检测。

- 质量与安全检测：主要用于代码质量与安全的扫描分析检测。

- 敏感信息检测：主要适用于检测纯文本文件中意外包含的敏感信息。例如 API密钥、用户名、密码、令牌、URL和其他机密的信息。

- IaC检测：主要适用于扫描基础设施配置。如 Terraform、CloudFormation、Kubernetes、Helm、Azure Resource Manager、Docker 配置中的不安全问题和合规问题。

### 慧鉴在线分析

#### 远程仓库拉取

远程仓库扫描适用于平台可访问代码托管服务的场景。建议使用测试仓库或只读凭据验证流程，不在文档中写入真实访问令牌。

1. 进入“自定义 > 代码托管平台”，点击“新建配置”，配置 Git/SVN/FTP/TFS 等仓库访问方式；演示只打开弹窗，不点击确定。
![新建仓库配置](产品使用手册.assets/git-repo-config-dialog.png)

1. 命令行远程仓库扫描同样使用占位符表示仓库地址、平台地址和 token，避免在手册中泄露真实凭据。
![远程仓库扫描命令](产品使用手册.assets/corax-cmd-remote-repo-command.png)

#### 使用流程与步骤

在线扫描的一般流程为：准备仓库凭据、源码包或构建产物，创建 Java 项目，创建扫描任务，选择在线分析和扫描对象，提交任务后在任务列表跟踪引擎扫描与 AI 智能审计进度。

1. 进入 Java 项目任务列表，点击“新建任务”，开始创建在线扫描任务。
![Java 项目任务列表入口](产品使用手册.assets/online-scan-01-task-list.png)

#### 本地上传

本地上传适合临时分析源码压缩包或无法长期接入仓库的项目。本手册固定使用 `test_demo` 目录下的两个在线扫描上传文件：`java-sec-code-master-source.zip` 作为源码压缩包，`java-sec-code-1.0.0.jar` 作为 Java 构建产物。

1. 在本机确认在线扫描上传文件存在：源码包 `java-sec-code-master-source.zip` 与构建产物 `java-sec-code-1.0.0.jar`。
![在线扫描上传文件](产品使用手册.assets/corax-cmd-online-upload-files.png)

1. 在新建任务弹窗中填写 Java 在线扫描任务名称，选择旗舰引擎和“在线分析”，源码来源选择“本地上传”，扫描节点选择“平台执行”。
![选择在线分析与本地上传](产品使用手册.assets/online-scan-02-online-mode.png)

1. 分别上传源码包 `java-sec-code-master-source.zip` 和构建产物 `java-sec-code-1.0.0.jar`，提交前确认两个文件名都已显示在弹窗中。
![上传源码包与构建产物](产品使用手册.assets/online-scan-03-uploaded-files.png)

1. 展开高级功能，确认 AI 智能审计等能力按任务策略开启；Demo 环境已配置模型，本次在线任务保留 AI 智能审计开启状态。
![在线扫描 AI 智能审计开关](产品使用手册.assets/online-scan-04-ai-audit-enabled.png)

1. 点击“开始扫描”提交任务，回到任务列表后按任务名称定位本次 Java 在线扫描任务。
![提交 Java 在线扫描任务](产品使用手册.assets/online-scan-05-task-submitted.png)

1. 任务列表中确认本次在线扫描已完成引擎扫描，并进入 AI 智能审计处理中状态；审计完成前不手工改写结果状态。
![在线扫描与 AI 审计状态](产品使用手册.assets/online-scan-06-task-audit-status.png)

## 项目与扫描任务

### 创建项目

#### 新建项目

项目用于承载扫描任务、缺陷结果、成员权限和统计数据。建议按业务系统或代码仓库创建项目。本文使用新建的 JavaSecCode 测试项目承载后续扫描说明。

1. 进入“项目”，点击“新建项目”，填写 JavaSecCode 测试项目名称。
![新建 Java 项目](产品使用手册.assets/admin-project-java-filled.png)

#### 选择项目语言

在新建项目弹窗中选择项目主要编程语言。本手册固定选择 Java，用于避免混合语言项目在任务创建时只出现 Linux 或 macOS 分析环境而缺少 Windows 环境。

1. 在“编程语言”下拉框中选择 Java，避免使用混合语言项目承载 JavaSecCode 扫描。
![选择 Java 项目语言](产品使用手册.assets/admin-project-java-filled.png)

#### 配置项目成员

在项目可见范围和成员区域添加项目成员，使研发、测试和安全人员能查看或处理对应项目缺陷。本次演示把管理员和新建扫描专用用户都加入项目可见范围。

1. 在“项目可见范围”中保留 admin，并追加新建扫描专用用户作为项目成员。
![配置项目可见成员](产品使用手册.assets/admin-project-java-filled.png)

#### 保存并进入项目

1. 点击“确定”后返回项目列表，搜索项目名称确认 Java 项目已经创建成功。
![Java 项目创建结果](产品使用手册.assets/admin-project-java-created.png)

### 创建扫描任务
