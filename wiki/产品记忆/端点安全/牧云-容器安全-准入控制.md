# 准入控制


**使用此功能需要前往安装集群准入控制组件。**

牧云·云原生安全平台基于 Kubernetes 原生架构，推出集群准入控制功能，当前主要支持 12 条规则，支持对单个集群配置多条策略，每条策略支持配置多个规则。并基于策略生成告警阻断事件。

策略规则类型：

1. 包含特定镜像名称；
2. 使用 securityContext.privileged 参数（以特权运行）；
3. 包含特定 Labels；
4. 包含特定 Capabilities；
5. 将匿名账户 / 账户组绑定到角色 / 集群角色（禁止使用匿名账户）；
6. Pod 资源使用 automountServiceAccountToken 参数；
7. 使用特定镜像仓库 ；
8. 在 env 中使用 Secret；
9. 使用 Pod 时未指定 container 的 cpu / 内存资源 limit；
10. 使用 Pod 时未指定 container 的 cpu / 内存资源 request； 
11. 共享命名空间。 

## 操作方法

策略配置列表提供策略名称、处理方式、是否启用、策略更新事件等字段。点击【添加策略】可以创建准入策略，支持对策略进行启用 / 禁用管理操作。

![](../../../images/product-features/upload_643375a7a86f1e155ce104466fb8d6ca.png)



点击【策略名称】字段可以前往查看策略详情。

![](../../../images/product-features/upload_b33c7e817ec71f52f612f863e55ed85c.png)

在集群环境中，如果操作者行为触发了已开启的策略将会上报告警 / 阻断事件，点击【事件名称】前往查看事件详情页面。

![](../../../images/product-features/upload_1cf16f6cdd77893297ede4737a39c4cb.png)

事件详情页面包括 3 个模块：原始报文、关联资产、事件信息。

![](../../../images/product-features/upload_9a2825ec7f18af9463757477e7710594.png)
