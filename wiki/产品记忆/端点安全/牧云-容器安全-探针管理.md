# 探针管理


## 安装探针

点击 “探针安装” 按钮进入安装引导页面，可根据容器所在环境选择探针部署方式。
- 集群自动化部署：适用于部署了 Kubernetes 等编排工具的纯集群环境，可通过集群管理工具来自动化部署探针到各个节点。
- 非集群部署：适用于在单个主机上用容器化技术（如Docker）拉起容器的环境，直接在机器上手动执行探针安装脚本进行部署。

![](../../../images/product-features/upload_b0feaebcf80af2ec7c874236b4763604.png)

### 集群自动化部署

安装探针前需确保已经集成对应集群资源，且集群处于连接成功状态。如果集群资源未被集成，请先在集成资源/集群资源中进行集成。

![](../../../images/product-features/upload_f717927101243e0cd0e62735ed0765e1.png)

![](../../../images/product-features/upload_44c770532ec46bb7000e78d0b9694dac.png)

集群自动化部署支持选择要部署探针的集群和节点，通过容器安全管理平台实现自动安装探针。也支持用户从管理端下载集群配置文件，前往集群 Master 节点手动执行命令，实现手动安装方案。

可为部署的探针指定 “探针运行模式” ，可以选择 “进程模式” 和 “POD 模式”，默认选择 “进程模式”。

**注意：若容器安全产品与主机安全产品融合，则容器安全探针仅支持以进程模式运行。**

可在 “高级设置” 参数中自定义探针资源配额和控制探针安装速度，限制容器探针资源占用。

其中 “新增 Node 自动部署探针” 配置默认关闭，用户可根据实际部署需求手动开启，开启后将自动为所有新加入集群的节点部署探针。

![](../../../images/product-features/upload_728843d3f8db18e20f0335725bd53a6d.png)

### 非集群部署

探针部署方式选择 “非集群部署”，下一步选择探针隶属的业务组。点击 “生成并复制命令” 按钮，将自动复制探针安装命令。

登录容器所在的服务器，并以 root 身份执行复制的安装命令，完成探针安装操作。

![](../../../images/product-features/upload_f7fffea37188ff0782c552a5fe32fd98.png)

![](../../../images/product-features/upload_e7c5501f30f1281c554551020dee7a43.png)

## 数据视图

已经安装成功的探针将在 “探针管理” 列表中展示，支持切换 “探针视角” 和 “集群视角” 查看信息。

### 探针视角

“探针视角” 默认展示主机 IP、主机名、集群名称、Node 名称、探针状态、探针版本等信息。系统会自动检查探针版本，对于不是最新版本的探针进行标识，点击探针版本后方标志查看可更新版本。

探针有四种通信状态【在线】【离线】【异常】【停用】：

- 在线：探针成功注册到平台，并保持正常通信。
- 离线：探针与平台最近一次通信结束，等待下一次通信唤醒。
- 异常：探针权限不足，无法注册到平台；平台无法连接到探针；或其他原因。
- 停用：探针被手动停用。

![](../../../images/product-features/upload_f892fb58e6e75d232b27fdb6650abcea.png)

### 集群视角

“集群视角” 展示已集成所有集群的探针安装情况，统计各个集群已安装探针和未安装探针 Node 信息。支持展示和管理集群自动部署探针和自动卸载探针配置，可批量调整多个集群的配置。

当 “新增 Node 自动部署探针” 开启时，将自动为所有新加入集群的节点部署探针。当 “集群缩容自动卸载探针” 开启时，集群缩容将自动卸载被移除节点上的探针。

![](../../../images/product-features/upload_38b69b323756f5fc9137868bcc78cdb0.png)

点击已安装探针和未安装探针 Node 统计数字，跳转到内层页面展示具体信息。对已安装探针节点支持进行探针管理操作，对未安装探针节点支持快速安装探针。

![](../../../images/product-features/upload_d7c0fb0a9c6592591fcab7fbfcf5f1ee.png)

![](../../../images/product-features/upload_fce6ae022f434d29ccf4fc58eba83b37.png)

## 探针管理操作

对已经安装的探针支持基本管理操作，包含卸载、停用、更新、重启、启用、修复。

![](../../../images/product-features/upload_2f1d8e359fd41897412409decd1c904f.png)

同时可对探针进行修改业务组、抓取运行日志、调整探针资配额、调整探针运行日志、自动降级设置。

![](../../../images/product-features/upload_69e292d78e0948f142d4a4eedfc94772.png)

注意：当存在离线探针需要手动卸载时，可前往探针所在机器执行以下步骤：

1. 关闭探针服务： 
    - 单容器环境：systemctl stop veinmind 
    - 融合部署的探针：systemctl stop cloudwalker
2. 删除探针相关文件：
    - 单容器环境：cd /opt/veinmind && uninstaller uninstall --purge
    - 融合部署的探针: cd /opt/cloudwalker && uninstaller uninstall --purge
3. 删除集群链接器：
``` text/x-sh
# 删除集群链接器
kubectl -n veinmind delete deploy veinmind-k8s-connector
kubectl delete namespace veinmind
```
## 业务组管理

点击页面右上角 “业务组管理” 按钮，进入内层页面管理业务组信息。系统按照树形结构展示业务组隶属关系，以及各业务组关联的主机信息。

支持对业务组进行创建子业务组、编辑业务组、删除业务组操作。

![](../../../images/product-features/upload_2383277aaa962452ad71ac3e58509b43.png)

系统默认内置分组 “根分组”，用户可根据业务分组情况，在 “根分组” 下创建子业务组。

点击 “根分组” 对应的操作按钮，下拉选中 “创建子业务组”，在弹窗中设置业务组名称和描述，成功创建新业务组。

![](../../../images/product-features/upload_92d41f539f531ec66af50db942aa1038.png)

![](../../../images/product-features/upload_72986df7caa5304662f2c3a7466f6e22.png)

选中某个业务组，点击右侧操作按钮，选择 “编辑业务组” 操作。可在编辑弹窗中修改选中业务组的名称和描述信息，调整隶属的上级业务组。

![](../../../images/product-features/upload_1fe7df0c6ec12c90891d1e175ac82cdf.png)

![](../../../images/product-features/upload_63ec6d47f88fe923e1bcf073f15ceaf1.png)

选中某个业务组，点击右侧操作按钮，选择“删除业务组”操作，成功删除选中的业务组。删除选中业务组后，其组内探针会被转移至父级组进行管理。

![](../../../images/product-features/upload_803aa59a75337579f3a48028df0c2f42.png)

在页面左侧树形结构中选中业务组，页面右侧展示选中业务组关联的主机信息。点击右侧列表中 “编辑” 操作，可为主机一键修改隶属关系。

![](../../../images/product-features/upload_4780ba48ac8cd28e539340d464014933.png)
