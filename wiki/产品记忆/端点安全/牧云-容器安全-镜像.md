# 镜像

在业务场景前置阶段，镜像构建的自由性及容器的多样化、网络的复杂化导致资产梳理变得困难。平台通过默认监测，可实现清点目标服务器上镜像详细资产全貌，关联资产风险，提供最新的资产清点结果。

点击【资产清点-镜像】进入镜像资产页面，此页面列表展示探针扫描获取的资产数据。可以直观查看某一镜像对象是否进行过扫描，是否存在安全风险，点击【镜像名称】可以前往查看镜像详情内容，点击【风险数据】可以前往查看此镜像的事件统计信息。

![](../../../images/product-features/upload_d6b64f69cf55e7415a146e067069ba9a.png)

支持切换 镜像 / 主机 / 仓库 / 集群 视角，通过不同的视角查看不同维度的资产情况，镜像视角展示所有扫描过的镜像资产，主机/仓库/集群视角实时展示当前最新的资产数据。页面右上角展示当前目标下镜像资产的更新时间，列表提供批量导出功能，可一键导出用户选中的镜像资产数据。

在区分扫描前后的无漏洞状态时，平台使用【无风险】表示扫描后的未发现风险，使用 严重 / 高 / 中 / 低 危漏洞数量为0表示未扫描状态，并在对应镜像名称后加上![](../../../images/product-features/upload_5bb82b871f662d51e37203e1f2355600.png)标识。如发现未扫描镜像可前往【管理中心-任务计划】模块中创建任务计划，对相应的镜像进行扫描。

![](../../../images/product-features/upload_9a6c1a527580c5320e2f633f9f24bc8b.png)

支持单次/批量选择镜像对象进行类型标识，支持标识镜像为【基础镜像】或【可信镜像】，标识后可前往【管理中心-策略管理】进行查看。手动标记后，表单对应镜像出现![](../../../images/product-features/upload_6827ae88742ec62fd5ad46528a6a2f2d.png)和![](../../../images/product-features/upload_03a93a24465efb790edfc49a8f56f370.png)标识。

1. 基础镜像：即业务镜像，一般选取安全性较高的镜像进行设置。 
2. 可信镜像：一般选取可以安全使用的镜像进行设置。

![](../../../images/product-features/upload_06409521032e12b23a5df7902caa7d6c.png)


点击 【镜像名称】 进入镜像详情页面，镜像详情包括三个模块【基础信息】【镜像层分析】【风险信息】，基础信息包括三个部分内容：镜像信息、镜像来源、关联资产。

## 基础信息

基础信息模块主要包含镜像信息、镜像来源和关联资产三个部分：

1. 镜像信息：提供镜像的10种基础信息字段，为助力业务推进，提供镜像 author 字段，便于风险镜像推进修复。
2. 镜像来源：用于标识当前镜像存在哪些仓库中、哪些主机上、被那些集群 Pod 使用。
3. 关联资产：关联基于此镜像部署的运行时资产，基于此字段，我们可以快速定位哪些主机上的容器，哪些集群中的 Pod 使用此镜像。

镜像资产以镜像 Reference + 镜像 ID 作为唯一标识符，所以某一镜像资产对象可能存在多个地方，有多个来源，如当前有同一个镜像 ubuntu:latest 存在主机 10.10.10.1 和主机 10.10.10.2 中，此 ubuntu:latest 镜像在镜像来源中将存在两条数据。提供这一字段便于用户精准定位镜像资产位置。

![](../../../images/product-features/upload_172a7bb045ebdfa9b1e0842c42584659.png)



## 镜像层分析

展示当前镜像 history 命令信息，并关联每层引入风险点，支持调整展示排序规则

![](../../../images/product-features/upload_851ebb4cd0b5f65fccf388559a32ff30.png)


## 风险信息

展示当前镜像风险评分信息，并提供当前镜像的所有安全事件统计数据，并标识当前镜像被哪些插件扫描过，有助于风险定位和保障镜像进行过完整的安全扫描。

![](../../../images/product-features/upload_9302986ec8225bd27b3bbb372f61f9a7.png)
