# 系统兼容性

> 长亭牧云容器入侵检测系统兼容性说明。适用版本：25.09.x。文档日期：2026 年 7 月。

# 管理端兼容性

由于牧云容器安全产品服务端采用容器化部署，因此底层操作系统对产品本身运行的兼容性没有影响，只有 CPU 指令架构有影响。目前兼容主流的 x86 以及 arm64 架构。（鲲鹏 920、海光芯片有真实部署过）

# 探针兼容性

25.02 ～ 25.11 版本的容器探针采用在宿主机节点以进程方式安装的形态，其兼容性可参考主机探针兼容性。以下特殊情况除外：

- 2.6.18 内核（CentOS 5、RHEL 5）容器探针不支持。
- 2.6.32 内核（CentOS 6、RHEL 6、Ubuntu 10.04）容器探针未做过专门适配。
- Windows 系统不支持。
