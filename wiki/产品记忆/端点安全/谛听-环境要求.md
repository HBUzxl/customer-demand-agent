# 设备性能要求

| __型号__ | __易捷版DS-Express-SP01__| __标准版DS-Standard-SP01__ |__高级版DS-Advanced-SP01__ | __尊享版DS-Premium-SP01__ |
| -------- | -------- | -------- |-------- | -------- |
| __支持探针__     | 20个A1000H/S或<br>1个A2000H探针  | 50个A1000H/S或<br>3个A2000H或<br>1个A4000H探针  | 100个A1000H/S或<br>6个A2000H或<br>2个A4000H探针 | 500个A1000H/S或<br>30个A2000H或<br>6个A4000H探针 |
| __支持开启蜜罐__ | 10 | 30 | 50 | 70 |
| __管理节点设备配置要求__  | CPU 2 核 <br> 内存 8G <br> 硬盘 500G  | CPU 4 核<br>内存 16G<br>硬盘 1T |CPU 8 核<br>内存 32G<br>硬盘 1T |CPU 16 核<br>内存 64G<br>硬盘 1T|

注：测试项目的运行时间短、日志量较小，表中四种型号的硬盘要求可以分别减小到 100G、500G、1T、1T。正式项目日志量较大，需要按照表中硬盘要求准备设备。

注：软件探针节点性能要求较低，探针1核2G内存50G磁盘存储即可。

# 部署环境要求

| __-__ | __管理节点要求__ | __探针节点要求__ |
| -------- | -------- | -------- |
| __内核__   | Linux 3.10.0-514 及以上  | 无  |
|__操作系统__  | Ubuntu 16.04 及以上；<br>CentOS 7.4 及以上；<br> Redhat 7.4 及以上；<br> SUSE 12 SP2 及以上；<br> Oracle Linux 7.4 及以上   | Ubuntu 16.04 及以上；<br> CentOS 6.5 及以上；<br> Redhat 6.4 及以上；<br> SUSE 11 sp4 及以上；<br> Oracle Linux 7.4 及以上；<br> Windows server 2008及以上 |
| __国产化环境__ | 【CPU】海光、鲲鹏、飞腾<br>【操作系统】中标鲲鹏、银河麒麟、<br>麒麟V10、统信UOS服务版（x86、arm）、<br>统信UOS 20、中科方德等操作系统的适配  | 同左  |
| __软件__ | Docker 18.06.2 及以上的稳定版；<br>Docker 的Storage Driver 为 overlay 或 overlay2；<br>Docker-compose；<br>Unzip (用于安装) | (仅Linux探针)<br>iptables 1.4.20 及以上 |
| __系统配置__ | 系统时间为 UTC 时间；<br>SELinux、Firewalld 关闭；<br>umask 为 022 | SELinux、Firewalld 关闭 |
| __文件系统__ | 谛听安装目录所在磁盘分区的文件系统类型为 ext4 | 无  |
| __磁盘分区__ | 蜜罐镜像目录 /var/lib/docker/<br> 下至少有 80G 空间；<br>建议将使用中的系统数据库目录<br>/data/d-sensor/data 挂载在固态硬盘上（如果有），<br>已归档的系统数据库目录/data/d-sensor/data1 <br>挂载在机械硬盘上，但要注意定期归档日志  | 无 |
| __网络__ | 安装时尽量在线 | 能访问管理节点的：<br>443 或 1338 端口（用于安装）<br>1337 端口（用于运行） |

PS. 内核、软件、系统配置、文件系统的检查在下文 "环境与依赖的检查与准备" 步骤中有所包含。操作系统版本、硬盘分区和网络请自行检查是否符合要求。
