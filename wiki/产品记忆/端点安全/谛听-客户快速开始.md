# 客户快速开始

从安装谛听到捕获第一条入侵事件的最短路径。

## 前提条件

- 已获取谛听安装包（主平台安装包 + 蜜罐镜像包）和许可证文件
- 管理节点服务器已满足[环境要求](../10.部署手册/2.环境要求.md)，Docker 及 Docker Compose 已安装

## 第一步：安装管理节点

1. 将安装包上传至管理节点服务器
2. SSH 登录服务器，执行环境检查脚本确认环境满足要求：

   ```bash
   chmod +x check_dsensor_env.sh
   ./check_dsensor_env.sh
   ```

3. 运行安装程序，按提示完成管理节点安装

   ```bash
   chmod +x install.sh
   ./install.sh
   ```

4. 安装完成后，通过浏览器访问 `https://管理节点IP` 进入管理界面

> 详细步骤和自动化脚本部署方式请参考 [首次安装](../10.部署手册/3.首次安装.md)。

## 第二步：上传许可证并登录

1. 首次访问系统会进入许可证上传页面，点击"选择许可证"上传 license 文件
2. 确认许可信息无误后，点击"确定上传"
3. 使用系统生成的默认账户登录，并尽快修改密码

> 支持密码认证、证书认证、Radius 认证、LDAP 认证四种方式，详见 [首次使用](../8.操作手册/2.首次使用.md)。

## 第三步：配置蜜网和蜜罐

1. **创建蜜网**：进入"蜜罐管理 → 蜜网管理"，点击"添加新蜜网"，输入名称并选择是否允许访问外网
2. **添加蜜罐**：进入"蜜罐管理"，点击"添加新蜜罐"，选择蜜罐类型和所属蜜网

   - 谛听支持 67 种蜜罐类型，涵盖系统服务（SSH、RDP、FTP 等）、数据库（MySQL、Redis、Oracle 等）、Web 应用（Jenkins、Nexus3、OA 等）、特殊缺陷（fastjson、Shiro 等）
   - 可自定义蜜罐用户名、密码、数据库数据，也可通过蜜罐模板快速配置

> 详见 [首次使用 - 配置蜜网和蜜罐](../8.操作手册/2.首次使用.md) 和 [蜜罐类型](../8.操作手册/5.蜜罐类型.md)。

## 第四步：安装探针

1. 进入"探针管理"页面，点击"添加新探针"
2. 选择适用的操作系统（Linux / Windows），按界面说明获取安装命令
3. 在目标服务器上执行安装命令
4. 返回"探针管理"页面，确认探针状态为"正常"

> 支持在线安装、离线安装和一行命令快速安装，详见 [首次安装 - 安装探针节点](../10.部署手册/3.首次安装.md)。

## 第五步：为探针添加端口服务

1. 进入"探针管理"，找到已安装的探针，进入探针详情页面
2. 点击"添加服务"，将蜜罐绑定到探针端口
3. 也可使用"一键监听剩余端口"快速配置

> 配置完成后，若探针状态为"正常"，则服务配置成功。详见 [首次使用 - 为探针添加端口服务](../8.操作手册/2.首次使用.md)。

## 第六步：验证入侵检测

使用客户端访问部署好的蜜罐服务，验证系统工作正常：

- **Web 类蜜罐**：浏览器访问 `http://探针IP:端口`
- **SSH 类蜜罐**：使用 SSH 客户端连接探针 IP 和对应端口
- **数据库类蜜罐**：使用数据库客户端连接探针 IP 和对应端口

触发入侵后，在"威胁日志 → 蜜罐入侵日志"中可以查看捕获的入侵记录，在"告警中心"查看告警信息。
