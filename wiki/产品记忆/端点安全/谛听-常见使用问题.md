## 忘记管理账号密码

进入 shell 重置：

```
docker exec -it dsensor_server bash
python manage.py initadmin --username USERNAME --password PASSWORD --action reset
```

## 账号的访问限制设置错了，无法登陆

进入 shell 重置
```
docker exec -it dsensor_server bash

python manage.py shell

from account.models import *

x = User.objects.filter(username='admin')[0]

#确认是否是admin用户
x


x.ip_policy

x.ip_policy_mode

x.ip_policy = ['*.*.*.*']

x.ip_policy_mode = 'allow'

x.save()
```

## 密码错误次数过多，系统锁死

进入 shell 创建一个新用户

```
docker exec -it  dsensor_server bash

./manage.py  initadmin  --username 1 --password 1 --action init
# 创建一个新用户
```
