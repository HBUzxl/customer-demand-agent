# DDR 产品发布 ChangeLog
## 3.10.1 版本发布

发布时间：2026-07-22

### 能力新增
- 支持针对 Windows 终端下发 BitLocker 加密配置。可以通过管理端统一配置各个员工终端的 BitLocker 开启状态，以及恢复密钥的同步。（注：1、该能力为 POC 功能，需单独授权，您可联系相关工作人员获取；2、该能力仅支持 Windows 终端，且终端需要包含 TPM 模块。）

- 修复剪切板日志中，命中内容存在乱码的问题；

- 优化 Linux 终端安装过程中的提示文案，方便用户理解安装步骤；

- 修复 新版本飞书通过预览查看文件时，被误判为外发的问题；

- 修复 Windows 终端下，Adobe Reader 打印文件时的水印失效问题；

## 3.9.18 版本发布

发布时间：2026\-07\-08
### **一、重点信息同步**
- 【本期的 OpenAPI 鉴权方式进行了重要调整，最新配置步骤如下】：
  - 步骤 1（准备账号） ：使用 companyadmin 账号登录平台后，在右上角进入到个人中心；
  - 步骤 2（生成密钥）：在个人中心，手动创建 API KEY；
  - 步骤 3（调用接口） ：在请求接口时，不能再使用旧的鉴权方式，最新示例如下:
    
    ``` curl -X POST -H "x-cs-header-company: <company_id>" -H "Authorization: Bearer <API KEY>" -k "https://xxx/openapi/v1/device/list" ```

- 【影响范围】：
  - 全部 OpenAPI；
  - 所有已经对接了 OpenAPI 的用户，需要您调整鉴权方式，原有 /v1/token 接口会下线；

- 对于给您带来的不便，我们深表歉意！本次的接口鉴权变动，也是为了能简化后续接口的鉴权方式，提升对接体验。如您遇到任何问题，欢迎联系我们，我们会尽快为您解决！

### **二、版本核心能力**

- 【新增功能】支持 AI 资产发现以及 AI 资产风险扫描。有效帮助企业解决 AI 资产清点，AI 资产风险排查的问题；

- 【新增功能】支持强制关闭 Windows 系统的自动更新功能。开启后，员工的 Windows 终端电脑将不再自动更新，有效降低运维成本。

- 【能力增强】桌面管理-软件管控-盗版检测功能，现可支持“隔离进程”模式。选择该配置后，会将疑似的盗版软件进程隔离到一个独立的区域，不与系统进程、其他进程共享资源，让您不用在担心某些恶意的盗版软件来感染您的系统或窃取其他程序的数据。


### **三、其他产品体验提升**
- 优化 产品顶部导航栏的“搜索”功能。现在可以通过此处搜索需要寻找的功能，并实现快速的定位;

- 优化 终端的诊断日志压缩包不再加密，下载后即可直接解压，提升问题处理效率;

- 优化 总览-创建策略卡片，hover 时的功能排序调整。将最常用的「泄露管控」进行了前置；

- 优化 终端管理-终端配置-运行资源 CPU 占用上限功能。支持分开配置 Windows 终端、Linux/信创 终端的 CPU 占用上限。避免了统一配置的场景下，Windows 终端占用 CPU 过高，Linux/信创 终端 CPU 资源分配过低的问题;

- 修复 Windows 终端导致的打印机打印异常终止问题;
