# Web站点

平台支持主动对应用中的 Web 站点进行资产清点，可清点容器内的 Web 站点信息并进行集中展示，包括所在容器信息、容器状态、服务类型、Web 路径信息等。

点击【资产清点 / Web 站点】进入 Web 站点资产页面，此页面列表展示探针实时获取的资产详情。支持查看某一容器内所有 Web 站点的基本情况。依据服务类型、域名、容器名称 / ID 进行具体 Web 站点资产区分。

![](../../../images/product-features/upload_874ac1614df504095c7f138c3b94a856.png)

点击【服务类型】可进入 Web 站点资产详情页面，详情包括两大模块：站点信息和关联资产信息。站点信息提供服务类型、Web 路径、发现时间、域名、主机端口、容器端口、协议、绑定 IP 等信息。关联资产信息提供容器和 Pod，用于关联整体云原生资产全貌，点击【容器名称】可跳转至容器基础信息页面查看容器详情。
