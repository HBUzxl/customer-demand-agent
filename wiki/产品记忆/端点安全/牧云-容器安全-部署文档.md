# 环境准备

设备配置要求： 8c 16G 内存 200G 磁盘以上。

操作系统要求：centos 7.9 及以上、ubuntu18.04 及以上、其他内核版本在3.10.0-1160 以上的系统。

请确认开启服务器 443、44443 端口，443端口用于正常web服务请求，44443端口用于探针交互服务，请确保安装探针的机器可以访问到服务端443和44443端口，因443同时为管理端web服务，若客户有合规要求，需要避免探针客户端能访问到管理端web服务，可以通过安装时指定与探针交互的web服务端口（指定方式参考），若如指定端口7777，则请确保安装探针的机器可以访问到服务端7777和44443端口即可。

~注意：从25.11.x版本开始，为了兼容集群版，探针通信端口统一改成了44443端口~

# 管理端安装步骤

1.  从 release 平台下载安装包到设备上，veinmind-VM-S10-xx.xx.xx.xx.bin。
2.  创建安装目录并安装，命令如下：
```postgresql
mkdir -p  /data/veinmind
chmod +x veinmind-VM-S10-xx.xx.xx.xx.bin
./veinmind-VM-S10-xx.xx.xx.xx.bin -C /data/veinmind
# 输入密码，等待解压完成
cd /data/veinmind
./veinmind-run.sh  --ss xx.xx.xx.xx  # 单机版改为正确的主机IP
./veinmind-run.sh  --ss xx.xx.xx.xx,xx.xx.xx.xx,xx.xx.xx.xx,xx.xx.xx.xx  ##集群版改为所有节点IP
```
3.  安装完成后，输入 docker ps -a 查看容器运行情况如下：
![image.png](../images/85079cb4-d75d-4c56-8c9b-6753eb38131b.png)
⚠️**注意：新装时 veinmind-db 启动不成功是符合预期的，无需处理。**
4. 访问 https://xx.xx.xx.xx 上传 lic 文件，保持初始密码。


# 探针安装步骤

## 非集群探针部署

1.  登录管理界面，访问“管理中心”-“探针管理”页面，点击右上角“探针安装”按钮，在弹出的侧边栏中选择“非集群部署”，点击“下一步”。
    ![image.png](../images/09cffdfd-46da-487f-af43-a8c778001acb.png)
2.  选择探针需被安装的“业务组”，点击“高级设置”可设置“探针资源配额”，点击“生成并复制命令”可生成探针一键安装命令，复制到系统中以 root 权限运行即可。
    ![image.png](../images/6f18323c-9475-467e-8fc8-ae5533a5a2bc.png)
    ![image.png](../images/1d40d130-b61e-4b75-8840-5780ef1f4944.png)

## 集群自动化部署

1.  登录管理界面，访问“管理中心”-“集成资源”页面，点击右上角“集成”按钮，选择集成集群资源，如 Kubernetes。
    ![image.png](../images/c671ce60-2aba-4c3d-a16f-aad92a3a8aeb.png)
2.  按照弹窗中的提示下载探针部署需要的镜像资源到具备 docker 命令的 linux 主机上（如集群的 master 节点），解压下载好的文件。
    ⚠️**注意：docker 版本建议在Docker 20.10 及以上。**
    ![image.png](../images/882c7343-0b76-4a24-9112-82785ff20bbc.png)
3.  在窗口中填写集群的仓库地址及账号密码，点击“生成命令”按钮，可生成镜像推送命令；复制生成的镜像推送命令到解压好的探针镜像目录执行即可将探针镜像推送至集群镜像仓库。
    ![image.png](../images/52218fe6-c439-442e-a44a-59d1152eec14.png)
    ![image.png](../images/3ffb12b5-3da9-40f1-9ea2-d7d6db44cccb.png)
    ![image.png](../images/4b59a5c1-1de2-44dc-aa51-2e9822748700.png)
⚠️**注意：若出现如上图提示:"docker manifest create is only supported on a Docker cli with experimental cli features enabled",则说明当前 docker 版本过低且未开启拓展功能，需要开启后重新推送。开启步骤请参考文档最后“如何开启 docker 实验特性”。**
    ![image.png](../images/bfb8dd98-0605-4920-9fd2-f53e42a02dd1.png)
4.  在窗口第 3 步中输入上一步中最后输出的“仓库路径信息”，点击“下载配置文件”按钮，将下载好的配置文件上传至集群 master 设备并解压"unzip k8s-2.zip  -d veinmind-config"。
    ![image.png](../images/6029b5b6-db81-449f-8152-b9928c7c1219.png)
    ![image.png](../images/a271d32b-19e0-4bbb-9b13-c39e2533d7e5.png)
5.  在 veinmind-config 目录中依次执行：
```text/x-sh
#集群连接组件安装说明
#1.初始化集群 RBAC 相关：
bash init-account.sh
#选择对应的集群类型  1: kubernetes, 2: openshift 
#2.初始化拉取镜像的凭证：
bash create-secret.sh <DOCKER_REGISTRY_SERVER> <DOCKER_USER> <DOCKER_PASSWORD>
#3.部署集群连接组件服务：
kubectl apply -f k8s-connector-deployment.yml
```
![image.png](../images/1a139cc7-46ef-47b3-93b7-34e57e91859c.png)
6.  执行 kubectl get pod -n veinmind 检查 veinmind-k8s-connector 处于 running 状态，即完成了集群集成。![image.png](../images/6640fd50-dde8-47f3-8b83-8506f30f9241.png)
7.  访问“管理中心”-“探针管理”页面，点击右上角“探针安装”按钮，在弹出的侧边栏中选择“非集群部署”，点击“下一步”。![image.png](../images/7454f1a9-859b-498a-a79c-394c1e55a7ab.png)
8.  确认集群已连接成功，点击“下一步”。![image.png](../images/3ee1c125-9d2f-4f88-93d3-0c13ba78c832.png)
9.  选择“自动安装”，选择对应的业务组，点击“高级设置”可以配置探针资源配额、安装速度控制；选择需要批量部署探针的集群及部署范围（全部节点或者部分节点），点击“立即安装”按钮即可。
    ![image.png](../images/agent-auto-install-advanced-settings.png)
10.  等待 5 分钟左右，可见集群探针陆续上线。![image.png](../images/b22f9d8f-7e2e-4d59-bf13-c4e30f09caf0.png)

# 更换 license

目前更换 lic 需要在后台进行操作：

1.  将 lic 文件上传到管理端服务器。
2.  执行如下命令：
```text/x-sh
curl -k --location --request POST 'https://<替换成实际地址>/auth/license_upload' --form 'license=@"<替换成实际的license文件地址>"'
```
3.  重启服务。
```text/x-sh
docker-compose -f ./manifest/docker/docker-compose.yml down
docker-compose -f ./manifest/docker/docker-compose.yml up -d
# 检查服务状态
docker ps -a
```

##  如何开启 docker 实验特性？

```text/x-sh
# 第一步：
vim /etc/docker/daemon.json
{
  "experimental": true
}
# 第二步：
vim ~/.docker/config.json
{
    "experimental": "enabled"
}
# 第三步：重启docker
systemctl daemon-reload && systemctl restart docker
```
