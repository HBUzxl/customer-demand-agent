# 长亭牧云主机入侵检测系统兼容性说明

## 1. 概述

### 1.1 产品架构说明

牧云主机安全管理平台由探针端和管理端组成：

- **探针端**：探针作为采集客户端安装在需要进行安全管控的服务器上，支持一键批量安装与卸载，部署载体包括但不限于物理机、虚拟机和云服务器等。
- **管理端**：管理服务为用户提供基于 HTTPS 的管控接口，可使用浏览器进行可视化管理，也可使用 API 实施自动化运维。
- **平台架构**：平台基于容器架构设计，可灵活扩展，支持单机部署和软件集群部署；通过自研分布式底座，部署载体不限于物理服务器和虚拟机，支持线下和云上部署，同时支持 SaaS 服务。

本文分别从探针和管理端两个方面说明兼容适配情况。

## 3. 管理端兼容性

真实运行的管理端分为大大小小数十个组件。为方便叙述，本章节将管理端视为一个整体，不再针对每个组件单独说明兼容适配情况。

与探针不同，管理端不存在功能降级情形，因此不根据每个业务功能单独展开。
