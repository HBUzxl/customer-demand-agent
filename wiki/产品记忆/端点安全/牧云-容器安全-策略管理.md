# 策略管理

牧云·云原生安全平台提供标识基础镜像、标识可信镜像、白名单等策略管理功能。

## 基础镜像

支持在镜像资产列表中进行基础镜像设置，手动设置的基础镜像将展示在此列表页面中，并支持取消已设置的基础镜像，支持通过镜像名称和镜像ID进行筛选，满足不同业务场景需求。
![](../../../images/product-features/upload_eed74126353d4d408be25023b3d0ad0d.png)




## 可信镜像

在镜像资产列表中进行可信镜像设置，手动设置的可信镜像将展示在此列表页面中，并支持取消已设置的可信镜像，支持通过镜像名称和镜像 ID 进行筛选，满足不同业务场景需求。
![](../../../images/product-features/upload_cf759930b398aaf5084a7bcbb28e3e3d.png)


## 白名单

支持对多种风险事件和检测规则手动设置白名单策略。点击策略后的【编辑】或【删除】可对策略进行更改。

![](../../../images/product-features/upload_68c18db3bc6097001af200530d15b8a7.png)


具体事件类型、对象类型、可支持加白规则如下：



| 事件类型     | 对象类型 | 可支持加白规则  |
| ------------ | -------- | ------------------------------------------------------------------ |
| 镜像漏洞     | 镜像     | CVE 编号  |
| 镜像恶意文件 | 镜像     | 文件 sha256 值    |
| 镜像Webshell | 镜像     | 文件 sha256 值  |
| 敏感文件     | 镜像     | 规则名称   |
| 容器逃逸     | 容器     | 特权容器(容器)、特权容器(集群 Pod)、不安全的挂载(容器)、不安全的挂载(集群 Pod)、共享命名空间(容器)、共享命名空间(集群 Pod)、不安全的 Capability(容器)、不安全的Capability(集群 Pod) |
| 反弹Shell    | 容器     | 远程地址、父进程命令行(全等匹配)、父进程命令行(正则匹配) |
| 异常连接     | 容器     | 异常 DNS 地址、异常 IP 地址、进程可执行文件名、进程可执行文件路径 |
| 命令审计     | 容器     | 规则名称、风险等级、进程命令行(全等匹配)、进程命令行(正则匹配)、进程用户名、进程可执行文件名、父进程用户名、父进程命令行(全等匹配)、父进程命令行(正则匹配)  |
| 暴力破解     | 容器     | 攻击源 IP、认证类型、用户名(全等匹配)、用户名(正则匹配)  |
| 内存后门     | 容器     | 类名(全等匹配)、类名(正则匹配)、父类名(全等匹配)、父类名(正则匹配)、所属类加载器 |
| 容器Webshell | 容器     | 文件 sha256、文件路径、文件目录、文件名、文件后缀 |
| 容器恶意文件 | 容器     | 文件 sha256、文件路径、文件目录、文件名  |
|  逃逸行为 |  容器   | 进程命令行(全等匹配)、进程命令行(正则匹配)、进程可执行文件名、父进程命令行(全等匹配)、父进程命令行(正则匹配)  |

为方便使用，表单【加白规则-匹配条件】的右上角，设置了正则工具。该工具支持对正则表达式的编写和匹配测试，最终会给出匹配结果。支持多行匹配和忽略大小写。在页面右侧给出了正则表达式的常用字符说明。

![](../../../images/product-features/upload_052258bd5b7e9ec0985497273cdf9ba1.png)




## 风险评分

支持自定义对镜像设置风险评分，总分 100，完成设置后可前往【镜像资产-风险信息】模块进行查看
