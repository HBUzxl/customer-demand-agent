# WebShell

**使用此功能请提前前往任务计划模块创建对应的周期扫描任务**

牧云·云原生安全平台镜像 WebShell 检测系统是长亭牧云主机安全管理平台的底层文件检测引擎 guanshan 的集成项目，经历了数次版本迭代与实场演练。

WebShell 检测引擎支持检测 php、jsp、asp 三种文件类型，主要依赖了以下核心技术：

1. 静态文本特征检测：通过大量文本特征对脚本内容进行快速模式匹配，可覆盖特征较为明显的 WebShell。
2. 骨架哈希检测：通过词法分析、语法分析等算法对脚本文件进行解析，构建抽象语法树，对 AST 的关键语法特征进行哈希，可对抗隐藏文本特征的 WebShell 免杀方案。
3. 静态语义分析检测：对脚本内容进行静态语义分析，通过恶意打分模型对文件内容进行评估，判断恶意程度较高的语义行为，可用于对抗自研的 WebShell 和无公开特征的 WebShell。
4. 动态污点追踪检测：将脚本内容编译为虚拟机字节码，对字节码进行模拟执行，通过污点追踪算法分析程序外部输入和敏感函数调用的关联关系，最终判断外部输入是否有可能通过脚本传入敏感函数，可用于对抗高度混淆和高度变形过的 WebShell。
5. 动态插桩内存检测：注入 Java 进程，Dump 关键内存数据，配合静态语义分析算法，用于检测动态注入的恶意脚本（内存型 WebShell）。

## 操作方法

点击【风险感知-镜像风险-WebShell】前往查看存在 WebShell 的镜像信息，此列表展示在【任务计划】进行安全扫描后发现的所有安全事件结果详情。点击【镜像视角】的镜像名称字段，可查看此镜像存在的 WebShell 风险事件。镜像视角仅展示存在 WebShell 的镜像资产，可通过不同纬度筛选查看事件数据和当前风险事件处理进度。

![](../../../../images/product-features/upload_0b6c82f8f4d3d1d545bba0ff53699d09.png)


点击【事件名称】可前往查看 WebShell 事件详情，点击上方视角切换支持从不同维度了解风险信息，支持基于【规则名称】【镜像名称】【镜像 ID】【风险等级】进行事件筛选。点击操作列的【处理】选择【加白事件】，将自动生成加白规则并对事件进行加白。

![](../../../../images/product-features/upload_c18135d65dab627b4a0dbe2bdd65b8f9.png)

列表状态列和多选支持为每条事件标记当前处理状态：

1. 有风险：默认标识，系统默认为所有上报的安全事件标记为有风险状态；
2. 确认中：当我们查看了事件详情有了下一步判断后，可以将此事件标记为确认中状态；
3. 已解决：当我们收到业务方反馈此问题已修复后，我们可以将此事件标记为已解决状态；
4. 误报：当我们发现 Webshell 信息匹配有误时，可以将此事件标记为误报状态；
5. 忽略：当我们任务此条事件数据无需关注时，可以将此事件标记为忽略状态。

点击【事件名称】进入 WebShell 事件详情页面， WebShell 事件详情包括五个模块【文件信息】【镜像信息】【事件信息】【检测详情】【处理记录】，提供 WebShell 的具体文件信息字段、检测依据和解决方案，并关联到发现此 WebShell 的镜像资产，有助于快速排查风险并进行下一步解决修复。点击【文件信息】模块右上角的![](../../../../images/product-features/upload_024979fd53530174002f86e303a3b705.png)可以下载 WebShell 样本文件。
