# 集成资源

牧云·云原生安全平台支持集成主流镜像仓库如 Docker Hub 、harbor 等，主流集群对象如 Kubernetes 等。点击【集成资源】进入集成页面。资源共有 3 种连接状态【连接成功】【连接失败】【连接中】

1. 连接中：探针正在验证资源认证信息。
2. 连接成功：当前集成资源对象与探针连接正常，可顺利通信。
3. 连接失败：
    1. 探针所在网络无法与目标资源所在网络正常通信，请排查此资源指定的扫描探针所在服务器是否能与目标资源所在服务器正常通信；
    2. 探针可以与资源正常通信，但因资源相关认证参数不正确导致鉴权失败，请排查资源认证参数是否准确；
    3. 当前资源绑定的探针或探针组被删除后没有可用探针。

![](../../../images/product-features/upload_a910392393c17fcc95c674e132e289e5.png)



点击右上角【集成资源】按钮，配置仓库/集群资源参数，完成参数配置后点击【测试连接】按钮，可快速测试当前探针是否可以连接到仓库，点击【创建资源】平台将创建仓库/集群资源对象。当连接状态变为【连接成功】时，即可对资源下发任务进行检测。

## 集成资源

仓库集成参数配置：

| 参数字段 | 内容 |
| ------------ | ------------------------------------------------------------ |
| 资源类型 | 支持选择 **Docker Hub、Harbor v1、Harbor v2、Docker Registry v2、华为 SWR、阿里 ACR（公有云实例）、腾讯 TCR、Nexus、Jfrog、Quay** |
| 资源名称 | 为当前仓库命名 |
| 仓库地址 | 此仓库对应地址 |
| 匿名访问 | 开启则可匿名扫描仓库公开镜像 |
| 用户名 | 您使用此仓库时个人账号的用户名，并选择此账号对应的类型：管理员账号、非管理员账号 |
| 密码 | 您使用此仓库时个人账号的密码 |
| Access Token | 此仓库个人账号的认证信息 |
| Access Key ID（AK） | 此仓库个人账号的认证信息 |
| Secret Access Key（SK） | 此仓库个人账号的认证信息 |
| 地域选择 | 云仓库的地域字段 |
| 实例 ID | 云仓库的实例ID |
| 探针类型 | 可选择本地部署探针或云部署探针 |
| 探针范围 | 为集成对象指定用于执行扫描任务的探针/探针组 |

集群集成参数配置：

| 参数字段 | 内容 |
| ------------ | ------------------------------------------------------------ |
| 镜像仓库地址 | 存储集群探针镜像包的私有仓库地址，**必须指定对应的 namespace** |
| 仓库账号用户名 | 访问仓库的账号 |
| 仓库账号密码 | 访问仓库的账号密码 |
| 启用代理 | 全局代理配置, 开启后集群探针/组件将通过代理地址与服务端进行通信 |

完成集成后可点击卡片进入资源详情对资源名称等字段进行修改。

点击卡片可以进入资源详情页面，支持对资源参数进行修改，支持一键跳转对应资源的资产列表查看资产详情。



### Docker Hub

牧云·云原生安全平台支持集成 Docker Hub 仓库，可对企业的仓库镜像进行扫描，依据扫描结果进行风险分析边并提供修复建议，重点关注开发人员在镜像构建时的风险管理。

**重要提示 : Docker Hub 官方限制普通账户每 6 小时只能拉取 100 - 200 个容器镜像，Docker Pro 和 Docker Team 帐户可以在 24 小时内进行 5,000 次拉取，这一点可能会影响用户在平台的使用体验，更多详情请查看官方文档**

**前置准备**

1. 前往 Docker Hub 官网；
2. 在 个人页面-账户设置-安全 中新建 AccessToken；
3. 权限选择 Read、 Write、Delete；
4. 稍后集成需要使用此字段，用户可以复制对应的 AccessToken 备用：例如：4xxxxxx9-dxx0-4xxe-axx8-6xxxxxxxxxx0；
5. 探针准备：用户需要提前创建部署用于扫描仓库的探针或探针组。

**操作步骤**

1. 前往产品控制台；
2. 导航到 集成资源 页面，点击右上角 集成资源；
3. 选择 Docker Hub 资源类型；
4. 为用户的仓库命名，并输入用户的 Docker Hub 用户名与新创建的 AccessToken；
5. 选择用户需要的探针；
6. 点击 测试连接，测试当前连接状态；
7. 点击 创建资源。

![](../../../images/product-features/upload_53bc6f3189f794f5743c66127b5de952.png)


**选择探针时请注意，保证所选探针所在机器和仓库之间的连通性，以防探针机器在外网仓库机器在内网等情况**

**错误排查**

如果一直无法连接到仓库，请依照以下条目进行排查：

1. 检查用户名与 AccessToken 是否填写正确；
2. 检查 AccessToken 权限是否配置正确；
3. 检查部署探针的服务器是否配置代理可以访问到 dockerhub 外网仓库（login 接口和产品使用接口不同，无参考价值）。

### Kubernetes / Openshift

牧云·云原生安全平台支持集成 Kubernetes/Openshift 集群，可对企业的业务集群进行扫描，检测与防护。

**操作步骤**

1. 前往产品控制台；
2. 导航到 集成资源 页面，点击右上角 集成资源；
3. 选择集群对应的资源类型；
4. 执行命令下载镜像包，并上传到可访问私有仓库的服务器，请确保服务器上有 docker 客户端；
5. 填写命令参数，平台不会保存使用仓库账号密码, 仅用于单次生成命令：
    - 镜像仓库地址：存储集群探针镜像包的私有仓库地址，**必须指定对应的 namespace** 
    - 仓库账号用户名密码：访问仓库的账号密码
6. 点击生成命令按钮，并使用生成的命令将镜像包推送到集群私有仓库中；
7. 完成推送后会自动输出一段内容，需要复制内容并前往平台上传；
8. 完成上传后，点击下载配置文件并上传到集群节点；
9. 前往集群节点，运行命令：
    - 初始化集群 RBAC 相关：`bash init-account.sh`
    - 初始化拉取镜像的凭证：`bash create-secret.sh <DOCKER_REGISTRY_SERVER> <DOCKER_USER> <DOCKER_PASSWORD>`
    - 部署集群连接组件服务：`kubectl apply -f k8s-connector-deployment.yml`
10. 完成后前往产品控制台，集群会自动注册到平台。

<img src="../../../images/product-features/upload_51cf01aa4c6fcdc01d0be4110658ec2a.png" width="60%" height="" />



点击卡片进入资源详情页面，集群资源提供关联组件卡片，当前提供 3 种集群插件，其中集群连接组件自动安装，另外两种组件情况如下：

日志审计组件：如需使用集群日志审计功能，需要提前给对应的集群安装组件。
1. 安装流程：点击手动安装组件按钮，点击【下载】按钮下载组件压缩包，将下载的压缩包上传到 master 节点并解压，kubectl create 下载的deployment 文件，然后运行命令：chmod +x ./install.sh，然后运行 ./install.sh 即可。
2. 成功安装后组件会自动与平台进行通信，当组件状态展示为 正常运行中 时，则证明组件安装成功，可以使用集群日志审计功能。

准入控制组件：如需使用集群准入控制功能，需要提前给对应的集群安装组件。
1. 安装流程：点击手动安装组件按钮，点击【下载】按钮下载组件压缩包，将下载的压缩包上传到 master 节点并解压，kubectl create 下载的deployment 文件，然后运行命令：chmod +x ./install.sh，然后运行 ./install.sh 即可。
2. 成功安装后组件会自动与平台进行通信，当组件状态展示为 正常运行中 时，则证明组件安装成功，可以使用集群准入控制功能。

## 匿名访问

Docker Hub、Harbor v1、Harbor v2、Docker Registry v2、Nexus、Jfrog 仓库支持匿名访问功能，开启匿名访问后可以前往创建任务计划，指定仓库中的公开镜像进行扫描，无需配置账户认证信息。

## 分布式扫描

Harbor v1、Harbor v2、Docker Registry v2、Nexus、Jfrog 仓库使用管理员权限访问时支持分布式扫描功能，可以选择多个探针，下发扫描任务时平台将会分布式下发扫描，提高扫描速率。
