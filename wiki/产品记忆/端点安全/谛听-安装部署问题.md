## docker 网段与客户内网冲突

确保 docker 版本在 18.06 及以上（18.06 以下不支持这个特性）
修改 /etc/docker/daemon.json 中的以下字段（若无该文件，则新建）：
```
{
	"default-address-pools": [{
		"scope": "local",
		"base": "*.*.*.*/16",
		"size": 24
	}, {
		"scope": "global",
		"base": "*.*.*.*/16",
		"size": 24
	}]
}
```
重启 docker，docker inspect 查看容器 ip 是否成功更改

## windows 探针想卸载的时候找不到当时的路径

windows 在任务管理器中-详细信息中，在顶上的tab中，可以选择列，展示路径名称

## 探针和管理节点之间无法使用 1337 端口

可以修改为别的端口，需要修改两部分：

管理节点后台 docker-compose.yml 文件里，修改 supermario 部分端口代码
```
ports:
  - "1234:1337/tcp"
```  

修改后重启谛听 docker-compose  up -d
另外一个是安装探针的时候，需要 `./chaitin-bootstrap -server-addr IP:1234`
若将想将 443 换 其他端口，改动类似。

## docker 默认存储位置空间不足

可以修改（或新建）daemon.json文件。修改后会立即生效，不需重启 docker 服务：
```
vi /etc/docker/daemon.json
// 添加内容：
{"graph": "/new-path/docker"}
```
> **注意：** 修改后所有容器和镜像会丢失，已经运行过一段时间的谛听不要这样修改，否则界面上原有的蜜罐蜜网无法使用，且不能删除

另外可以用 docker images prune 删除多余镜像

## ECS硬盘扩容

要给硬盘扩容，可以按照以下步骤进行操作：

1. 首先，确保你已经对要扩容的硬盘进行备份。因为扩容过程中可能会有数据丢失的风险，所以请务必备份重要数据。

2. 打开一个终端或命令提示符窗口，并使用以下命令来查看当前的分区情况：

    fdisk -l
    在输出中找到你要扩容的硬盘及其分区信息。

3. 使用以下命令安装 parted 工具（如果尚未安装）：

    sudo apt-get install parted

4. 运行以下命令以打开 parted 工具（请将 /dev/vda 替换为你要扩容的硬盘设备）：

    sudo parted /dev/vda

5. 在 parted 命令提示符下，输入 print 命令以查看硬盘分区信息：

    (parted) print
    确认当前分区表类型为 msdos（如果你的分区表类型是 gpt，则需要使用其他工具进行扩容）。

6. 输入 resizepart 命令，后跟要扩展的分区号。例如，要扩展 /dev/vda1 分区，你可以输入：

    (parted) resizepart 1

7. 根据提示，输入新的分区大小。你可以使用 + 后面跟着要增加的空间大小或 N% 后面跟着要添加的百分比。例如，要将分区扩展到最大可用空间，可以输入：

    (parted) resizepart 1 100%
    或者，如果你想在当前大小的基础上增加10GB，可以输入：

    (parted) resizepart 1 +10G

8. 输入 quit 命令以退出 parted 工具。

9. 运行以下命令以重新读取分区表并调整文件系统大小（假设使用的是ext4文件系统）：

    sudo resize2fs /dev/vda1

10. 现在，你应该已经成功地将硬盘分区扩展到所需的大小。
