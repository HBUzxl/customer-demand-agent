# 权限管理

牧云·云原生安全平台支持多角色权限管理，满足网络安全运维中分权分责、多角色协同的需求。系统默认提供 admin 用户并关联系统管理员角色，同时支持自定义角色、灵活配置权限，并可为不同用户分配相应角色。

## 用户管理

点击页面右上角 “添加用户” 按钮，在弹窗中设置用户名称、关联角色、用户有效期，成功添加新用户。**添加新用户后请妥善保存密码信息，平台不提供二次查看入口。**

![](../../../images/product-features/upload_bbf516646a6481e13f17ba8121244546.png)

已经创建的用户支持编辑、删除、解锁、重置OTP功能。其中 “用户状态” 分为几下三种情况：
- 正常：账号正常，可正常使用功能；
- 锁定：账号触发访问策略被系统锁定，不可登录平台，可手动解锁用户账号；
- 过期：账号使用时间超出过期时间则会自动设定为过期状态，不可登录平台，可通过修改过期时间恢复为正常状态。

![](../../../images/product-features/upload_4175fff7765eff5d37267969b7d4a6b0.png)

## 角色管理

当前平台默认提供两种角色，系统管理员和运维管理员角色。

点击页面右上角 “创建角色” 按钮，在弹窗中自定义新的角色并设置权限范围。已经创建的角色支持编辑和删除操作。

![](../../../images/product-features/upload_117eccec9d10ed92133fd9058b72fb5d.png)

## 访问策略

**该功能仅限 admin 账号使用**

平台提供错误登录锁定和单会话登录限制策略，可依据不同的业务要求进行策略配置。账号触发策略锁定后，可联系 admin 手动解锁账号。

![](../../../images/product-features/upload_c977791ab94d17503f40bebe1bb111dd.png)

点击多因素认证后方的开关，可选择启用多因素认证（TOTP)。管理员启用多因素认证的全局配置后，用户登录界面需要二次验证。市场上常见的支持多因素认证的软件基本都可以支持本管理平台多因素认证，这里以阿里云app为例说明使用方法：

下载并安装阿里云应用，在移动设备端登录阿里云应用。选择“我的” >“ 虚拟MFA”，单击+选择合适的方式添加多因素认证设备。

扫码添加（推荐）：在移动设备端，单击扫码添加，扫描阿里云控制台绑定MFA步骤页面出现的二维码，单击确定。

手动添加：在移动设备端，单击手动添加，输入账号和密钥，单击确定。

在本平台多因素认证配置界面，输入移动设备端显示的动态验证码，单击保存完成绑定。（ 移动设备端的阿里云应用会显示您当前账号的动态验证码，每30秒更新一次。）

![](../../../images/product-features/upload_8cedf715733662e6533a72cae1843132.png)

管理员开启多因素认证后，对于没有绑定 OTP 的用户，登录系统时需进行首次绑定。

![](../../../images/product-features/upload_7f33e83d7d88f35aaa8311817be25f4e.png)

输入用户名和密码后，点击 “登录” 按钮跳转到多因素认证绑定指引页面，用户扫码或者手动添加多因素认证设备。

![](../../../images/product-features/upload_fa46bf11e1b8ec66b5d58dea8a066865.png)

用户绑定多因素认证设备后再次登录管理平台，输入用户名和密码，再输入即时的多因素验证设备生成的动态密码方可登录系统。

如果用户丢失了 OTP 无法登录系统，管理员可在用户管理列表中为普通用户重置 OTP。重置后该用户下次登录时，系统会引导其重新绑定新的验证器。

![](../../../images/product-features/upload_254da13414255e7cf616fe38df57e723.png)
