# 更新说明

## VM-S10-26.07.003

## 新增功能

- **服务端运行监控** - 新增服务端运行监控能力，便于持续观察服务运行状态。

- **探针代理安装** - 探针支持代理安装，提升受限网络环境下的部署适配能力。

- **扫描结果展示** - 扫描任务详情新增扫描结果展示，便于在任务详情中直接查看检测结果。

## 改进优化

- **告警记录字段补充** - 微隔离告警记录页面新增源节点 IP、目的节点 IP 字段，提升告警定位和分析效率。

- **业务组筛选优化** - 优化探针列表业务组筛选能力，提升探针检索体验。

- **预置用户安装** - 探针支持使用预置用户安装，可在安装命令后指定现有用户进行安装。

- **集群名称筛选** - 镜像漏洞筛选支持按集群名称筛选，便于在多集群场景下快速定位风险。

## Bug 修复

- 修复资产清点中应用软件镜像视角按软件类型筛选不生效的问题。

- 修复行为学习模型学习列表按学习状态筛选不生效的问题。

- 修复入侵检测-逃逸行为通过 IP 地址筛选后未自动弹出完整主机信息的问题。

- 修复 host PID 模式容器进程被误判为宿主进程的问题。

- 修复策略管理中白名单、镜像白名单筛选器名称与列表不对应的问题。

- 修复恶意文件、webshell、内存后门任务编辑后返回空白问题。

- 修复弱口令字典数据小于3M上传报错的问题。

## VM-S10-26.07.002

## 新增功能

- 支持创建和执行自定义 Lua 脚本任务，支持用户根据实际业务需求编写、上传并执行 Lua 脚本，实现安全检测、数据采集、风险分析及自动化处置等场景的灵活扩展，提升产品扩展能力和场景适配能力，降低针对个性化需求的开发成本，使安全运营人员能够快速响应不同环境下的检测和处置需求。
- 新增一键查询功能，为用户提供统一的产品内搜索入口，支持快速查找产品功能模块、页面入口、业务对象及关键数据，实现搜索结果一键跳转，降低用户查找和操作成本。
- 支持 OIDC 和 OAuth 第三方认证，支持与企业现有身份管理平台进行集成，实现统一身份认证和单点登录（SSO），

## 改进优化

- WebShell 检测结果支持对恶意内容进行高亮展示，便于快速定位风险片段。
- 补全微隔离告警记录、运行时风险弱口令、容器逃逸、镜像风险 WebShell、恶意文件、敏感信息等页面的数据导出能力。
- 探针版本号保持与主机侧一致，减少版本识别差异。
- 优化连接失败场景下的集成资源删除能力。

## Bug 修复

- 修复集群下发安装探针页面不展示的问题。
- 修复集成集群脚本兼容不同版本 `kubectl` 的问题，避免安装集群探针时报错。
- 修复探针服务表记录被软删除后，导致 gRPC 探针服务无法正常注册、心跳异常的问题。
- 修复编排文件自定义规则设置后，上传 Dockerfile 文件未匹配到对应自定义规则的问题。
- 修复命令审计命中内置规则 `_runc` 时被恶意攻击误报的问题。
