# 产品架构
本产品是一个全面的云原生应用保护平台(CNAPP)，采用三层架构设计，集成了多种容器安全、合规管理和运行时保护能力，支持多云环境部署，为企业提供端到端的云原生安全解决方案。

# 业务模块功能说明

## 资产管理
提供对云原生环境中各类资产的全面可视化和管理能力。主要场景包括容器镜像、集群、节点等资源的清点与分类，帮助企业了解资产分布情况，识别潜在的安全风险点，为安全策略制定提供基础数据支持。

## 数据可视化
将复杂的云原生安全数据转化为直观的图表和报告。适用于安全状态监控、风险趋势分析等场景，帮助管理者快速了解系统整体安全状况，发现异常模式，做出及时决策。

## 镜像风险
专注于容器镜像安全检测，识别镜像中的漏洞、恶意代码和不安全配置。适用于 CI/CD 流程中的镜像安全验证，帮助开发团队在部署前发现并修复安全问题，减少生产环境中的安全隐患。

## 运行时风险
监控容器运行过程中的异常行为和安全事件。适用于识别未授权访问、特权提升、异常网络连接等威胁场景，提供实时防护和告警，保障容器应用的运行时安全。

## 集群响应
提供针对 Kubernetes 集群级别安全事件的自动化响应能力。适用于集群组件漏洞利用、权限滥用等场景，能够自动隔离受影响的节点或工作负载，限制攻击面扩大。

## 运行时响应
针对容器运行时的安全威胁提供实时响应和缓解措施。适用于检测到恶意进程、文件篡改等安全事件时，能够根据预设策略自动终止可疑容器或限制其网络访问权限。

## 合规基线
提供针对各种安全标准和法规的自动化合规性检查。自动评估云原生环境的合规状态，生成差距分析报告，指导合规性改进，目前已有适用于 Docker 17.06 版本的 Docker CIS 基线 1.1 和适用于集群 1.16-1.18 版本 Kubernetes CIS 基线 1.6 。

## 集群编排
提供安全管理和配置 Kubernetes 集群的能力。适用于集群配置审核、权限管理等场景，确保集群配置符合安全最佳实践，减少配置错误导致的安全风险。

## CI/CD集成
实现与企业现有 CI/CD 流程的无缝集成，在开发和交付过程中嵌入安全检查。适用于 DevSecOps 实践，帮助开发团队在早期发现并解决安全问题，提高应用交付的安全性。

## 容器行为学习
利用机器学习技术分析容器的正常行为模式，识别异常活动。适用于零日攻击检测、内部威胁识别等场景，能够发现传统规则难以识别的高级威胁。

## 引擎升级
提供平台的安全引擎和规则库的自动更新功能。适用于确保防护能力与最新威胁同步更新的场景，保障平台对新型攻击的防御能力。

## 报表生成
自动生成全面的安全和合规报告。适用于向管理层汇报安全状况、满足审计要求等场景，提供可视化的安全绩效指标和趋势分析，支持数据驱动的安全决策。

# 各通用能力说明

## 任务调度系统
提供分布式任务管理和执行的基础架构。适用于大规模安全扫描、定期合规检查等场景，能够高效分配计算资源，保证任务按优先级顺序执行，支持任务的并行处理和故障恢复，提高整体平台的工作效率。

## 基线规则系统
管理和维护安全基线规则库的核心组件。适用于 CIS 基准、NIST 框架等安全标准的实施场景，提供可定制的规则配置，支持规则的版本管理和更新推送，确保安全评估基于最新的安全最佳实践进行。

## 集群准入组件
控制容器和 Pod 进入 Kubernetes 集群前的安全验证机制。适用于强制实施镜像签名验证、安全策略合规性检查等场景，确保只有符合安全要求的工作负载才能部署到集群中，有效防止不安全组件的引入。

## 漏洞评估系统
全面扫描和分析容器镜像、应用代码和依赖库中的安全漏洞。适用于供应链安全管理、风险优先级排序等场景，提供漏洞的详细信息和修复建议，帮助开发团队和安全团队协同解决关键安全问题。

# 业务接入引擎
业务接入引擎是平台的核心连接层，负责适配各种容器运行时和云原生环境，实现无缝集成与安全监控。

从架构图可见，该引擎支持多种容器技术生态，包括 Docker、ContainerD、CRI-O、PodMan 和 Harbor 等主流容器运行时和镜像仓库。这种广泛的兼容性，无论其底层技术栈如何，均能够确保了平台能够覆盖企业中几乎所有的容器化工作负载。

在云原生环境方面，该引擎通过专门的适配器支持多云部署模式，包括:
1. 公有云环境：如阿里云、华为云、腾讯云等主流云服务提供商；
2. 私有云环境：支持 Kubernetes、OpenShift、OpenStack 等私有云平台；
3. 混合云环境：能够跨越多个云平台提供统一的安全管理视图。

底层技术上，该引擎采用了轻量级的事件收集和代理架构，通过 API 接口实时获取容器运行状态、网络流量和系统调用等数据。它使用了高效的数据处理管道，确保在不显著影响应用性能的前提下实现全面的安全监控。引擎还实现了与基础设施层的深度集成，支持 K3S、 Kubernetes 和 Docker 等不同的容器编排和运行环境，能够适应从边缘计算到大规模集群的各种部署场景。

通过这种设计，业务接入引擎成为了连接云原生基础设施和安全能力的关键桥梁，实现了"一次部署，全栈防护"的安全理念。


# 产品形态
## Docker 一键安装版本
采用Docker容器化技术与Docker Compose编排工具进行部署，实现了高效、一致且可复制的部署流程。每个技术组件（PostgreSQL、Traefik、Nginx、Redis等）被封装在独立容器中，确保了环境隔离和资源管控。

通过Docker Compose配置文件定义服务间的依赖关系，系统可一键启动或停止，大幅简化了复杂多语言架构的部署难度。这种架构具备显著优势：环境一致性保证，消除了设备本身差异带来的维护问题；便捷的水平扩展能力；易于维护和版本控制；支持微服务架构；降低基础设施管理成本；加速开发、测试和生产环境间的交付流程。

## 集群版本(K8s版)
采用 Kubernetes 容器编排技术与 Helm 模板化部署能力进行部署，面向多节点、高可用和规模化运行场景。系统各核心服务以 Deployment、Service、ConfigMap、Secret 等 Kubernetes 资源形式运行，PostgreSQL、Redis、Traefik、Nginx、后端 API、gRPC 服务、协调服务等组件可在集群内统一编排、调度和管理。

通过 Helm Chart 定义服务配置、镜像版本、网络暴露、证书、存储与依赖关系，平台可实现标准化安装、升级和回滚，显著降低复杂私有化环境下的交付和运维成本。该版本适合企业级生产部署，具备更好的弹性扩展、故障自愈、滚动升级、资源隔离和统一运维能力。

在集群安全能力方面，平台支持 Kubernetes / OpenShift 集群接入，可通过集群连接组件完成资产采集、状态同步和安全事件上报，覆盖集群资产盘点、节点与 Pod 识别、工作负载管理、镜像风险、基础设施漏洞、配置基线、编排文件风险、日志审计、准入控制、微隔离和网络关系分析等能力，形成从集群接入、资产发现、风险检测到响应治理的完整闭环。
