# Web框架

平台支持主动对应用中的 Web 框架进行资产清点，可清点容器内的 Web 框架信息并进行集中展示，包括所在容器信息、服务类型 、框架路径等。

点击【资产清点 / Web 框架】进入 Web 框架资产页面，此页面列表展示探针实时获取的资产详情。依据框架名、框架语言、服务类型、容器信息、发现时间进行具体Web框架资产区分。

![](../../../images/product-features/upload_509e23893aaaef24fad9e957913ff1db.png)

点击【框架名】可进入 Web 框架资产详情页面，详情包括以下模块：框架信息、容器信息、Pod 信息、主机信息、集群信息。框架信息提供框架名、框架语言、服务类型、发现时间、框架版本、框架路径等信息。点击【容器名称】、【Pod 名称】、【节点名称】、【所属集群】均可跳转至对应模块查看详细信息。
