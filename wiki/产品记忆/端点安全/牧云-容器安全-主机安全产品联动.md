# 主机安全产品联动

容器安全平台支持与主机安全产品进行联动，完成联动相关配置后，可对主机安全产品和容器安全产品实现统一认证和管理。

在容器管理平台【用户中心-API Token】使用已有或新建管理员API Token。

在主机安全产品的【其他系统设置】模块中，点击【容器安全产品联动】右侧编辑按钮，进入配置编辑界面。

填写需要联动的容器安全平台地址和管理员 API Token 信息，确认信息无误后进行保存。注意：主机安全平台与容器安全平台必须能够互相访问，否则无法成功配置联动管理。

![](../../images/product-features/upload_12b7ec6760a1e7c3c5ff9d89f192a9c8.png)

当在后台成功配置好【容器安全产品联动】后，在主机安全平台的「用户详情」和「账号信息」中将会增加【容器安全平台认证集成】配置。使用者需要先点击【容器安全平台认证集成】旁的编辑按钮，打开编辑侧弹窗完成容器安全用户 API Token 添加。

![](../../images/product-features/upload_25852fc5dca88fb4eba4c00abec1c65c.png)

![](../../images/product-features/upload_0b7320382513d2557a31b4ad47eea167.png)

与此同时，菜单栏将展示主机安全 / 容器安全产品切换组件。为主机安全账号添加好容器安全用户API Token后，点击下拉中的【容器安全】选项，主机安全账号能直接免登录跳转到容器产品中进行操作。在容器产品中的权限，与该主机安全账号配置的容器安全用户 API Token 相关。

![](../../images/product-features/upload_2f15af41a214e0491d0385e1149cb7c0.png)

在统一认证和管理场景下，主机探针和容器探针在同一台机器上可做到兼容和便捷安装。已经安装了主机安全探针的服务器，可通过主机安全探针管理界面，扩展安装容器安全探针，并对扩展安装的容器安全探针进行管理。

当在主机安全管理平台后台成功配置好【容器安全产品联动】后，主机探针管理列表将增加【容器安全探针管理】操作和相关字段。

选中已经安装了主机安全探针的机器，点击【安装探针】将进行容器安全探针的扩展安装。容器安全探针扩展安装后，列表中会展示容器安全探针的状态和版本信息，点击 【卸载探针】对容器探针进行卸载。更新探针操作类似。
