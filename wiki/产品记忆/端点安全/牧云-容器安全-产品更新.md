# 产品更新

为方便用户部署更新，设置产品更新页面进行平台版本管理。页面包含当前产品信息、更新历史表单两个模块。

当前产品信息包含产品名称、是否支持融合、服务端版本、集群安装包版本、探针端版本和漏洞引擎版本 6 个基础信息。融合是指，如果不支持与主机安全产品融合，容器探针和主机探针则可独立安装，共存于同一设备上而不冲突。如果支持融合，两种探针会共享安装目录和名称，需要先配置 API Token 联动，否则在同一设备上安装两种探针将导致冲突。

版本历史表单包含更新包版本、类型、上传时间、状态和相关操作。

![](../../../images/product-features/upload_9b1e8d0f1988048e4e7c49a8dcaf9226.png)

点击页面右上角【上传更新包】，即可对平台进行版本更新。
