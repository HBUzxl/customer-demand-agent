## 基本原理和模块

不同于普通蜜罐，虚拟机蜜罐基于libvirt创建虚拟机。

在 vm_domain 中，运行了 libvirt 和 api服务，供管理平台操作虚拟机。

```yaml
vm-manager:
  image: vm_domain:v2.0
  container_name: vm_domain
  restart: always
  cap_drop:
    - NET_RAW
  network_mode: "host"
  logging:
    driver: "json-file"
    options:
      max-size: "200M"
  volumes:
    - "/data/libvirt/images:/var/lib/libvirt/images"
    - "/var/lib/vm_manager2/:/var/lib/vm_manager/"
    - "/var/run//libvirt/:/var/run//libvirt/"
    - "./logs/vm_manager:/vm_manager/logs"
  devices:
    - "/dev/kvm:/dev/kvm"
  privileged: true
  cpus: 0.5
```

vm_domain 容器和宿主机共享网络空间，因此libvirt可以看到蜜网（docker网桥），创建虚拟机时，可以将虚拟机网卡连在docker网桥上，从而达到联入蜜网的效果。

但是libvirt无法像docker那样自动给容器分配IP，因此需要管理平台随机网段内的IP地址，生成iso文件，在虚拟机启动时加载。同时虚拟机内部有开机自启动的进程Tarsius，读取iso文件，给网卡配置IP，从而真正连入蜜网。

## 调试方法

虚拟机蜜罐比起docker蜜罐调试困难很多。

若要查看虚拟机状态，可以用virsh命令，类似于查看容器用docker命令。

```bash
docker exec -it vm_domain bash
virsh
list --all        # 查看虚拟机状态
start XXXX        # 启动虚拟机
suspend XXXX      # 暂停虚拟机
resume XXXX       # 恢复虚拟机
quit              # 退出

cat /var/log/libvirt/qemu/XXXX.log  # 查看某个虚拟机的log
```

可以用list命令查看虚拟机状态，如果是running说明正在运行。如果是paused说明被暂停了，可以用resume恢复。

但是有时虚拟机状态已经是running了，绑定服务仍然失败。此时用virsh也无法看出问题。

需要安装virt-manager，并且个人电脑需要能ssh到谛听管理平台，这样才能通过virt-manager进入虚拟机。

### 安装virt-manager

* mac 10:

  ```bash
  brew tap jeffreywildman/homebrew-virt-manager
  brew install virt-manager
  # 安装出错的话，在这里找解决方法：https://github.com/jeffreywildman/homebrew-virt-manager
  ```

* mac 11:

  ```bash
  brew tap Krish-sysadmin/homebrew-virt-manager
  brew install virt-manager
  ```

#### 修改docker-compose.yml

需要访问到libvirt-sock

```bash
vim /data/d-sensor/docker-compose.yml
```

将 `/var/run/libvirt/` 路径添加到 mount 路径：

```yaml
volumes:
  - "/data/libvirt/images:/var/lib/libvirt/images"
  - "/var/lib/vm_manager2/:/var/lib/vm_manager/"
  - "/var/run//libvirt/:/var/run//libvirt/"
  - "./logs/vm_manager:/vm_manager/logs"
```

重启容器：

```bash
docker-compose up -d
```

重启后虚拟机蜜罐会被关闭，需要在管理界面重置虚拟机蜜罐。

在mac上执行：

```bash
virt-manager -c 'qemu+ssh://root@${IP}/system?socket=/var/run/libvirt/libvirt-sock'
```

可以看到virt-manager界面，从这里登陆进入虚拟机。然后可以看网络配置是否正常。
