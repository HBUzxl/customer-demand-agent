# 用户中心

点击系统页面右上角标志，进入 “用户中心”。

![](../../images/product-features/upload_29991f1af04ab9e0fa3a9c2dec499fde.png)

## 修改密码

点击 “修改密码” 按钮，在弹窗中输入当前账号旧密码和新密码进行确认，完成修改密码操作。

![](../../images/product-features/upload_18f313c0fead493b8c807e24e5524b74.png)

![](../../images/product-features/upload_ff3ced06efa93d352b8ff2943be4de8b.png)

## API Token

点击 “API Token” 按钮，进入 API Token 管理页面。

![](../../images/product-features/upload_9573efc6e3db8b1356a94c77251c2276.png)

支持用户自定义添加 API Token，集中展示已添加的 Token 状态、Token 名称、Token、备注、过期时间信息。同时可对 Token 进行启用、禁用、删除、编辑、筛选等管理操作。

![](../../images/product-features/upload_9b9e201a049b283cd9dce82e15e66297.png)

点击页面右上角 “添加 API Token” 按钮，打开弹窗填写 Token 名称和备注，选择过期时间和配置权限，并设置访问规则。

![](../../images/product-features/upload_e04f3df5fb45c3378a571c26efa56b7d.png)

保存填写的信息后，成功生成 Token。此时需要及时保存 Token，考虑到安全性，后续将无法再次查看 Token 的具体内容。

![](../../images/product-features/upload_496467b31c4895ee403ecf77336d2584.png)
