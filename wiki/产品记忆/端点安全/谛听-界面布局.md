# 系统界面布局介绍

## 导航栏区域

![系统界面布局](images/upload_807d875f01f0fb9324f1dff018f0f2d3.png)

<center>图3.1-1 系统界面布局</center>

产品界面左侧为菜单导航栏，顶部为面包屑和功能区。

左侧导航栏包括 7 个一级菜单，分别为：

- **统计分析**：提供历史和实时入侵统计数据，整体把控内网中的入侵数据
- **威胁日志**：提供完整入侵记录，可查找、下载，并对入侵进行溯源
- **蜜罐管理**：对蜜罐进行配置
- **探针管理**：对探针进行配置
- **用户管理**：对系统用户进行管理
- **系统配置**：对谛听管理系统进行配置
- **系统信息**：对谛听管理系统信息进行查看

## 面包屑区域

所有页面均包含面包屑。面包屑分为左右两侧，左侧为当前页面归属的一级菜单，右侧为当前页面菜单名。

<center>图3.3-2 威胁告警通知</center>

![系统负载过高通知](images/upload_ee0239ca9380f75b204adc9d0e39d96e.png)

<center>图3.3-3 系统负载过高通知</center>

![探针状态异常通知](images/upload_48457c664cb6a851ef2b5d23d824c8d5.png)

### 告警提示音

![告警提示音](images/upload_2771499a3b78a644e20ee3e6252acce2.png)

<center>图3.3-6 告警提示音</center>

开启时，Web 页面会播放告警提示音。

提示音只有开启通知弹窗时才能开启，可以选择关闭。

![告警中心入口](images/upload_c94aca5a0f16ad167097cc7dbc9fffc3.png)

<center>图3.3-7 告警中心入口</center>

![告警中心-告警处置弹窗](images/upload_ce9211354555526de7954d3c98ff9d14.png)

<center>图3.3-9 告警中心-告警处置弹窗</center>

除此之外，告警列表可以对告警信息进行排序和筛选，如下图所示，点击进行操作即可。

![告警中心-排序与筛选](images/upload_3e55685d3d33488112828bb1d558a126.png)

<center>图3.3-10 告警中心-排序与筛选</center>

### 产品配置向导

![产品配置向导](images/upload_cf5a94a7c9f81aa332a8bafe79d27b51.png)

<center>图3.3-11 产品配置向导</center>

顶部功能区的问号为产品配置向导标识，帮助用户快速了解产品功能并完成配置。

点击该标识，可展示支持演示的配置项，包括蜜网配置、蜜罐配置、探针配置、探针服务配置，点击配置项名称，可快速跳转对应页面并展示配置步骤。

![产品配置向导-配置步骤引导](images/upload_d344074a5a9cef2b9c1ea2f1a460acae.png)

<center>图3.3-12 产品配置向导-配置步骤引导</center>

配置步骤引导弹窗包含配置项标题、步骤提示、配置步骤进度、跳过按钮以及下一步按钮。

![产品配置向导-配置步骤进度](images/upload_9180b48ef508fdf668c30c771889b5b6.png)

<center>图3.3-13 产品配置向导-配置步骤进度</center>

点击下一步按钮，即可展示接下来的配置步骤。

点击弹窗左下角配置步骤进度的圆点，可以快速跳转至对应步骤。

点击跳过按钮，即关闭该配置项的引导，后续步骤不再展示。

### 个人中心与登出

![个人中心](images/upload_6f65b47ded43815272cfec8752f0a219.png)

账户区域显示的是当前账号，包含"个人中心"和"登出系统"。

点击"个人中心"，可查看用户信息：

- **登录选项**：可配置用户的登录相关设置
- **Open API**：可依据 API Token 对谛听管理系统部分功能进行自动化操作

![个人中心页面](images/upload_a935b45fb67323cc11712994c20d9301.png)

<center>图3.3-14 个人中心</center>

点击"登出系统"，则当前用户账号被登出，继续使用需再次登录。

另外，用户可以在 个人中心 -> 登录选项 -> 二步验证 处开启二步验证。开启前，保证谛听设备的时间准确。开启时，需要扫描弹窗中展示的二维码，将二步验证的密钥记录下来，妥善保存（例如录入到手机上的二步验证 APP）。开启后，在用户登录时，需要在密码或证书登录后，再使用之前记录的二步验证密钥，进行一次6位数字的动态密码认证（一般手机上的二步验证 APP 会自动计算出来）。
