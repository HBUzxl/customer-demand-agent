# 合规基线

**使用此功能需要先前往任务计划模块创建对应的基线扫描任务。**

牧云·云原生安全平台提供合规基线功能，基于 CIS Benchmark 官方标准提供上百条基线检查项，覆盖容器、镜像、主机等多个维度，对业务系统所在容器、集群以及容器原镜像进行合规检测，以防止不安全的配置导致容器逃逸或者集群入侵事件。检查完成后即可前往【合规基线】页面查看扫描结果。

- Docker CIS 基线 1.1 ：适用于 Docker 17.06 版本
- Kubernetes CIS 基线 1.6 ：适用于集群 1.16-1.18 版本

切换左侧基线类型即可查看对应的基线检查项扫描结果，列表展示对应检查项名称和分类，并统计当前检查资产的通过率，点击检查项名称即可前往详情页面查看检查详情信息。

![](../../../images/product-features/upload_4eb4d221f47c95113468ae6d812cf515.png)


点击【检查项名称】进入检查项详情，详情提供【检查项描述】【修复建议】【检查方法】等信息，并关联所有检查过的资产对象、检查时间和检查结果是否通过，支持点击对应的资产名称查看已有资产的详细信息。
