# 鉴微漏洞风险管理平台 — 产品介绍

## 一、产品概述

**鉴微（Insight）** 是北京长亭科技有限公司自主研发的企业级漏洞风险管理平台。平台以"资产发现 → 漏洞扫描 → 暴露面管理 → 风险优先级排序 → 修复工单 → 报告归档"为主线，覆盖漏洞风险管理的全生命周期，帮助安全团队将海量漏洞数据转化为可度量、可跟踪、可闭环的安全运营动作。

鉴微采用微服务架构，支持私有化部署，已服务于金融、物流、互联网等多个行业的头部客户。

---

## 二、产品定位

鉴微定位为**企业级漏洞风险管理中枢**。与传统的漏洞扫描器不同，鉴微不仅具备自有扫描能力，更核心的价值在于：

- **汇聚归一**：将 Nessus、Xray、SafeLine、Tenable SC、青藤云安全、微步在线等 10+ 第三方安全工具的扫描结果统一接入，打破数据孤岛。
- **智能优先级排序**：基于 VPT（漏洞优先级技术），结合资产价值、漏洞威胁情报、暴露面上下文等多维因素，自动计算漏洞处置优先级，避免安全团队陷入"CVSS 评分通胀"的困境。
- **闭环处置**：通过内置工作流引擎和处置门户，将漏洞从发现、分派、修复到验证的完整流程线上化、可追溯。
- **合规支撑**：提供多维度报告（PDF/Excel）、基线比对、审计日志等能力，满足等级保护、行业监管等合规诉求。

## 三、核心能力
### 3.1 资产管理

支持多维度的 IT 资产统一管理，涵盖：

| 资产类型 | 管理能力 |
|---------|---------|
| **IP 资产** | 资产录入、标签管理、归属组织、联系人关联 |
| **域名资产** | 域名及子域名管理、证书生命周期跟踪 |
| **Web 资产** | Web 站点管理、API 接口资产梳理 |
| **软件组件** | 主机软件/组件清单管理 |
| **资产标签** | 灵活标签体系，支撑资产分类与风险策略关联 |

### 3.2 漏洞管理

- **IP 漏洞**：面向主机/网络层漏洞的统一管理与跟踪
- **Web 漏洞**：面向 Web 应用的漏洞管理，支持自定义漏洞录入与批量导入
- **漏洞标签**：自定义漏洞标签体系，支持多维度分类与筛选
- **VPT（漏洞优先级技术）**：基于资产重要性、漏洞威胁等级、利用活跃度、暴露面等多维因子，智能计算漏洞处置优先级，驱动安全团队聚焦真正高风险项

### 3.3 暴露面管理

- **端口暴露**：对外/对内开放端口的持续监测与清单化管理
- **指纹识别**：服务指纹、组件版本的自动化识别，辅助漏洞影响面分析
- **暴露分析**：风险暴露面的量化评估与变化跟踪

### 3.4 扫描任务管理

- 支持自有扫描引擎及第三方扫描器任务的统一调度
- 扫描列表管理、扫描镜像版本管理
- 任务执行状态跟踪与结果回传

### 3.5 工作流与工单管理

- **自定义工作流引擎**：支持按组织、漏洞类型、严重等级等维度定义差异化处置流程
- **工单生命周期管理**：创建 → 分发 → 处理 → 验证 → 关闭，全流程可追溯
- **飞书/Lark 集成**：工单通知、状态同步实时推送至飞书，降低系统切换成本

### 3.6 处置门户（Dispose）

- **免登录处置**：修复人员无需登录主系统即可查看属于自己的漏洞工单，降低使用门槛
- **独立前端界面**：轻量化处置体验，聚焦修复任务本身

### 3.7 报告与报表

- **多格式输出**：支持 PDF、Excel 等格式的安全报告生成
- **排期报告**：支持按日/周/月自动生成并分发定时报告
- **自定义模板**：满足不同汇报场景（管理层简报、技术细报、合规审计）的模板化输出
- **基线比对**：支持不同时间点/不同组织的安全态势横向与纵向对比

### 3.8 通知与消息

- **多渠道通知**：邮件（SMTP）、钉钉机器人、Syslog
- **策略驱动**：可按漏洞等级、资产范围、时间窗口等维度配置通知策略
- **模板化管理**：通知内容模板化，支持变量替换

### 3.9 知识库

- **漏洞知识库**：内置漏洞描述、修复建议、参考链接等标准知识条目
- **自定义知识库**：支持企业沉淀自身的安全知识资产，形成私有知识库

### 3.10 第三方集成

鉴微具备广泛的第三方安全工具集成能力：

| 集成工具 | 集成方式 | 用途 |
|---------|---------|------|
| Tenable Nessus / SC | 同步适配器 | 漏洞扫描结果汇聚 |
| Xray | 同步适配器 | Web 漏洞扫描结果汇聚 |
| 长亭 SafeLine | 同步适配器 | WAF/API 安全事件联动 |
| 青藤云安全 | 同步适配器 | 主机安全告警汇聚 |
| RSA SecurID | 同步适配器 | 身份认证集成 |
| 微步在线 ThreatBook | 同步适配器 | 威胁情报消费 |
| Cloud Walker | 同步适配器 | 云资产安全数据汇聚 |
| 攻击面管理（ASM） | 同步适配器 | 攻击面数据同步 |

### 3.11 系统管理

- **认证与授权**：支持 LDAP、OIDC/OAuth、TOTP 双因素认证
- **RBAC 权限模型**：角色、用户、组织多层级权限控制
- **许可证管理**：License 激活、续期与用量监控
- **SSO 单点登录**：支持与企业统一身份认证系统对接
- **审计日志**：全平台操作审计记录，满足合规追溯要求
- **系统监控**：服务健康状态、资源用量的可视化监控

### 3.12 数据管理

- **数据导入**：支持 DOCX、XLSX 等格式的漏洞/资产数据批量导入
- **数据导出**：提供 JWT 认证的安全数据导出 API
- **自定义数据字段**：支持按企业需求扩展数据模型字段

### 3.13 网络拓扑

- 基于图形化的网络拓扑可视化（Netmap）
- 展示资产之间的网络连接关系与风险传导路径

### 3.14 全文搜索

- 基于 Xapian 搜索引擎的全文检索
- 支持跨资产、跨漏洞类别的快速检索

### 3.15 运维管理

- **Operator 服务**：支持系统升级、补丁管理和运维操作
- **Docker UI**：提供基于 Web 的 Docker 容器/镜像管理界面

## 四、适用场景

### 4.1 大中型企业漏洞管理体系建设

企业安全团队面临多源扫描器、海量漏洞、有限修复资源的矛盾。鉴微提供从"发现"到"闭环"的完整管理框架，帮助建立规范化的漏洞管理流程。

### 4.2 多扫描器结果统一汇聚与优先级排序

当企业同时使用 Nessus、Xray、主机安全、云安全等多种工具时，鉴微作为统一汇聚平台，将分散的漏洞数据归一化处理后，通过 VPT 智能排序，让安全团队聚焦真正高风险的漏洞。

### 4.3 安全合规与审计

金融、运营商等受强监管行业需要满足等级保护、行业监管对漏洞管理的合规要求。鉴微提供标准的审计日志、多维度报告和基线比对能力，支撑合规审查。

### 4.4 安全运营中心（SOC）支撑

作为 SOC 的核心组件，鉴微提供仪表盘、趋势分析、工单统计等运营视角，帮助安全运营团队量化工作成效、持续改进安全态势。

### 4.5 DevSecOps 集成

通过 SAST 能力和开放 API，鉴微可嵌入 DevOps 流水线，实现代码提交阶段的自动安全检测，推动安全左移。

### 4.6 安全服务提供商（MSSP）交付

多组织管理、RBAC 权限模型和独立处置门户使鉴微适合 MSSP 为多个客户提供漏洞管理服务。

## 六、主要价值

### 6.1 效率提升：从"人找漏洞"到"漏洞找人"

通过多源数据汇聚、智能优先级排序和自动化工单路由，将安全团队从手工汇总、逐条研判的低效工作中解放出来，让高风险漏洞自动推送到正确的人手中。

### 6.2 风险可见：从"一团漆黑"到"全局可视"

仪表盘、VPT 排序、趋势分析和网络拓扑等能力，让安全管理者和运营团队对企业的安全风险全貌一目了然，支持数据驱动的决策。

### 6.3 闭环管理：从"发现即结束"到"修复才闭环"

内置的工作流引擎和处置门户将漏洞管理从单纯"发现问题"延伸到"分派→修复→验证→归档"的完整闭环，每个漏洞的处理过程可追溯、可度量。

### 6.4 生态兼容：从"工具孤岛"到"数据融合"

10+ 第三方安全工具的集成适配器，让企业已有的安全投资（Nessus、Xray、主机安全等）成为鉴微的数据源而非孤立的烟囱，最大化存量工具的 ROI。

### 6.5 合规支撑：从"突击准备"到"常态合规"

审计日志、多维度报告、基线比对等能力，让安全合规从被动突击变为常态化的过程管理，从容应对各类监管检查。

### 6.6 持续运营：从"静态扫描"到"动态运营"

暴露面持续监测、定时报告排期、统计分析等能力，支持安全团队建立持续改进的运营节奏，而非一次性扫描的静态工作方式。

## 七、产品部署

鉴微采用**私有化部署**方式，支持在客户自有数据中心或私有云环境中安装运行：

- **部署架构**：基于 Docker Compose 的容器化部署
- **统一入口**：Tengine（基于 Nginx 的反向代理）提供 HTTP/HTTPS 统一访问
- **服务编排**：通过 Taskfile + Docker Compose 管理服务生命周期
- **平台支持**：`linux/amd64`，`linux/arm64` 多架构镜像
- **管理工具**：提供 Operator 运维服务进行系统升级与补丁管理

## 八、总结

鉴微漏洞风险管理平台是一款面向企业安全团队的成熟产品，它**不是又一个漏洞扫描器**，而是帮助企业将"扫描结果"转化为"安全成果"的管理中枢。通过资产全景、漏洞汇聚、智能排序、工单闭环、合规报告五大能力支柱，鉴微帮助安全团队实现从被动响应到主动运营的跨越。
