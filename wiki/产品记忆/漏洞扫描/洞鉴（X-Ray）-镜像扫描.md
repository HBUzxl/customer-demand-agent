# 镜像扫描

镜像扫描针对容器镜像内的软件包和依赖进行漏洞检测。与远程扫描的检测视角不同，适合检测组织内部构建应用的风险情况。

## 镜像扫描任务列表


镜像任务列表集中展示任务的名称、类型、状态、风险结果等信息。

![](../images/镜像扫描.png)


## 创建镜像扫描任务

点击镜像任务列表右上角 “添加扫描任务” 即可添加新任务：


![](../images/upload_3742d9aea1bb1b4ea515b64d52dae683.png)


镜像扫描任务分为以下两种类型（创建任务后无法切换）：

* **上传本地镜像扫描**：
    * 直接上传本地镜像 TAR 文件，适用于离线环境或临时扫描本地构建镜像。支持 Docker 标准 TAR 格式，上传后系统将自动解析镜像层次结构，检测操作系统漏洞、应用程序漏洞和配置风险。扫描过程中会分析镜像的文件系统、已安装软件包及其版本信息。
* **访问远程仓库扫描**：
    * 访问远程仓库以获取镜像，多个目标镜像的扫描，可以一次性扫描整个仓库或项目
    * 支持仓库类型 Docker Registry V2、Harbor、JFrog，要求管理节点能够访问仓库地址


## 镜像扫描任务详情

点击镜像扫描任务列表上的任务，即可打开任务详情：

![](../images/upload_ee255fcd8f90db75e9cab5063578be63.png)

镜像扫描任务详情展示任务进度、时间、扫出镜像、扫出漏洞等。
