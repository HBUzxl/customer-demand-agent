# 鉴微（Insight）风险分析与运营管理平台产品使用手册


## 1. 关于产品

### 1.1 产品定位

鉴微（Insight）风险分析与运营管理平台面向企业漏洞风险运营场景，围绕资产、漏洞、检测、工单、报告和配置能力，帮助安全团队完成多源漏洞数据接入、资产风险关联、漏洞优先级评估、闭环处置、运营统计和审计追踪。

平台支持通过扫描器、同步任务、手动录入、批量导入、第三方集成等方式汇聚资产与漏洞数据，并通过 VPT 优先级、工单流转、通知策略和报告能力支撑风险治理闭环。

### 1.2 主要能力

- **可视化运营**：展示资产、漏洞、工单、任务等运营指标，支持仪表盘、数据对比和工单运营报表。
- **资产中心**：管理主机、Web、主域名、子域名、API、证书、主机软件、资产标签、业务系统和资产图谱。
- **风险管理**：管理 IP 漏洞、Web 漏洞、漏洞标签、漏洞知识库、漏洞情报库、风险排查、基线风险和开发安全风险。
- **检测管理**：管理扫描检测任务、数据同步任务、接入设备和镜像。
- **工单中心**：通过流程模板、全部工单、我的工单和工单配置实现风险闭环处置。
- **报告中心**：管理报告任务、报告模板、报告资料和报告下载。
- **配置中心**：配置 VPT、数据治理、用户权限、可视化配置、数据字段、通知、数据导入、日志、容器和系统参数。

### 1.3 初始化与登录

1. 平台安装部署完成后，使用管理员账号登录。
2. 进入系统后上传并激活 License。
3. 使用初始管理员账号完成首次登录，按要求修改密码或补全个人信息。
4. 根据实际组织结构创建组织、用户和角色，配置数据访问范围。
5. 根据需要接入扫描器、导入资产/漏洞数据、配置通知和工单模板。

- 查看或维护个人信息。

平台菜单可见性同时受 **License 版本、角色权限、管理员类型、系统配置** 控制。

| 控制项 | 影响 |

| 基础版 License | 不显示工单中心、资产暴露面、证书资产、API 资产、资产图谱、基线风险、风险排查 |

## 3. 功能模块说明

## 3.1 可视化

### 3.1.1 可视化仪表盘

可视化仪表盘用于集中展示资产、漏洞、工单、任务等运营指标。用户可根据权限查看所在组织及下级组织相关数据。

常见展示内容包括：

- 资产总量、主机资产、Web 资产、域名资产、端口、软件/服务等资产指标。
- 漏洞总量、待处理、确认中、修复中、待复测、误报、忽略、已修复等漏洞指标。
- 漏洞等级分布、漏洞变化趋势、已修复趋势、风险资产排行等图表。
- 工单创建趋势、工单状态、闭环率、任务执行情况等运营图表。

### 3.1.2 数据对比

数据对比用于对不同时段的漏洞或运营数据进行横向比较，辅助评估风险收敛效果。该入口当前为超级管理员可见。

### 3.1.3 工单运营报表

工单运营报表用于查看工单处理效率和闭环情况，可用于分析待办、已办、逾期、周转时长等工单运营指标。

## 3.2 资产中心

资产中心用于管理平台纳管的各类资产及其状态、负责人、标签、暴露面和关联风险。

### 3.2.1 资产管理

当前资产管理入口包括：

| 资产类型 | 说明 |
|---------|------|
| 主机资产 | 管理 IP、主机名、系统、端口、指纹、主机软件、负责人、组织等信息 |
| Web 资产 | 管理 URL、域名、协议、端口、Web 服务、指纹、关联漏洞等信息 |
| 主域名资产 | 管理主域名、解析记录、备案、Whois、证书、负责人等信息 |
| 子域名资产 | 管理子域名及其关联主域名、解析和资产关系 |
| API 资产 | 管理 API 方法、路径、分组、负责人和关联漏洞等信息 |
| 证书资产 | 管理 SSL/TLS 证书信息、证书状态和到期情况 |

资产页面通常支持 **列表模式** 和 **详情模式**：

- 列表模式：用于筛选、排序、批量选择、批量编辑、下载和查看汇总信息。
- 详情模式：用于查看单个资产的基础信息、关联资产、漏洞、变更记录、指纹、端口、软件等详情。

### 3.2.2 资产状态

资产按管理状态分类，常见状态如下：

| 状态 | 说明 |
|------|------|
| 已纳管 | 需要持续管理风险的资产。纳管资产需要配置负责人 |
| 未纳管 | 尚未分配负责人或尚未纳入风险治理流程的资产 |
| 已排除 | 不参与常规风险治理的资产。排除后关联风险可按规则忽略 |
| 历史资产 | 已下架或不再使用的资产 |

在非证书、非子域名资产中，调整资产状态时可选择是否同步调整关联漏洞状态：

- 资产从已纳管/未纳管改为已排除/历史资产时，可将关联漏洞同步为忽略。
- 资产从已排除/历史资产改为已纳管/未纳管时，可将关联漏洞同步为待处理。

### 3.2.3 资产新建、导入与编辑

常用操作：

1. **新建资产**：在对应资产类型页面点击新建，填写基础信息、组织、负责人等内容后保存。
2. **批量导入**：通过 Excel 文件导入资产数据。导入时按页面提示完成字段映射和组织归属设置。
3. **编辑资产**：可在列表或详情页进入编辑页面，修改资产基础属性。
4. **批量编辑**：选择当前页或全量筛选结果后，批量调整资产状态、负责人、其他负责人和备注。
5. **删除资产**：管理员可删除部分资产类型；具体是否可删除以页面按钮和权限为准。

### 3.2.4 资产筛选与下载

资产列表支持通过顶部筛选条件检索。常见筛选维度包括资产名称/IP/URL、组织机构、负责人、资产状态、标签、端口、协议、风险等级、更新时间等。

下载支持两种方式：

- **下载选中**：下载当前勾选的资产。
- **下载全部**：下载当前筛选条件下的全部资产。

### 3.2.5 资产暴露面

资产暴露面包括：

| 页面 | 说明 |
|------|------|
| 端口服务 | 查看开放端口、协议和服务暴露情况 |
| 网站指纹 | 查看 Web 服务、框架、中间件等指纹信息 |

该能力受 License 控制，部分版本不显示。

### 3.2.6 主机软件

主机软件用于查看主机安装的软件和组件清单，可用于结合 CPE、版本信息和漏洞知识库判断受影响资产。

### 3.2.7 资产标签

资产标签用于给不同类型资产添加自定义分类标识。标签可用于资产筛选、资产运营分析和 VPT 评分权重配置。

### 3.2.8 业务系统

业务系统用于将资产按业务系统归类，便于按系统维度统计风险、分配负责人和推进治理。

### 3.2.9 资产图谱

资产图谱用于展示资产之间的网络连接或拓扑关系。该入口当前为超级管理员可见，并受 License 控制。

## 3.3 风险管理

风险管理用于管理漏洞、基线风险、漏洞知识、漏洞情报和开发安全风险。

### 3.3.1 漏洞列表

漏洞列表包括：

| 类型 | 说明 |
|------|------|
| IP 漏洞 | 管理主机/IP 维度的漏洞 |
| Web 漏洞 | 管理网站、URL、Web 应用维度的漏洞 |

漏洞列表支持列表与详情查看。列表中可按漏洞名称、编号、等级、状态、资产、组织、负责人、标签、发现时间、更新时间等维度筛选。

漏洞状态包括：

| 状态 | 说明 |
|------|------|
| 待处理 | 新发现或待分派处理的漏洞 |
| 确认中 | 正在确认漏洞真实性或影响范围 |
| 修复中 | 已确认并进入修复过程 |
| 待复测 | 修复完成，等待验证或复测 |
| 误报 | 经确认不构成真实风险 |
| 忽略 | 因业务原因暂不处理或排除 |
| 已修复 | 已完成修复并验证通过 |

### 3.3.2 漏洞处置

漏洞处置支持单个或批量操作。常用操作包括：

- 调整漏洞状态。
- 填写处置备注。
- 标记误报或忽略。
- 标记已修复，并可填写修复措施。
- 从漏洞列表发起聚合工单。
- 发送漏洞通知邮件。
- 导出漏洞数据。
- 对 IP/Web 漏洞进行再次扫描或复测相关操作（以页面按钮为准）。

### 3.3.3 漏洞详情

漏洞详情通常包含：

- 漏洞概要、等级、编号、CVE/CWE、类型、发现时间等基础信息。
- 漏洞描述、危害、修复建议、修复过程记录。
- 关联资产、组织、负责人、标签、VPT 优先级。
- 关联工单和处置历史。

### 3.3.4 漏洞标签

漏洞标签用于给漏洞添加业务或治理分类，例如重点漏洞、专项漏洞、红线漏洞等。标签可用于筛选和 VPT 权重配置。

### 3.3.5 漏洞知识库

漏洞知识库用于查看标准漏洞知识条目，通常包含漏洞名称、编号、等级、描述、危害、修复建议、公开时间、PoC/EXP、受影响版本等信息。

用户可按漏洞名称、编号、等级、产品等维度检索知识库。部分知识库条目支持在平台内定制或补充。

### 3.3.6 漏洞情报库

漏洞情报库用于维护平台侧的风险情报信息。情报字段可包含是否有 PoC、是否有 EXP、是否已有补丁、是否存在大规模利用等，并参与 VPT 风险优先级计算。

常用操作包括新增、编辑、删除、检索、批量导入，以及从知识库复制条目到情报库。

### 3.3.7 风险排查

风险排查用于围绕高危产品、情报或特定风险条件定位受影响资产。可按产品、服务、CPE、版本等条件匹配资产库中的软件或组件，形成排查结果。

该能力受 License 控制，部分版本不显示。

### 3.3.8 基线风险

基线风险用于管理主机或系统配置合规检查发现的问题。基线风险通常来源于扫描器或同步任务，不完全等同于漏洞工单流程，具体处置方式以页面能力为准。

该能力受 License 控制，部分版本不显示。

### 3.3.9 开发安全风险（SAST）

开发安全风险为嵌入式 SAST 子应用，包含：

- 迭代管理。
- 风险列表。
- 对接配置。

该模块需系统配置启用后才显示对应入口。

## 3.4 检测管理

检测管理用于创建扫描任务、同步任务，接入扫描设备并管理镜像。

### 3.4.1 任务列表

任务列表包含两类任务：

| 类型 | 说明 |
|------|------|
| 扫描检测任务 | 由平台发起扫描，配置目标、策略、设备等信息后下发执行 |
| 数据同步任务 | 从外部扫描器或数据源拉取资产、漏洞、基线等数据 |

常用操作：

1. 点击「检测管理」→「任务列表」。
2. 在扫描检测任务或数据同步任务之间切换。
3. 点击新建，填写任务名称、组织、目标、设备、参数、执行周期等配置。
4. 保存后等待任务执行或手动触发执行。
5. 查看任务执行记录、状态和结果。

扫描检测任务还支持接管扫描端已有任务。接管时需选择扫描器，拉取任务后选择需要接管的任务，并配置所属组织等信息。

### 3.4.2 接入列表

接入列表用于管理扫描设备。常用操作包括：

| 操作 | 说明 |
|------|------|
| 新建 | 新建扫描设备，可从已有镜像或上传镜像创建 |
| 查看 | 查看设备配置和详情 |
| 启动/停止 | 控制设备对应容器运行状态 |
| 映射 | 配置扫描器组织、范围与平台组织/安全域的映射关系 |
| 编辑 | 修改扫描设备参数 |
| 删除 | 删除扫描设备 |

### 3.4.3 镜像管理

镜像管理用于查看和上传扫描设备所需的 Docker 镜像。用户可上传镜像文件，并在接入设备时选择对应镜像创建扫描器容器。

## 3.5 工单中心

工单中心用于将漏洞或资产风险转化为可跟踪的处置流程，实现分派、执行、审批、复测、关闭和审计。

### 3.5.1 流程模板

流程模板用于定义工单的节点、表单、执行人、流转规则和处置策略。当前入口为超级管理员可见。

常见能力：

- 查看模板列表。
- 新建或编辑模板。
- 启用、停用或校验模板。
- 预览流程图。
- 配置执行人、审批人、节点表单和流转条件。

### 3.5.2 全部工单

全部工单用于查看系统范围内的工单，支持筛选、搜索、查看详情和批量操作。该页面用于管理员或有权限用户进行全局工单跟踪。

### 3.5.3 我的工单

我的工单用于当前登录用户处理与自己相关的工单，通常包括：

| 分类 | 说明 |
|------|------|
| 待处理 | 当前用户需要处理的节点或工单 |
| 我创建 | 当前用户创建的工单 |
| 抄送给我 | 当前用户被抄送的工单 |
| 已处理 | 当前用户已处理过的工单 |

在工单详情中，用户可查看基础信息、关联风险、处理历史、附件、评论和当前节点待填写内容。

### 3.5.4 工单创建

工单可从漏洞详情、漏洞列表或批量操作中发起。当前实现支持聚合创建和多用户创建等场景。

创建流程通常为：

1. 选择风险或漏洞数据。
2. 选择流程模板。
3. 填写工单标题、优先级、截止时间、说明等基础信息。
4. 选择执行用户或由模板规则自动匹配执行人。
5. 提交后生成工单，并与漏洞或资产建立关联。

### 3.5.5 工单操作

工单详情页根据当前节点和模板配置展示可用操作，常见操作包括：

| 操作 | 说明 |
|------|------|
| 提交/同意 | 完成当前节点并推进流程 |
| 驳回 | 将流程退回到指定节点 |
| 转派 | 将当前节点转给其他用户处理 |
| 关闭 | 结束工单 |
| 延期 | 申请或处理延期 |
| 加签 | 在流程前后增加审核或处理人员 |
| 委派 | 委派他人协助处理 |
| 催办 | 提醒当前处理人处理 |
| 拆单/升级 | 按模板或集成场景进行拆分、升级处理 |

### 3.5.6 工单配置

工单配置用于配置全局工单策略、外部集成、通知、同步等能力。当前入口为超级管理员可见。

平台当前包含多类客户 ITSM 集成和通知配置能力，具体可配置项以页面展示为准。

## 3.6 报告中心

报告中心用于生成、管理和下载安全运营报告。

### 3.6.1 报告任务

报告任务由报告微应用提供，当前入口为超级管理员可见。用户可创建周期或临时报告任务，配置统计范围、报告内容、接收人和执行时间。

### 3.6.2 报告模板

报告模板由报告微应用提供，当前入口为超级管理员可见。用户可创建、编辑、导入、导出和管理报告模板。

### 3.6.3 报告资料

报告资料用于查看和管理已生成的报告文件。常用操作包括查看、下载、删除等。报告内容可基于资产、漏洞、统计图表和运营数据生成。

### 3.6.4 报告下载

报告下载用于集中下载已生成的报告文件或导出结果。具体支持格式以页面和报告服务配置为准，常见格式包括 Word、PDF、HTML 等。

## 3.7 配置中心

配置中心用于管理平台级配置、权限、数据治理、通知、导入、日志和系统运维能力。

### 3.7.1 VPT

VPT 用于对漏洞风险处置优先级进行评分和排序。配置项通常包括：

- 资产属性权重：资产重要性、是否外网、资产标签等。
- 漏洞属性权重：漏洞等级、漏洞类型、漏洞标签、知识库标签等。
- 情报属性权重：是否有补丁、是否有 PoC/EXP、是否在野利用等。
- 特殊计分规则：满足特定组合条件时直接指定评分或等级。
- 等级映射：将评分映射为 P0/P1/P2/P3/P4 等处置优先级。

### 3.7.2 数据治理

数据治理用于配置漏洞等级、来源、类型等字段到处置优先级的映射规则。当前入口为超级管理员可见。

### 3.7.3 用户管理

用户管理包括：

| 页面 | 说明 |
|------|------|
| 用户列表 | 创建、编辑、禁用、重置密码、删除用户，维护邮箱、手机号、组织、主管等信息 |
| 角色列表 | 创建、编辑角色并绑定功能权限。当前入口为超级管理员可见 |
| 组织机构 | 维护树形组织结构和组织属性，支撑用户归属和数据访问控制 |

普通用户的数据访问范围通常与所属组织及其下级组织相关；管理员和超级管理员具备更高范围的数据访问能力。

### 3.7.4 可视化配置

可视化配置包括：

| 页面 | 说明 |
|------|------|
| 数据统计 | 配置仪表盘数据统计内容 |
| 仪表盘管理 | 管理仪表盘模块、图表类型、指标和分组 |

支持的图表类型以页面为准，常见包括表格、折线图、柱状图、饼图、指标卡等。

### 3.7.5 数据管理

数据管理用于维护平台数据字段、自定义字段、业务字段展示等配置。该能力影响资产、漏洞等数据列表或表单字段展示。

### 3.7.6 通知管理

通知管理包括：

| 页面 | 说明 |
|------|------|
| 消息提醒 | 配置通知策略，定义触发条件、接收人和通知方式 |
| 通知方式 | 配置邮件、钉钉、Syslog 等通知通道 |
| 通知模板 | 配置漏洞通知、工单通知等消息模板 |

通知方式当前包含邮件 SMTP、钉钉和 Syslog 配置。通知方式支持测试发送和发送记录查看。

### 3.7.7 数据导入

数据导入用于通过文件或数据源批量导入平台数据。当前入口要求管理员权限。

常见导入对象包括：

- 主机资产。
- Web 资产。
- 域名资产。
- IP 漏洞。
- Web 漏洞。
- 漏洞情报或其他模板支持的数据。

基本流程：

1. 选择导入对象和模板。
2. 上传文件或配置数据源。
3. 配置字段映射和覆盖策略。
4. 执行导入。
5. 查看导入结果、成功条数和失败原因。

### 3.7.8 日志管理

日志管理用于查看用户操作审计日志。可按用户名、IP 地址、操作描述、时间等条件筛选。

### 3.7.9 容器监控

容器监控用于查看和管理平台可见范围内的 Docker 容器与镜像。常见能力包括：

- 容器列表和状态查看。
- 容器启动、停止等操作。
- 容器日志查看。
- 容器详情和资源状态查看。
- 镜像列表、镜像上传、镜像删除。

### 3.7.10 系统管理

系统管理用于维护系统级参数、授权许可、SSO 配置和系统监控等内容。当前入口为超级管理员可见。

### 3.7.11 个人中心

个人中心用于用户查看和维护个人信息，包括基础资料、联系方式和密码等。

## 4. 常用操作流程

### 4.1 新增并纳管资产

1. 进入「资产中心」→「资产管理」。
2. 选择资产类型，例如主机资产或 Web 资产。
3. 点击新建或导入。
4. 填写资产基础信息、组织机构和负责人。
5. 将资产状态设置为「已纳管」。
6. 保存后在列表或详情页确认资产信息。

### 4.2 批量调整资产状态

1. 进入对应资产列表。
2. 使用筛选条件定位目标资产。
3. 勾选当前页资产，或选择全量筛选结果。
4. 点击纳管、取消纳管、排除、下架或批量操作。
5. 填写负责人、其他负责人、备注等信息。
6. 如需联动漏洞状态，打开「同步调整漏洞状态」。
7. 保存并等待列表刷新。

### 4.3 处置漏洞

1. 进入「风险管理」→「漏洞列表」→「IP 漏洞」或「Web 漏洞」。
2. 通过筛选条件定位漏洞。
3. 查看漏洞详情，确认影响资产、漏洞等级、修复建议和历史记录。
4. 选择单个或多个漏洞，点击处置。
5. 选择目标状态，填写备注；如状态为已修复，可填写修复措施。
6. 保存后查看状态变更和处置历史。

### 4.4 从漏洞发起工单

1. 在漏洞列表或漏洞详情中选择需要处理的漏洞。
2. 点击创建工单或聚合工单入口。
3. 选择流程模板。
4. 填写工单基础信息和优先级。
5. 选择执行人或使用模板自动匹配规则。
6. 提交工单。
7. 在「工单中心」查看工单流转状态。

### 4.5 创建扫描检测任务

1. 进入「检测管理」→「任务列表」。
2. 选择扫描检测任务。
3. 点击新建。
4. 配置任务名称、扫描目标、扫描设备、参数和执行方式。
5. 保存任务。
6. 在任务记录中查看执行状态和结果。

### 4.6 配置通知方式

1. 进入「配置中心」→「通知管理」→「通知方式」。
2. 选择邮件、钉钉或 Syslog。
3. 填写服务地址、端口、账号、认证方式或机器人配置。
4. 保存配置。
5. 使用测试发送功能确认配置有效。
6. 在发送记录中查看发送结果。

### 4.7 生成报告

1. 进入「报告中心」。
2. 在报告任务中新建周期任务或临时任务。
3. 选择报告模板或配置报告内容。
4. 设置统计范围、组织范围、执行时间和接收人。
5. 保存并执行任务。
6. 在报告资料或报告下载中查看和下载生成结果。

## 5. 常见问题与处理建议

| 问题 | 可能原因 | 处理建议 |
|------|---------|---------|
| 菜单不可见 | License、角色权限、管理员类型或系统配置限制 | 检查 License 版本、用户角色、权限点和 SAST 配置 |
| 资产导入失败 | 模板格式不正确、字段映射错误、组织或负责人不存在 | 使用页面模板重新整理数据，检查失败原因并重新导入 |
| 资产无法纳管 | 缺少负责人或权限不足 | 补充负责人，确认当前用户具备执行权限 |
| 漏洞状态未变化 | 处置失败、权限不足、被工单流程约束 | 查看页面错误提示，检查关联工单和当前用户权限 |
| 工单无法提交 | 表单必填项缺失、模板流转规则不满足 | 补全当前节点表单，检查模板配置 |
| 通知发送失败 | 邮件/钉钉/Syslog 配置错误或接收人信息缺失 | 使用测试发送，检查用户邮箱、机器人地址或 Syslog 地址 |
| 扫描设备离线 | 容器未运行、网络异常、认证配置错误 | 检查接入列表、容器监控、设备配置和网络连通性 |
| 报告无法生成 | 报告任务配置不完整或报告服务异常 | 检查报告任务状态、模板配置和报告服务日志 |

## 6. 附录

### 6.1 漏洞状态速查

| 状态 | 说明 |
|------|------|
| 待处理 | 新发现或待处理漏洞 |
| 确认中 | 正在确认真实性或影响范围 |
| 修复中 | 正在修复 |
| 待复测 | 等待复测验证 |
| 误报 | 已确认不构成真实风险 |
| 忽略 | 暂不处理或排除 |
| 已修复 | 修复完成并验证通过 |

### 6.2 资产状态速查

| 状态 | 说明 |
|------|------|
| 已纳管 | 纳入风险治理流程 |
| 未纳管 | 尚未纳入治理或未分配负责人 |
| 已排除 | 不参与常规治理 |
| 历史资产 | 已下架或历史保留 |

### 6.3 角色说明

| 角色类型 | 说明 |
|---------|------|
| 超级管理员 | 拥有全部菜单和角色管理等最高权限，但仍受 License 和系统配置约束 |
| 管理员 | 拥有大部分管理能力，但不包含部分超级管理员限定入口 |
| 普通用户 | 仅能访问被授权的菜单和操作，数据范围受组织归属控制 |

### 6.4 数据闭环关系

```text
检测管理 → 资产/漏洞入库 → 风险管理 → 工单中心 → 复测/验证 → 报告与可视化
     ↓             ↓             ↓              ↓
   接入设备       资产中心        VPT           通知/审计
```

- 检测任务和同步任务产出资产、漏洞、基线等数据。
- 资产中心维护资产状态、负责人、标签和业务归属。
- 风险管理对漏洞进行筛选、处置、通知和优先级评估。
- 工单中心承接漏洞或资产处置流程。
- 报告中心与可视化模块用于运营复盘和管理汇报。
