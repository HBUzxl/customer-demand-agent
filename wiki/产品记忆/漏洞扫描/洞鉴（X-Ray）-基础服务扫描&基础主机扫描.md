# 基础服务扫描&基础主机扫描

## 基础服务漏洞扫描

**扫描目标**：主机 + Web 服务

**扫描插件**：主机插件 + Web 插件

**扫描策略特点**：

* 全覆盖主机相关和 Web 相关原理扫描漏洞及版本匹配漏洞，针对主机目标群体下的WEB应用及服务也可以检出并扫描；
* 不具备 WEB 爬虫，不能深入扫描 WEB 应用及服务
* 适合客户不清楚环境内对象都有哪些并要求尽量扫描全的场景；


## 基础主机漏洞扫描

**扫描目标**：主机

**扫描插件**：主机插件

**扫描策略特点**：

* 专覆盖主机相关原理扫描漏洞及版本匹配漏洞，明确扫描对象仅专注主机目标；
* 适合客户职责划分清晰或仅检测主机安全状况的场景；
* 相对基础服务漏洞扫描策略，扫描速度更快
