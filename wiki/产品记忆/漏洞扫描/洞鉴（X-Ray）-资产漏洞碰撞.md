# 资产漏洞碰撞

> 需要开启 “漏洞碰撞” 模块授权，建议同时开启 “资产管理” 模块授权。支持标准版、集群版，不支持易捷版。

### 功能描述

资产漏洞碰撞通过将客户已有资产信息（如 CMDB 数据、指纹库）与最新漏洞库进行智能比对，快速定位受漏洞影响的资产。

资产漏洞碰撞不依赖扫描引擎的部署，不会对扫描目标发送请求。简单、高效、非侵入性，可为突发应急响应、初步风险摸底、批量资产筛查提供核心支撑。

### 核心价值

- **速度快**：快速定位风险资产，节约大量风险筛查和处置时间；
- **评估成本低、依赖少**：使用已有资产数据即可完成，无需提前部署引擎；
- **无侵入性**：不对扫描目标实际发送请求，无任何影响业务稳定性的风险，无需提前报备网络扫描行为

### 典型使用场景

- **突发安全事件应急**：当 Log4j、Spring Cloud 等高危漏洞爆发时，通过漏洞编号快速碰撞全量资产，明确受影响的业务系统、服务器，节约大量应急时间；
- **海量资产初步摸底**：企业内拥有数千台服务器、上万个应用组件时，先通过该功能快速过滤全量资产的高风险漏洞，后续再针对重点资产开展精细扫描工作，提升风险评估效率；
- **无扫描引擎区域评估**：企业小微分支机构、涉密机房等少量区域无法部署扫描引擎设备，通过该功能，仅基于 CMDB 资产数据完成基础的资产风险筛查，保障安全红线；
- **漏洞库更新后快速匹配**：企业已通过洞鉴扫描到若干资产指纹时，更新系统漏洞库后，可通过此功能用已有资产指纹过滤新的漏洞。在不增加扫描频率的情况下，提高新漏洞扫描的及时性

### 使用方法

#### 许可证申请

申请 “漏洞碰撞” 模块授权。注意：

- 部署模式支持标准版、集群版，不支持易捷版    
- 建议同时选择 “资产管理” 模块，可以完整使用下文两个策略

#### 创建任务

资产漏洞碰撞包含两个扫描策略：

![image.png](../images/954aca3e-00e8-4231-a406-505e7cb2b5db.png)

**资产漏洞碰撞（文件导入）——导入文件进行漏洞碰撞**

使用步骤：

1. 创建 资产漏洞碰撞（文件导入） 任务，导入表格形式的资产文件。表格模版可直接在创建任务页下载：
![image.png](../images/60733375-cbb3-4d4f-9752-66e80ee67e54.png)
2. 配置其他任务配置。可以筛选要碰撞的漏洞等
3. 保存并启动任务

注：系统无法保证管理员手动导入的资产清单的准确度，因此，为避免污染系统内的集中管理数据，任务不支持同步结果到资产管理、漏洞管理。但可以生成任务的报告。

**资产漏洞碰撞——对资产管理中的资产进行漏洞碰撞**

直接使用资产管理的数据进行碰撞，依赖其已有的指纹数据。因此建议在已收集资产指纹、更新漏洞库后执行，无损碰撞新规检出风险。

使用步骤：

1. 提前配置好资产组，以供任务选择（位置：资产中心->资产列表->资产组列表）
2. 创建 资产漏洞碰撞 任务，选择资产组目标
3. 配置其他详细配置。支持自动生成扫描报表、同步结果到漏洞管理、扫描结束邮件通知、筛选要碰撞的漏洞
4. 保存并启动任务

注1：该策略必须有资产管理授权才能使用。

注2：目前仅对资产组内的主机资产生效，不对 Web 资产生效。


#### 导出报告

**保证模版包含 30% 权重漏洞**

由于漏洞碰撞的检测原理都是产品版本匹配，检出漏洞的权重（置信度）仅为 30%。所以导出报告时，注意使用自定义的报告模版（报表中心->报表模板->添加报表模版），勾选上 30% 权重的漏洞：
