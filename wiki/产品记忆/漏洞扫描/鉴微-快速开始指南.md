# 鉴微（Insight）产品快速开始指南

---

## 1. 产品简介

鉴微（Insight）是一体化风险分析与运营管理平台，核心能力：

| 能力 | 说明 |
|------|------|
| 资产纳管 | 主机、Web、域名、API、证书 5 类资产统一管理 |
| 漏洞闭环 | 多扫描源漏洞聚合→确认→修复→复测→闭环 |
| 工单流程 | 可配置的漏洞修复流程，支持审批/转派/延期 |
| 可视化 | 资产、漏洞、运营三大视角数据大屏 |
| 报告中心 | 日报/周报/月报/季报/年报，支持自定义模板 |

**核心术语**：

| 术语 | 含义 |
|------|------|
| 资产 | 被管理的 IT 资源（主机/IP/域名/Web/API/证书） |
| 漏洞 | 扫描器发现的安全问题（IP漏洞/Web漏洞/基线漏洞） |
| 工单 | 漏洞修复的任务流程单 |
| 扫描器 | 接入的第三方扫描设备（洞鉴/牧云/Nessus等） |
| VPT | 漏洞优先级评分（P0最高→P4最低） |
| 纳管/未纳管 | 资产是否已分配负责人纳入管理 |

## 2. 首次使用

### 2.1 首次访问与 License 激活

系统首次部署后，在登录页面完成 License 激活，获取初始密码后登录。

**第一步：获取机器码**

1. 浏览器访问鉴微平台 URL（默认 `https://<服务器IP>:443`）
2. 页面自动进入 License 激活界面，显示当前机器的**机器码**
3. 点击「复制」将机器码发送给相关工作人员，申请 License 文件

![获取机器码](../images/Pasted%20image%2020260731144650.png)

**第二步：上传并激活 License**

1. 收到 License 文件后，在激活页面点击「选择证书」并上传 License 文件
2. 页面将预览 License 信息，包括：证书 ID、授权企业名称、证书有效期、维保有效期、当前机器码、**初始化密码**
3. 核对信息无误后，点击「激活」完成 License 激活

![上传激活License](../images/Pasted%20image%2020260731144809.png)
**第三步：首次登录**

1. License 激活成功后，页面自动切换至登录表单
2. 输入管理员账号（默认为 `admin`），使用 License 预览中显示的**初始化密码**登录
3. 首次登录后进入「信息确认」页面，必须**重新设置密码**（含新密码和确认密码），并可补充手机号和邮箱
4. 提交后需使用新密码重新登录，即可进入系统

> License 已激活后如需更新、续期或查看 License 信息，可进入「配置中心 → 系统管理 → 授权许可」操作。

### 2.2 初始化配置（管理员）

首次登录完成后，管理员建议按以下顺序完成基础配置：

**第一步：创建组织架构**

「配置中心 → 用户管理 → 组织机构」→ 新建组织层级

**第二步：创建用户与角色**

- 「配置中心 → 用户管理 → 用户列表」→ 新建用户，分配角色
- 「配置中心 → 用户管理 → 角色列表」→ 按需创建自定义角色

**第三步：对接扫描器**

详见下方「检测管理」章节

## 4. 核心操作流程

### 4.1 资产管理

> 菜单：**资产中心 → 资产管理**

#### 添加资产（3种方式）

| 方式 | 操作路径 | 适用场景 |
|------|---------|---------|
| 手动录入 | 资产列表 → 点击"新建" | 少量资产 |
| Excel 导入 | 资产列表 → 点击"导入" → 下载模板 | 批量初始化 |
| 扫描自动发现 | 接入扫描器 → 创建同步任务 | 持续运营 |

#### 资产状态说明

| 状态 | 含义 | 后续操作 |
|------|------|---------|
| 已纳管 | 已分配负责人，正常管理 | 持续追踪 |
| 未纳管 | 未分配负责人，无法追踪 | 需分配组织和负责人 |
| 已排除 | 风险被忽略 | 不参与风险统计 |
| 下架 | 已下线，归档为历史资产 | 可恢复 |

#### 5 类资产速览

| 资产类型 | 典型字段 | 采集方式 |
|---------|---------|---------|
| 主机资产 | IP、OS、端口、指纹 | 扫描器上报/手动录入 |
| Web 资产 | URL、域名、标题、证书 | 扫描器上报/手动录入 |
| 域名资产 | 域名、DNS 解析、Whois | 扫描器上报 |
| API 资产 | URL、请求方法、参数 | 扫描器上报/手动录入 |
| 证书资产 | 域名、有效期、颁发机构 | 从域名资产读取 |

### 4.2 风险管理（漏洞处置）

> 菜单：**风险管理 → IP漏洞 / Web漏洞**

#### 漏洞生命周期

```
待处理 → 验证中 → 修复中 → 复测中 → 已修复
   ↓        ↓
 误报      忽略
```

#### 处置漏洞（两种方式）

**方式一：直接处置**

1. 进入漏洞列表，筛选「待处理」状态
2. 点击漏洞进入详情，研判漏洞有效性
3. 选择处置动作：确认/误报/忽略 → 依次流转至已修复

**方式二：下发工单（推荐，适合团队协作）**

1. 勾选一个或多个漏洞 → 点击「下发工单」
2. 选择工单模板、执行人、优先级
3. 工单创建后，漏洞自动关联，状态随工单流转

#### VPT 优先级参考

| VPT 等级 | 含义 | 处置建议 |
|----------|------|---------|
| P0 | 最高优先级 | 立即处置 |
| P1 | 高优先级 | 24h 内处置 |
| P2 | 中优先级 | 本周内处置 |
| P3 | 低优先级 | 本月内处置 |
| P4 | 最低优先级 | 评估后按需处置 |

---

### 4.3 检测管理（扫描器对接）

> 菜单：**检测管理 → 接入设备 / 任务列表**

#### 对接扫描器

1. 「接入设备」→ 点击"新建"
2. 选择扫描器类型
3. 填写地址和认证信息（Token/账号密码）
4. 确认设备状态变为「在线」

#### 扫描器对接速查

| 扫描器 | 内置 | 认证方式 |
|--------|------|---------|
| 洞鉴 | ✅ 内置 | API Token |
| 云图 | ✅ 内置 | API Token |
| 雷池 API Sec | ✅ 内置 | Token |
| 青藤 HIDS | ✅ 内置 | 账号密码 |
| 牧云 | ❌ 需上传 | API Token |
| Tenable SC | ❌ 需上传 | API Key |
| Tenable NS (Nessus) | ❌ 需上传 | API Key |
| 绿盟 RSAS | ❌ 需上传 | 账号密码 |
| 盛邦 RayScan | ❌ 需上传 | 账号密码 |

#### 创建任务

| 任务类型 | 用途 | 菜单位置 |
|---------|------|---------|
| 扫描检测任务 | 触发扫描器执行一次扫描 | 任务列表 → 扫描检测任务 → 新建 |
| 数据同步任务 | 定时从扫描器同步漏洞/资产 | 任务列表 → 数据同步任务 → 新建 |

---

### 4.4 工单中心

> 菜单：**工单中心 → 工单管理 / 创建工单**

#### 创建工单

1. 「工单中心 → 创建工单」
2. 选择模板 → 填写信息 → 关联漏洞/资产 → 选择执行人 → 创建

#### 处理工单

1. 「我的工单 → 待处理」查看待办
2. 点击"查看" → 填报处置结果 → 点击"完成执行动作"

#### 工单操作速查

| 操作 | 说明 | 使用场景 |
|------|------|---------|
| 同意 | 流程正常流转 | 审核通过 |
| 驳回 | 退回上一节点 | 信息不全/处置不达标 |
| 转派 | 转给其他人 | 责任人变更 |
| 延期 | 申请延期处理 | 需更多时间 |
| 加签 | 增加审核节点 | 需要其他人审核 |
| 回退 | 撤回工单 | 上一执行人撤回 |

#### 工单列表说明

| 标签 | 含义 |
|------|------|
| 待处理 | 需要我处理的工单 |
| 我创建 | 我发起的工单 |
| 抄送给我 | 别人抄送我的工单 |
| 已处理 | 我已处理完成的工单 |

---

### 4.5 报告中心

> 菜单：**报告中心 → 报告任务**

#### 快速生成报告

1. 「报告任务 → 新增任务」
2. 选择任务类型：**周期任务**（日报/周报/月报）或 **临时任务**
3. 选择报告模板或自定义内容
4. 保存后自动按计划生成

#### 下载报告

展开任务 → 点击下载 → 选择格式：**Word / PDF / HTML**

## 6. 角色与典型工作流

### 安全运营人员

```
登录 → 可视化大屏看全局
     → 风险管理 → 查看新增漏洞 → 研判
     → 下发工单/直接处置 → 追踪修复
     → 定期生成周报/月报
```

### 管理员

```
初始：上传License → 建组织 → 建用户 → 配角色 → 对接扫描器
日常：用户管理 → 工单模板维护 → VPT规则调优 → License续期
```

### 实施人员

```
部署：安装鉴微服务 → 配置数据库 → 上传License
对接：接入扫描器 → 测试连通 → 创建同步任务
交付：确认资产入库 → 确认漏洞同步 → 培训用户
```

## 7. 常见问题

| 问题 | 解决方法 |
|------|---------|
| 忘记密码 | 联系管理员后台重置，或使用「忘记密码」功能 |
| License 过期 | 「配置中心 → 系统管理 → 授权许可」更新 |
| 资产未入库 | 检查扫描器在线状态、数据同步任务是否启动 |
| 漏洞未显示 | 检查同步任务状态、筛选条件 |
| 工单无法提交 | 检查必填字段、下一节点配置 |
| 通知收不到 | 检查「通知管理」中的邮件/钉钉配置 |
| 不能操作某个模块 | 联系管理员检查角色权限 |
