# 洞鉴（X-Ray）产品介绍

### 产品简介

**洞鉴（X-Ray）风险评估系统** 是一款从攻击者视角出发的安全风险评估产品，覆盖 Web 漏洞扫描、主机服务漏洞扫描、基线合规检查、容器镜像扫描、API 漏洞扫描、弱口令扫描、监管专项检查（两高一弱）、逻辑漏洞扫描等能力。

洞鉴依赖于长亭专业的安全攻防经验，转化为自研漏洞风险检测算法，利用 PoC 原理漏洞验证，为用户提供攻击视角下的网络脆弱性检测的能力，追求风险评估结果 **高精准**、**低误报**，降低安全运营成本。在日常运营场景下配合资产与漏洞关联管理分析，全面探测网络资产安全状况，精准定位资产安全薄弱点，持续跟踪网络健康状况，实现资产风险生命周期的轻量级闭环。

相关概念或产品：`漏洞扫描器` `漏扫` `漏洞扫描` `风险评估` `资产评估` `资产探测` `安全评估工具` `漏洞管理` `资产测绘系统` 

### 核心能力

| 模块 | 说明 |
|------|------|
| 扫描管理 | 远程扫描、代理扫描、合规检查、容器镜像扫描的任务、策略、配置管理 |
| 资产中心 | 主机资产、Web 站点资产的集中管理 |
| 漏洞管理 | 漏洞全生命周期闭环管理 |
| 报表中心 | 任务、资产、漏洞等多维度报表生成 |

### 部署形态

洞鉴为本地化部署产品，典型使用场景：

- **主动扫描** — 对内网资产发起扫描，评估风险状况
- **主机登录检测** — 通过 SSH 凭据登录主机，收集包版本信息进行风险评估
- **被动收集** — 通过代理、日志上传、API 文档、资产清单等方式收集分析资产情况
