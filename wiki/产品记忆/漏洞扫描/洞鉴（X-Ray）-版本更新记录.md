# 版本更新记录

## XR-S(H)10-26.06.001


> **主要更新**：基线更新、扫描历史自动清理
> **引擎版本**：6.18.14_r1
> **漏洞库版本**：6\_2026-06-17\_r1


### 基线检查

* 新增大量基线核查策略
  * 操作系统：AIX、HP-UX、Solaris
  * 应用中间件：exchange、BIND、IHS
  * 网络设备：Juniper路由器、迈普路由器和交换机、华三路由器和交换机、思科路由器和交换机、华为路由器和交换机、中兴路由器和交换机
  * 安全设备：思科ASA防火墙、思科PIX防火墙、CheckPoint防火墙、山石防火墙、Fortigate防火墙、Juniper NetScreen防火墙、Juniper SRX防火墙、安氏防火墙、华三防火墙、华为防火墙、迪普防火墙、奇安信天眼、中睿中天睿眼、启明星辰防火墙、天融信防火墙、启明星辰 WAF
  * 虚拟化设备：hyper-v、xenserver、kvm、OpenStack 虚拟化设备
  * 主流数据库：Sybase、达梦
* 优化基线任务配置和展示
  * 任务计划支持设置 每月第 x 个星期的 x 点 x 分
  * 检查结果新增 “命令实际执行结果”
  * SSH 登录支持配置 enable 密码，适配迈普设备
* 增加若干基线相关的统计和管理细节
  * 首屏统计增加若干下钻能力
  * 首屏统计增加基线的 “不合规配置” 统计
  * 主机资产详情增加基线风险详情，支持跳转到相关任务
  * 主机资产列表增加 “下发基线扫描” 操作
  * 主机资产增加是否可信字段
  * 基线任务列表支持按主机 IP 筛选

### 系统管理

* 新增扫描历史自动清理和一键手动清理。扫描历史过多、磁盘空间有限、对查询性能要求高的，可以在备份数据后进行清理（位置：系统管理->系统设置->扫描历史自动清理）
* 新增 OIDC 统一认证配置，增强第三方认证集成能力 *（位置：系统管理->系统设置->OIDC 统一认证配置）
* 大幅增强 Webhook 消息配置能力，支持更多事件通知与配置场景 *（位置：系统管理->消息配置）
* 新增 并发会话数、并发用户数、会话清单、在线用户清单、一致性统计（位置：系统管理->系统信息->状态监控）
* 资产管理->主机资产，增强批量操作能力：支持按筛选条件批量下发任务、批量生成报告、异步任务追踪。

### 其他

* 优化了漏洞详情中富文本的展示效果
* 新增漏洞库 API
* 优化了大量界面样式交互细节

### 性能和稳定性

* 升级 OpenVPN 至 2.6.20、Redis 至 7.4.9，处理 EOL 和兼容性问题。
* 优化若干性能问题

---

### Bug 修复

* 修复批量选择后无法生成报告、报告模板默认值错误，等报告相关问题
* 修复漏洞详情含少数特殊字符时，无法正常完成漏洞复测的问题
* 修复主机状态多条结果不一致时未优先采信 up 状态的问题
* 修复主机资产列表资产状态图标不显示问题
* 修复其他一些已知问题

## XR-S(H)10-26.05.001

> **主要更新**：自定义页面代码、基线 SSH 预执行命令
> **引擎版本**：【待补充】
> **漏洞库版本**：【待补充】

### 新增与优化

#### 扫描与任务

- 基线任务新增 “SSH 预执行命令”
  - 支持 sudo 提权、su 提权、enable 切换权限模式、自定义命令
  - 自定义命令严格校验内容与可执行角色，降低安全风险
- 浏览器爬虫支持 “允许爬取父目录”

#### 资产中心与漏洞管理
- 支持通过任务结果筛选资产与漏洞数据
- 优化资产状态
    - 新增 “陈旧” 标记，连续一个季度未扫描则切换为 “陈旧” 状态，醒目过滤建议扫描的资产
    - 降低网络波动影响，连续 3 次扫描资产未存活，才切换为 “不存活” 状态
    - 简化配置流程。现在任务中同步到资产管理的配置更简单了
- 调整了漏洞状态的名称，减少歧义

#### 系统管理
- 新增 “自定义界面代码”，可以用于灵活定制化界面

#### 其他

- minion 新增备份与恢复命令（ `backup` / `restore` ）
  - 支持定期备份
  - 支持数据库、证书、配置、引擎 id 等分别备份与还原
- 优化大量前端 UI 交互细节
  - 多处列表单选筛选改为可多选（内部注：报表模板列表「模版来源」、扫描任务列表「扫描状态」、自定义 POC 列表「漏洞等级」、系统用户列表「用户角色」、漏洞库列表「厂商」、漏洞库列表「服务类型」）
  - 多处列表新增列宽拖拽能力（内部注：IP段、业务系统、网络区域、消息配置列表、日志管理列表、内置 POC 插件列表、自定义指纹列表）

---

### Bug 修复

- 修复 资产漏洞碰撞（文件导入） 策略上传大文件失败的问题

## XR-S(H)10-26.03.001

> **主要更新**：风险接受、AI MCP、版本匹配漏洞复测、插件列表
> **引擎版本**：6.18.11_r8
> **漏洞库版本**：6\_2026-03-19\_r1

### 新增

* 新增 “风险接受配置” 模块，支持标记出已知的接受漏洞，减少告警噪音
* 新增 MCP 接口，支持接入 AI 应用
* 知识库增加 “内置 POC 插件” 列表，方便查询

### 优化

* 版本匹配漏洞（30% 权重漏洞）也支持复测了
* 策略中 “智能插件调用” 改为默认开启
* Word、Excel 报告增加 “数据筛选” 小节，展示生成时的所有筛选条件，方便排查问题
* 新增管理节点 ID（系统管理/系统信息/基本信息），仅超级管理员可见；新增引擎 ID（编辑引擎、引擎详情页），方便排查问题
* 支持修改引擎节点的 IP（该 IP 只用于界面展示，不实际用于连接节点，也不会同步到节点设备上），方便迁移引擎设备
* 用户可以设置自己登录后的默认工作区
* 主机资产的操作系统支持设置为任意字符，不限定于内置的操作系统列表
* 优化大量 UI 与界面交互细节
  * 报告列表增加生成的百分比进度。在超时或报错时可以一键重新生成
  * 优化若干列表页交互，包含支持设置列表字段、支持手动调整各字段宽度、筛选组件与其他页面统一、筛选支持多选
  * 降低任务列表自动刷新频率
  * 修复若干 UI 错位问题
  * 右上角增加 中英文切换 快捷按钮
* 优化性能
  * 优化前端启动速度
  * 优化 工作区、任务、漏洞 的查询性能
* 优化安装、启动程序

### Bug 修复

* 修复 k8s 引擎增加的副本数显示和实际的不一致的问题
* 修复信创版本金仓 mac 地址失效，导致引擎节点异常的问题
* 修复 webhook 消息未处理好转义导致发送失败的问题
* 修复 k8s 引擎拓展的子引擎，在系统服务页面会显示异常的问题。修复 “引擎节点状态” “引擎节点总数” 统计数量不一致的问题（PEP-10697）
* 修复备份还原失败的问题
* 修复引擎调度可能出现超时问题

## XR-S(H)10-26.01.001

> **主要更新**：新增资产漏洞碰撞功能
> **引擎版本**：6.18.10_r4
> **漏洞库版本**：6\_2026-01-28\_r1

### 新增

* 新增 **资产漏洞碰撞** 功能，包含新增 2 个策略：资产漏洞碰撞、资产漏洞碰撞（文件导入）。

### 优化

* 大幅优化漏洞查询 OpenAPI 的性能（/vuln/filter）
* 调整扫描任务风险等级的计算方法。现在扫描任务的风险等级与任务内最严重的漏洞的等级一致
* 扫描任务详情、扫描任务报告的漏洞详情中，增加 “漏洞披露时间” 字段
* 主机登录成功也会记录扫描日志
* 逻辑漏洞扫描任务 “被测账号 Cookie” 支持填写 IP 地址

### Bug 修复

* 修复多核 CPU 时，系统管理-系统信息-服务状态 的容器 CPU 占用率在超过 100% 时仍然只显示 100% 的问题
* 修复拥有 “资产管理” 授权但没有 “漏洞管理” 授权时，无法正常生成资产报表的问题
* 修复资产报表中展示了 “误报” 漏洞的问题
* 修复编辑任务后点击 “保存并立即扫描”，有小概率修改的插件会不生效的问题
* 修复了其他一些已知问题
