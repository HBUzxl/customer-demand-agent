# 系统管理

## 系统设置

### 基本配置

配置 登录策略配置、密码策略配置、SMTP 服务器配置、日志输出配置、数据备份设置、FTP 服务器设置、日志存储配置、访问 IP 限制、报表设置、产品联动配置。

![](../images/upload_f87470bef37bcfaddfe7664903e9f3c2.png)

#### 登录策略配置

登录策略配置用于设置管理端登录相关的安全参数，保障系统访问安全。

主要包括：

- **会话超时时间**：设置用户登录会话的最大空闲时间，超时后自动退出
- **登录失败锁定**：连续登录失败达到阈值后，锁定账户/IP一段时间


注：

* 登录超时/操作超时后，用户需重新登录
* 修改登录策略后，仅对之后新创建的登录会话生效，已有的会话不受影响
* 锁定期间，该账户/IP将无法登录管理端


#### SSO 认证配置

SSO（Single Sign-On）认证配置用于集成企业统一身份认证系统，支持 OIDC 和 OAuth2.0 协议。

开启 SSO 认证后，用户可在登录页选择 "SSO 登录" 方式，使用企业统一认证系统（如 Okta、Azure AD、Keycloak 等）的账号进行登录。

注：

- 需先在身份提供方完成应用注册，获取 Client ID 和 Client Secret
- 确保回调地址已在 IdP 中配置为允许的回调地址，也不会被内部网络策略拦截
- 开启 SSO 后，常规账号密码登录方式仍然可用

#### 密码策略配置

设置全局密码的安全要求，包括密码复杂度要求、更换频率要求等。包括：

- **密码复杂度要求**：规定密码长度、字符类型要求
- **密码更换频率**：设置密码定期更换周期，到期后强制修改
- **密码过期提醒**：密码到期前多少天开始提醒用户更换

注：

- 修改密码策略后，只对之后修改密码的用户生效，已有密码不受影响

#### SMTP 服务器配置

配置系统使用的 SMTP 服务器。 SMTP 服务器用于发送邮件，包括：

1. **任务通知**：在任务结束后，自动发送扫描结束邮件。需要在任务中配置 “扫描动态通知” 
2. **报表发送**：在任务结束后，自动发送扫描任务的报表文件。需要同时配置任务中的 “扫描动态通知” 与 “自动生成扫描报表”
3. 其他系统告警通知

注：

- **使用第三方邮件服务商**：如使用 QQ 邮箱、163 邮箱或企业微信邮箱，通常需要先在邮箱设置中开启 SMTP 服务并获取"授权码"作为认证密码，而非邮箱登录密码


#### 日志输出配置

设置 Syslog 输出配置。配置后，可输出系统操作日志

#### 系统语言设置

设置当前系统语言为中文或英文。

#### 引擎时间同步

开启或关闭引擎时间同步。开启后，强制将引擎时间同步为管理节点设备时间，避免异常。

#### 腾讯云部署密钥配置

配置腾讯云 API 访问密钥，用于引擎部署、资源查询等腾讯云相关功能

#### 数据备份设置

配置系统数据的自动备份策略，确保系统数据安全。设置后会自动在选定时间生成进行数据备份。详细设置请参考 “备份还原” 相关说明。

注：

- 自动备份时间建议设置在业务低峰期，例如凌晨
- 定期检查备份文件是否生成成功，磁盘空间是否充足，避免因磁盘空间不足导致备份失败或数据丢失

#### FTP 服务器设置

FTP 服务器设置用于配置远程文件传输服务器，支撑数据备份的远程传输和其他文件交换需求。

#### 日志存储配置

日志存储配置用于管理系统操作日志的本地存储策略。包括存储数量或时间、告警通知邮箱。

#### 扫描历史自动清理

自动清理扫描历史（扫描任务实例）相关的数据，包含扫描日志、任务发现漏洞、任务发现资产等。以减少系统磁盘占用、提高数据查询性能。

注：

- 不会删除的数据：扫描计划、资产中心数据、漏洞管理数据
- 部分全局统计数据不会在清理后重新计算
- 为保障基本的历史可回溯能力，开启自动清理后不允许设置低于 180 天的保留周期

#### 访问 IP 限制

访问 IP 限制用于配置管理端的登录来源 IP 白名单或黑名单，增强系统访问安全。

访问 IP 限制支持两种模式：

- **白名单模式**：仅允许白名单内的 IP 地址登录管理端。适用于安全要求高的环境，可设置仅允许办公网段或 VPN 网段访问
- **黑名单模式**：禁止黑名单内的 IP 地址登录管理端。适用于需要阻止特定来源的入侵尝试

注：

- 配置白名单时，请确保至少包含一条当前管理员的 IP 地址，避免将管理员自身锁在系统外
- 如果错误配置导致无法登录，请联系官方技术支持，通过后台命令重置 IP 限制配置

#### 报表设置

报表设置用于配置系统报表的全局生成设置。

- **报表生成超时时长**：超时后判定为生成失败。
- **报表留存时间**：超过留存时间后的报表会自动从磁盘中删除，以减少磁盘占用；0 天表示不限制留存时间

#### 产品联动配置

产品联动配置用于设置本系统与其他安全产品或平台的联动集成，实现安全数据互通和协同处置。

显示配置可帮助企业进行 OEM 配置，例如 logo、名称等。

## 消息配置

消息配置提供钉钉、企业微信、飞书等外部消息告警配置。

![](../images/upload_17d0e7c2acd3f07a32a90890e2c697ec.png)

点击右上角 “添加一个配置”，即可打开添加的弹窗：

![](../images/upload_8bdcc14d89caad507565e8d8f55a46b8.png)

根据钉钉、飞书、企业微信、百川的官方文档，获取消息通知的地址，填入到上图的 “渠道地址”，然后补充名称、说明等信息，保存即可完成配置。

## 系统信息

### 基本信息

展示产品相关信息，包含产品信息、许可证信息等。可在此处更新许可证。

展示管理节点设备状态、网络状态、会话状态。可在此处编辑设备时间。

![](../images/upload_21097ce9394fe75467f1b60a57ac8938.png)

点击 “系统时间” 后的编辑图标，可在弹窗中修改系统时间，如图：

![](../images/upload_419a51c7adc8542a9165be4b7d23b2a5.png)

支持修改“系统时间”信息，点击“确定”按钮，即系统时间编辑成功。

**注：修改系统时间后，默认也会同步引擎的时间。如果和真实时间差距过大，可能引发未知问题，请谨慎修改。**

展示系统各个容器健康信息。

![](../images/upload_1504f5ef614ba9ac9c02951e1d762247.png)

如果容器缺失或状态异常，请联系官方技术支持确认。

## 系统服务

### 引擎升级

此处可执行引擎升级操作。

**注意：**

* 引擎升级会导致服务中断，会对正在进行的任务自动暂停，可能会造成部分扫描数据丢失，建议在没有任务执行的时间进行升级操作
* 升级前需要选择想升级的引擎，不同类型（arm、x86、集群版等）的引擎所使用的升级包不一样。若需要升级多种类型，请执行多次升级操作

![](../images/upload_efd5a0a218c2a4f853e0a7444814175b.png)

#### 离线升级

在 “离线升级” 标签，直接上传目标引擎升级包即可：

![](../images/upload_0f9f83e803260e2794904b0ded526912.png)


上传后会对上传文件进行内容和版本的校验。校验通过后，点击 “一键升级”按钮，即引擎升级操作开始执行。

#### 在线升级

在 “在线升级” 标签。配置好网络连接后，在界面可以直接看到新版本的引擎升级包，点击下载即可：

![](../images/upload_996f6ad7629c64c93cfb9d86b7a16bf1.png)


首次使用在线升级功能，需要前往升级服务平台进行注册。步骤为：
- 第一步：点击“升级服务平台”按钮，访问「升级服务平台」页面；
- 第二步：使用与此系统一致的许可证进行账号注册；
- 第三步：返回洞鉴「在线升级」页面，点击“更新升级服务平台地址”，默认需要输入“ https://product-support.chaitin.cn/ ”，点击“确定”按钮，即升级服务平台注册成功。

**注意：**

- 若产品部署在内网环境中，无法直接链接升级服务平台，需要通过配置代理服务器实现，并在上述第三步中填写代理服务器的地址。

### 备份还原

可在此对系统数据进行备份还原操作，还可以查看备份还原历史。

![](../images/upload_42c2f30dfbdbe0bf8567d9ccc2d685c9.png)

常用操作：

- 在线还原备份：创建备份后，在备份列表直接点击 “在线还原” 即可
- 离线还原备份：创建备份后，点击“下载” 下载备份文件到本地。点击 “上传文件还原” ，上传本地下载的备份文件，确认信息后即可恢复
![](../images/upload_955632448de57fe34cb91dc0467bf18a.png)


注：

- 备份数据包括扫描任务、任务结果、资产数据信息、漏洞数据信息、日志审计信息等。备份时需预留磁盘容量，避免恢复后出现数据丢失
- 还原操作会覆盖当前系统数据
- 备份数据还原需要一定时间，再此期间尽量不要操作系统

## 引擎管理

### 引擎列表

集中管理系统中的所有引擎节点。包括查看运行状态、修改扫描配置等。

![](../images/upload_9cdcd7b821d544779be59810d3eaff11.png)

常用操作：

* 查看引擎详情：点击列表可打开引擎详情
![](../images/upload_a690afc939be6ef6c2db0d43f00e43f8.png)
* 禁用/启用引擎节点：点击列表右侧 “启用”“禁用” 即可。禁用后，在创建任务时无法选中该引擎
* 重启引擎节点：点击列表右侧 “重启” 即可。可远程重启引擎程序，用于初步排障
![](../images/upload_17d045ea1bc643eb8f0ba657d724da15.png)
* 删除引擎节点：点击列表右侧 “删除” 即可。若引擎有关联的扫描任务，则无法执行删除操作，需要手动解除任务与此引擎的关联，方可删除成功


#### 编辑引擎节点

点击“编辑”按钮，可以修改引擎的详细配置：

![](../images/upload_e9f866a1cbb03c897bb277e4afb164dc.png)

配置含义：

* **引擎权限**：“公有” 表示任意组织单位的任务皆可使用，“自定义权限” 表示只允许特定组织单位使用
* **网络区域配置**：定义该引擎能够访问的网络段，方便多引擎智能调用
* **盲打平台**：配置该引擎扫描盲打漏洞时所用的盲打平台。详情可参考 “盲打平台” 相关文档
* **被动爬虫服务器配置**：配置引擎下发被动爬虫任务时，所用的配置
* **域名解析配置**：配置 DNS 服务器，用来解析扫描时遇到的域名。（注：在列表选择多个引擎，可以批量配置域名解析配置）
