# 资产中心

资产中心可集中对所有任务扫出的资产进行风险管理，也可以手动导入资产清单，以方便下发扫描任务。

## 资产全景

资产全景可一览全局资产数量、运行情况、风险等级分布等。

![](../images/upload_8681aa097514790fa4d4005ebae1e8e9.png)

## 资产列表

### 主机资产列表

主机资产列表集中展示系统中所有主机资产，可进行筛选、导出报告、导入等操作。如图：

![](../images/upload_2792871d766896031fbfa994d3b4ffea.png)


#### 查看存活动态

“存活动态” 按钮可以一键查看 **近期存活状态变化的资产**。

右侧的 “...” 按钮可以配置具体 “变化” 的定义。包含时间范围、变化的类型：

![](../images/upload_df0762a9b1d588a2ba61ea577c6d78de.png)

#### 创建主机资产

点击右上角 “手动添加主机” 即可手动导入资产：

![](../images/upload_6a1afd6ef8cc2a0c7e9d000a347d81e0.png)

支持两种添加方式：

* 方式一：手动添加
    * 直接添加单个资产
    * 手动添加的资产在后续扫描中被发现时，系统会自动关联并补充指纹、漏洞等信息，不会产生重复记录
* 方式二：文件上传
    * 一次性导入包含多个资产的表格。可先在界面下载表格模版

#### 批量导出、生成报表、下发任务

在主机资产列表选中主机，右上角 “批量操作” 可以直接 “导出”、“生成报表”、“下发任务”：

![](../images/upload_7681bdd3076ed93c9a59f82228a451ff.png)

* 导出：导出成 txt 文件
* 生成报告：生成资产的报告（详细配置请参考 “报表管理” 相关说明）
* 下发任务：直接跳转到添加任务页面，选择一个主机/服务类策略，扫描目标为选中的主机


### 主机资产详情

主详详情展示主机的基本信息、端口指纹信息、漏洞信息、Web 信息等：

![](../images/upload_e65ae0f61118ab0333d724e73963468b.png)

基础信息和端口指纹信息可手动添加、编辑。漏洞信息和 web 信息则由系统自动关联。


## Web 站点资产

### Web 站点资产列表

集中展示系统中所有 Web 站点资产，可进行筛选、导出报告、导入等操作。如图：

![](../images/upload_3d38535550469f2720e51da7f24b8c83.png)

#### 创建 Web 站点资产

点击右上角 “手动添加 Web 站点” 即可手动导入资产。支持两种添加方式：

* 方式一：手动添加
    * 直接添加单个资产
    * 手动添加的资产在后续扫描中被发现时，系统会自动关联并补充指纹、漏洞等信息，不会产生重复记录
* 方式二：文件上传
    * 一次性导入包含多个资产的表格。可先在界面下载表格模版


#### 批量导出、生成报表、下发任务

在 Web 站点资产列表选中 Web 站点，右上角 “批量操作” 可以直接 “导出”、“生成报表”、“下发任务”：

![](../images/upload_708cee8172df6956164831a1ee8cf97a.png)

* 导出：导出成 txt 文件
* 生成报告：生成资产的报告（详细配置请参考 “报表管理” 相关说明）
* 下发任务：直接跳转到添加任务页面，选择一个 Web 类策略，扫描目标为选中的站点

### 查看 Web 站点资产详情

Web 站点详情展示 Web 站点的基本信息、指纹、漏洞、目录结构、子域名、主机、API 等：

![](../images/upload_66b2f99d5740d3d954ef6a5139b8096b.png)

基础信息、指纹应用信息可手动添加、编辑。漏洞和其他 web 信息则由系统自动关联。

## 资产组列表

划分资产组可以更方便地进行扫描任务下发和风险管理：

![](../images/upload_016a2ec1a32b39e60b80d644ddaafe76.png)

点击右上角 “添加资产组” 可创建新资产组，如图：

![](../images/upload_f0d812dc860a01c14786c229ec40a2f6.png)


* 邮箱：配置邮箱且开启 “任务发送报表通知”，当通过该资产组下发任务时，自动生成的任务结果报表将发送到上述地址的邮箱
* 资产同步模式：自动同步可根据 IP 段自动从资产列表同步资产


#### 基于资产组批量导出报表、下发任务

选中列表上的资产组，右上角 “批量操作” 可以直接 “生成报表”、“下发任务”：

![](../images/upload_84f4ed0a46085c854023c92dd122e797.png)

* 生成报告：生成资产组中所有资产的报告（详细配置请参考 “报表管理” 相关说明）
* 下发任务：直接跳转到添加任务页面，扫描目标为选中的站点

# 资产属性管理

## IP 段管理

以网段的形式统计和管理资产。添加后，可以直观查看 IP 段的理论 IP 数、实际存活 IP 数、负责人等信息。如图：

![](../images/IP段列表.png)

一个“ IP 段” 可以添加多个实际网段，点击列表 “查看”，能分列看到其包含的所有 IP 段情况，如图：

![](../images/IP段-查看IP段.png)

### 创建 IP 段

点击右上角 “添加 IP 段”，配置名称、网段（可添加多个）、组织单位等信息即可：

![](../images/upload_186cb39d5b8000dfb0d1096ec9a5b923.png)

### 执行批量操作

在 IP 段列表中点击“多选框”按钮选中需要执行批量操作的 IP 段，鼠标悬浮“批量操作”按钮，支持“删除”、“导出”，和“更新数据”操作，如图：

![](../images/upload_99c4546ee3ec44b27986f0d56f9223b9.png)

* 导出 IP 段：导出表格文件。
* 更新实际存活 IP 数：点击即更新

## 业务系统管理

在左侧导航栏中点击“资产中心-资产属性管理-业务系统管理”，访问「业务系统管理」页面，如图：

![](../images/upload_37267652a74b3feb2886cd3e61b83edb.png)

此页面主要展示系统中所有业务系统，用户可在此页面执行业务系统管理操作。

### 创建业务系统

点击“添加业务系统”按钮，弹出「添加业务系统」弹窗，如图：

![](../images/upload_b74598e9790dfedc03654c5a3b7f0f7d.png)

需要配置“业务系统名称”和“组织单位”信息；

点击“确定”按钮，即业务系统创建成功。


## 网络区域管理

在左侧导航栏中点击“资产中心-资产属性管理-网络区域管理”，访问「网络区域管理」页面，如图：

![](../images/upload_3bf788d992c31752402d0fea9b46bbb7.png)

此页面主要展示系统中所有网络区域，用户可在此页面执行网络区域管理操作。

### 创建网络区域

点击“添加网络区域”按钮，弹出「添加网络区域」弹窗，如图：

![](../images/upload_a0cef42916d30782ee4c6f7ff80ad30f.png)

需要配置“网络区域名称”和“组织单位”信息；

点击“确定”按钮，即网络区域创建成功。


## 标签管理

配置资产的标签，一个资产可以有多个标签。
