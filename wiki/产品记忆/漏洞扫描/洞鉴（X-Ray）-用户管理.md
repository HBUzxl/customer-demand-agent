# 用户管理

洞鉴使用 RBAC（Role-Based Access Control）即 基于角色的权限控制模型 进行系统用户授权。配置时有以下三个关键元素：用户、角色、权限。用户是系统实际的操作员。角色是具备相同权限的用户集合。权限是访问和操作的许可，通常是“增删改查”。

初始账户（admin）为超级管理员，拥有所有配置权限。建议登录后配置 系统管理员、安全管理员、安全审计员 三类角色，分权进行管理。

PS. 用户需要选择**组织单位**，该配置与角色无强相关关系，具体说明可参考 “组织单位” 相关文档。

## 系统用户管理

此处用于管理系统中所有用户账号。可执行 **添加、编辑、查看、删除** 操作。

![](../images/upload_476dac06c2db1e738e6d6cb12945352e.png)

注：

- 一个用户配置一个角色身份
- 删除用户后，此用户所管理的组织单位将自动移除此管理员，删除前请确认
- admin 账户无法删除
- 选中多个用户，点击右上角 “批量操作-导出”，可导出用户基本信息成表格文件

## 用户角色设置

此处用于管理系统中所有角色。可执行 **添加、编辑、查看、删除** 操作。

![](../images/upload_b1f5fbb344a851102584483adc219f07.png)
![](../images/upload_323c84bafeaf57c593636a42d24ef2ee.png)

注：

- 一个角色包含多个权限， “权限” 指增删改查某个配置的能力，如图：
- “**角色创建单位**” ：表示角色使用范围，即该单位及其单位在配置用户的时候可以选择该角色。注意与用户的组织单位不一定一致
- “**IP 白名单**”：表示该角色的用户只能通过这些 IP 进行登录
- 无法删除有用户正在使用的角色
- 无法删除系统内置角色

## 组织单位管理

此处用于管理系统中所有组织单位。可执行 **添加、编辑、查看、删除** 操作。

![](../images/upload_4daa58986e45a3ae87338125fbcc38cc.png)


- **创建组织单位**：点击 “添加根组织单位” ，或是在组织单位树上点击 “添加”。都可创建新组织单位：
![](../images/upload_9e149c407e7963666947fe07f759cb9a.png)
- **执行组织单位管理**：鼠标悬浮组织单位结构树上的目标组织单位名称，支持“添加”（创建子组织单位）、“编辑”，和“删除”操作
![](../images/upload_61550a2d91e085005ff72eb63a7b03bb.png)

注：

- 仅组织单位的负责人可以创建子节点组织单位
- 仅组织单位的负责人可以编辑 “组织单位负责人” 信息
- 仅组织单位的负责人可以删除组织单位
- 删除组织单位后，此组织单位关联的所有资源数据都将会被删除。删除时需要输入登录密码，请谨慎操作
- 组织单位在各个功能模块的生效方式，可以参考 “组织单位生效方式” 相关文档
