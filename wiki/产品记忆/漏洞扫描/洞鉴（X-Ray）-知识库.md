# 知识库

知识库是扫描引擎检测漏洞的基础知识。包含漏洞、POC 插件、指纹。

知识库模块可集中查看、管理系统中的这些知识信息。

## 漏洞库

漏洞库展示系统中存储的所有漏洞知识。

![](../images/upload_8ff6833be7e3839625cb3c31eea8a705.png)

**常用操作**：

* **升级漏洞库**：点击列表右上角的 “升级漏洞库” 按钮，可以快捷跳转到「系统服务-漏洞库升级」页面升级漏洞库（详情可查看相关文档）
* **批量编辑自定义标签**：选择若干漏洞，点击右上角 “批量操作” “编辑” 即可批量编辑这些漏洞的自定义标签
![](../images/upload_54675826cd19c02dd4658cb807348f83.png)
* **批量下发任务**：选择若干漏洞，点击右上角 “批量操作” “下发任务”，可快速创建这些漏洞的扫描任务
![](../images/upload_5455aaa76048644f067db38055dda778.png)


### 漏洞详情

点击列表最右侧操作区的 “查看”按钮，可查看某个漏洞的详情：

![](../images/upload_80838618bb3ac53c5f4f6d1ab717d109.png)

**字段含义**：

* **VPR 分值**：漏洞的处理优先级，分值越高，处理的优先级越高
* **漏洞衡量维度**：表示 VPR 分值的衡量维度，包含攻击途径、攻击复杂度等
* **漏洞趋势**：表示一定时间范围内，系统扫描时，该漏洞的出现频次

## 自定义POC

自定义 POC 用于扩展系统内置的漏洞检测能力。管理员可在此添加自编写的检测脚本。

![](../images/upload_026a8c5027465d0cceb63d7179dd993b.png)

**常用操作**：

* 查看：点击列表右侧的 “查看” 按钮
![](../images/upload_a2671111c0271120a318c896dff9986c.png)
* 检测：点击列表右侧的 “检测” 按钮，直接下发任务
  * PS. 自定义 POC 仅支持用“基础 Web 漏洞扫描”策略下发任务。


### 添加自定义 POC

点击列表右上角 “添加自定义 POC” - “手动添加”/“从文件上传”即可：

![](../images/upload_6848cce11b4f81cdb4788fe342675851.png)

**方式一：手动添加**

如图，手动配置信息并撰写检测脚本：

![](../images/upload_c7757757809ed4a9dbcd43ee4e8e9050.png)

* 漏洞信息：自定义 POC 中需要配置漏洞信息。若编号填写为系统 漏洞库 中已存在的漏洞知识，则 POC 扫出漏洞时会自动关联对应漏洞知识。反之，则会扫出一个自定义的漏洞
* 检测脚本：脚本编写比较复杂，请参考界面提供的 “《漏洞 yaml 格式自定义 POC 说明》”

**方式二：从文件上传**

如图，直接在弹窗中上传文件 POC .yml 文件即可：

![](../images/upload_ca1782205977a009542cbc8e3895abbd.png)

## 自定义指纹

自定义指纹用于扩展资产识别的能力，帮助系统更准确地识别资产的组件、版本等信息。与自定义 POC 类似，管理员可手动添加和维护自定义指纹检测脚本。

![](../images/自定义指纹.png)

点击右侧 “查看” 可查看指纹详情：

![](../images/upload_a3b2447a4d476c45416e1653b2509799.png)


### 创建自定义指纹

点击“添加自定义指纹”按钮，填入检测脚本即可：

![](../images/upload_4f8f08dceb9336facd5b39695b83990e.png)

脚本编写比较复杂，请参考界面最下方提供的 “《漏洞 yaml 格式自定义指纹说明》”
