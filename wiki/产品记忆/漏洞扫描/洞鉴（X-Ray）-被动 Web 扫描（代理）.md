# 被动 Web 扫描（代理）

## 策略介绍

被动 Web 扫描（代理）支持将洞鉴引擎配置为浏览器代理。用户通过浏览器访问目标网站时，洞鉴可以收集访问过程中的 URL 信息，并基于收集到的 URL 与漏洞探测 POC 插件生成漏洞探测请求，对网站进行漏洞检测。

访问链路如下：

```text
浏览器请求 <----> 洞鉴引擎（IP + 端口） <----> 目标网站
```

## 环境说明

以下配置示例以分布式部署为例：

- 管理节点：`10.9.34.2`
- 引擎节点：`10.9.33.241`

## 创建扫描任务

**步骤一：**新建被动 Web 扫描（代理）任务，并配置通用数据来源。

![被动 Web 扫描代理数据来源配置](../images/web_-1-07fa4c7d8a79.png)

- **接收地址**：单机部署时填写管理节点地址（`169.254.1.1`）；分布式部署时填写引擎节点地址。
- **代理服务器可用端口范围**：填写一个不常用的端口范围，避免与已有服务冲突。
- **用户名**：代理服务器用户名。
- **密码**：代理服务器密码。

**步骤二：**配置扫描目标。

![被动 Web 扫描代理目标配置](../images/web_-2-0d2e607a4fd7.png)

扫描目标用于过滤浏览器代理流量。引擎代理会接收浏览器中的所有流量，配置扫描目标后，洞鉴仅对命中的目标进行信息收集和漏洞探测。

**步骤三：**创建扫描任务后，页面会展示需要连接的代理地址和端口。

![被动 Web 扫描代理连接信息](../images/web_-3-cfe55788894e.png)

## 配置浏览器代理

以 Firefox 浏览器的代理扩展插件 `FoxyProxy` 为例。填写洞鉴页面展示的代理地址和端口，使浏览器流量通过洞鉴代理访问目标网站：

![FoxyProxy 代理配置](../images/web_-4-069db0f47c52.png)


## 配置 HTTPS 证书

如需访问 HTTPS 网站，需要下载并导入洞鉴提供的 HTTPS 根证书。

**步骤一：**在洞鉴 Web 页面下载 HTTPS 根证书。

![下载 HTTPS 根证书](../images/web_-5-c2eea1b32b13.png)

**步骤二：**在浏览器中导入证书：进入浏览器设置，搜索“证书”，选择下载的证书文件并导入。

![浏览器导入 HTTPS 证书](../images/web_-6-e5851f2f895d.png)

## 验证扫描结果

在浏览器中访问需要扫描的网站后，洞鉴扫描任务会发现 Web 页面，并开始进行漏洞扫描。
