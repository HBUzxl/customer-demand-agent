# 报表中心

此处可集中管理系统中的报表、报表模版。

## 报表管理

集中展示系统中所有报表，可在此处生成、下载、删除报表。

![](../images/upload_6733ba51f070a856ee7dc6f93fce7bbb.png)

* **预览报表**：点击“查看”按钮，即可在线预览 html 格式的报表内容。
* **下载报表**：在报表列表中“报表下载”列，点击文档 icon 即可下载对应报表文件。
* **批量下载报表**：选择一到多个报表，点击右上角 “批量操作”-“下载” ，选择一到多种格式，即可批量下载对应格式的报表：
![](../images/upload_a2fff0ed6043855f82474c3d323a4deb.png)


### 生成报表

点击列表右上角 “生成报表” 可添加新报表：

![](../images/upload_1a8109ab9be252ef6b7d1fac47b10222.png)

配置含义：

* **组织单位**：报表所属组织单位（详情可查询 “组织单位” 相关文档）
* **报表类型**：包含任务报表、资产报表、漏洞报表等，不同类型的报表的目标和内容不同
  * **扫描任务报表**：选择一到多个扫描任务实例生成报表
  * **资产报表**：选择一到多个 “主机和 Web 站点” 或 “资产组” 生成报表
  * **任务对比报表**：选择两个不同的扫描任务实例生成报表
  * **资产对比报表**：选择一到多个主机资产、再选择一个统计时间单位生成报表
  * ... 等等
* **报表模版**：每种报表类型对应一到多种报表模版，差异在于报表中的展示字段和筛选不同
* **拆分子报表**：建议报表内容过多开启。开启时，系统会将资产和漏洞信息单独拆成多份子报表进行输出，以避免文件过大，导致本地软件无法打开
* **合并生成/批量生成**：
  * 例如：扫描任务报表，点击“合并生成”按钮，单个或多个扫描任务实例数据会合并生成一个汇总任务报表；点击“批量生成”按钮，多个扫描任务实例会批量生成多个任务报表。



## 报表模板

此处可管理系统中的报表模版。每种报表类型对应一到多种报表模版，差异主要在于报表中的展示字段和筛选不同。

![](../images/upload_fd2584f34fd5cd1b7ac7449fc12f9e73.png)

点击列表右侧 “查看” 按钮，即可查看模版具体信息：

![](../images/upload_15ad184ccda90ba5fb18c18e127e193e.png)

#### 创建报表模板

点击“添加报表模板”按钮，即可添加新报表模版：

![](../images/upload_5f070e2189cbf2fedd8068cd401cc220.png)

配置含义：

* **报表类型**：每种报表类型的内容都不一样。先选报表类型，再勾选具体展示字段和筛选即可
* **数据筛选**：任务报表的筛选，仅生效于报表中的资产清单、漏洞清单，综述信息（即任务的概览和统计分析）与任务实际数据保持一致，不会受到筛选的影响
