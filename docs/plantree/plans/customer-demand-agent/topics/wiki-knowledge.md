## 产品记忆

### 页面模板

每个产品一个 Wiki 页面：

```markdown
---
type: entity
category: 产品
aliases: ["WAF", "SafeLine"]
tags: ["边界安全", "WAF", "Web防护", "CC防护"]
---

# 雷池（SafeLine）

## 一句话定位
长亭雷池下一代 Web 应用防火墙，7 层流量清洗...

## 核心能力
| 能力 | 说明 | 置信度 |
|------|------|--------|
| CC 攻击防护 | 基于行为分析的 CC 攻击检测与清洗 | 1.0 |
| SQL 注入防护 | 语义分析引擎，误报率低 | 1.0 |
| Bot 管理 | 恶意爬虫识别与拦截 | 0.8 |

## 适用场景
- 客户网站被频繁扫描/攻击
- 业务系统面临 Web 层威胁
- 等保合规需要边界防护

## 能力边界
- 不覆盖主机层威胁（需配合牧云）
- 不覆盖内网横向移动检测
- 不提供代码层漏洞修复

## 竞品对比
| 竞品 | 优势 | 劣势 |
|------|------|------|
| 华为WAF | 品牌知名度高 | 规则更新慢 |
| 绿盟WAF | 传统厂商积累 | AI 能力弱 |
```

### 检索

用户输入 → 分词 → 提取关键词 → 匹配产品标签 + 能力名 → 按置信度排序返回。

## 行业记忆

### 威胁类型

```markdown
---
type: entity
category: 威胁类型
aliases: ["CC", "HTTP Flood", "挑战黑洞"]
tags: ["DDoS", "应用层攻击", "Web安全"]
---

# CC 攻击（Challenge Collapsar）

## 定义
针对 Web 应用层的分布式拒绝服务攻击，模拟正常用户请求耗尽服务器资源。

## 典型表现
- 网站访问变慢或无法访问
- 大量来自不同 IP 的异常请求
- 服务器 CPU/内存飙高但带宽正常

## 关联产品
- 雷池（CC 防护）
```

## 检索策略

```text
用户输入: "我们做跨境电商，最近过等保二级"

1. 行业记忆/行业场景 → "电商"关键词 → 匹配电商页面
2. 行业记忆/合规 → "等保二级"关键词 → 匹配等保页面
3. 产品记忆 → 电商+等保的关联产品 → 雷池 + 洞鉴 + 万象
4. 用户记忆/客户画像 → 查客户名 → 如果是老客户，追加历史上下文
5. 用户记忆/使用者画像 → 查销售等级 → 调整输出风格
```

## AI 写入机制

Agent 分析过程中，如果发现以下情况，主动调用 `wiki_ensure_page` 写入 Wiki：

| 触发条件 | 写入目标 | 写入内容 |
|----------|----------|----------|
| 发现新的客户 | `用户记忆/客户画像/` | 自动提取行业、技术栈、痛点创建客户画像 |
| 客户信息有变 | `用户记忆/客户画像/` | 更新已有画像 |
| 发现新的威胁模式 | `行业记忆/威胁类型/` | 创建威胁类型页面，分析时标注"需人工审核" |
| 发现新的行业痛点 | `行业记忆/行业场景/` | 追加到对应行业页面 |

## 与 chaitin-products skill 的关系

`chaitin-products` skill 存的是**完整产品文档**（白皮书、用户手册、部署手册）。Wiki 页面是这些文档的**结构化摘要**——提取核心字段用于 prompt 注入。

产品文档更新 → 人审后提炼 → 更新 Wiki 产品页面。行业记忆和用户记忆则完全由 Agent 自主维护。
