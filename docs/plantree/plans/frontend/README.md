## 心智模型：三层可见性

一切"想看到的东西"按时间与范围分三层，每层有对应界面：

1. **即时层（对话内）**：发生时就在眼前——停止、编辑重发、ask_user
   选项卡、内联审核弹窗、运行指示、意图标记。
2. **会话层（飞行记录仪）**：一个会话发生过的一切，事后深检——
   消息+工具调用+checkpoint 行+每轮 LLM 审计（模型命中/回退/耗时）
   +每轮 system prompt 实例。
3. **系统层（观测台）**：跨会话与后台——任务、日志、健康、配置。

## 信息架构（六页收敛为五区）

| 区 | 路由 | 角色 | 吸收项 |
|---|---|---|---|
| 对话工作台 | `/analyze/:id` | 多会话并行；侧栏每会话运行点（G1 状态按 session 隔离 Map）；对话内 F1-F4 卡片；H2 意图徽标 | F0-F4、G1-G3、G6 会话搜索、H2 |
| 会话深检 | `/history/:id` | 回放升级为飞行记录仪：现有时间线表格 + checkpoint 行（P4）+ LLM 轮次审计行（C2 trace 补记后消费）；与对话页互跳不合并（操作现场 vs 验尸台） | P4、C2 审计 |
| 观测台 | `/observe`（新） | 后台任务列表（P11 固化/P5 Lint/G4 标题/F0 Run 队列）+ 任务实时事件流 tail；系统日志 tail；LLM 调用统计；系统健康（wiki/checkpoint/DB/启动配置快照） | C2、P11、F0 |
| 配置中心 | `/settings` | prompt 分层视图（L0-L3a，静态模板 vs 动态注入分块展示，ADR-016 可视化）；路由+fallback 链可视化；行为参数表；数据位置+记忆统计；远期 prompt 编辑（C3） | C1、C3 |
| 记忆库 | `/memory` | 管线阶段视图（捕获中 observe / 已固化 / 待审 pending 三列或过滤）；结构化编辑器（typed 字段表单）；「AI 抽结构」辅助按钮；版本链+回收站（P6/P10）；updated_by 留痕 | P11 人工侧、P6、P10 |

- **审核队列页消失**：主路径=对话内 F4 弹窗；兜底=记忆库"待审"过滤视图。
- **导航重组**：侧栏分两组——对话（新建/最近会话+运行指示）与系统
  （观测台/记忆库/设置）。审核不再占一级入口。

## G5 修订（原"回放/对话合并"否决）

操作现场与验尸台混装两边别扭：对话页要轻快（流式、卡片、操作），
深检页要密（表格、全量、审计）。保留两页互跳即可。

## 后端依赖 API（前端蓝图的缺口清单）

- F0：POST /api/message→202+run_id、GET /api/sessions/{id}/stream?since=N、
  POST .../runs/{id}/cancel、会话 running 状态
- C2：GET /api/tasks（+SSE tail）、GET /api/logs tail（后端日志流式）、
  trace 补记每轮模型命中/回退/耗时、GET /api/health 详情版
- C1：GET /api/prompts（分层模板）、记忆统计、fallback 配置已有
- P11：管线阶段状态（observe 计数/pending 数）、AI 抽结构（POST 触发）
- P6/P10：版本链查询、回收站列表、updated_by
