## 用户裁决（2026-08-15 原话）

> 「（可展开系统提示词行查看判定上下文）——我发现我们系统里会有一些
> 描述性的废话，没有必要……类似于这种描述性的废话，就是没有必要给
> 用户知道的、用户知道了也无所谓的东西；或者是明明有这个功能了，
> 但是你非得多此一举跟他提一嘴的东西，把用户当傻子的这种设计。
> 这种描述都给删掉。」

## 判定标准（从用户原话提炼）

删三类：

1. **解释内部机制**——「（可展开系统提示词行查看判定上下文）」：告诉
   用户去哪看 Agent 的判定依据，用户要么知道要么不在乎。
2. **内部行话外露**——用户可见文案出现 ADR-016 / L2 / L3a / 权限矩阵 /
   断点续传这类开发术语。
3. **自证式说明**——「点击行展开详情」（行本身可点，功能自解释）、
   「· 已提交结构化分析」（卡片本身就是分析，说了等于没说）。

保留：操作指引（用户完成动作必需的）、错误信息（含修复动作）、
状态标记（运行中/已停止——是信息不是解释）。
