# 侧边栏与模型管理体验修复

> 侧栏收缩态可用性 + 模型管理配置面与交互。状态：**Ready**（2026-08-15
> 用户实际使用反馈，三个问题均已核实根因）。

## 用户反馈（2026-08-15 原话）

> 「侧边栏我一搜索之后，就变成了只有这个，我只能新建。」
> 「侧边栏收缩之后……没有办法在收缩的情况下切换会话了，因为它没有在
> 前端显示对应的图标。我一收缩之后，它只能去新建会话。收缩之后的样式
> 你似乎没有好好设计，一边一坨。」
>
> 「模型管理内容太少：缺少一些必要的信息，比如最大上下文……有些东西
> 是可选，有些是必选，你需要标注清楚。可配置的东西应该是全的。」
> 「点击获取之后，应该出现一个下拉列表让用户选择。你现在是用弹窗，
> 而且弹窗里显示的还不是全量的模型，是让用户手动输入。」

## 现状核实（2026-08-15，代码证据）

### ① 侧栏收缩态功能性缺失

- 收缩态（`collapsed=true`）整个 conv-list 块 `!collapsed &&` 直接不渲染
  （AppLayout.tsx:118）——**收缩后无法切换会话**，只剩新建按钮+导航图标。
- 搜索框也包在 `!collapsed` 里——搜索词残留时展开显示被过滤后的列表，
  用户困惑「怎么只剩这些」；收缩/展开切换不清搜索词。
- 收缩态样式（index.css:293-308）只压了宽度，无会话头像/图标位设计。

### ② 模型管理配置面不全

后端 `ModelConfig` 仅 6 字段（name/endpoint/api_key/protocol/model/
temperature/max_tokens）。**缺**：最大上下文窗口（context window）、
请求超时（per-model）、重试次数、别名/备注、是否启用、base_path（网关
子路径）等。前端表单无「必选/可选」标注。

### ③ 获取模型交互不合理

Settings.tsx:103 `fetchModels` 拿到全量列表后用 `window.prompt` 让用户
**手动输入/复制粘贴**模型名——原生弹窗+手输，列表只是展示。后端
`/api/models` 返回完整列表（数据已全，纯 UI 问题）。

## 方案

### F1. 侧栏收缩态完整可用

- **收缩态会话快速切换**：收缩时显示最近 N 个会话的**圆点头像/首字图标**
  （取标题首字符，运行中绿点叠加——与展开态 run-dot 一致）；hover 展开
  tooltip 显示完整标题+时间；点击直接切换。
- **收缩/展开切换时清空搜索词**（或搜索词随会话切换保留但展开时可见
  搜索框+清除按钮——推荐前者，简单）。
- 搜索过滤后列表为空时显示「无匹配 + 清除搜索」按钮（不误以为会话丢了）。
- 收缩态整体样式重排：图标列垂直居中对齐、间距统一、新建按钮收缩成
  大「+」；导航图标 hover 背景一致。

### F2. 模型配置面补全 + 必选/可选标注

后端 ModelConfig 增字段（默认值兼容老 config——零迁移）：

| 字段 | 必选 | 说明 |
|---|---|---|
| name / endpoint / api_key / model / protocol | ✅ 必选 | 现有 |
| temperature / max_tokens | 可选（有默认 0.3/4096） | 现有 |
| `context_window` | 可选 | 最大上下文（token）——审计/预算参考 |
| `timeout_sec` | 可选 | per-model 超时（默认走全局 llm_timeout_sec） |
| `max_retries` | 可选 | per-model 重试（默认走全局） |
| `remark` | 可选 | 备注（如「DeepSeek 官方-便宜」） |
| `enabled` | 可选（默认 true） | 停用不删配置（路由跳过） |

- 前端表单重排：必选项一组（红星标注）；可选项折叠区「高级设置」展开；
  每项带说明 tooltip。
- console/config 只读视图同步展示新字段。
- 路由/回退链行为：enabled=false 的模型不出现在候选（fallback 链配置了
  停用模型时启动 warn）。

### F3. 获取模型改下拉选择

- fetch 成功后不再 prompt：模型卡内 model 字段旁出现**下拉列表**
  （`<datalist>` 或自定义 dropdown），列出网关返回的全量模型，当前值
  预选中；用户点选即写入。列表可搜索过滤（模型多时）。
- 失败保持现有错误横幅；空列表提示「网关未返回模型」。

## 非目标

- 不做模型连通性自动检测排序（获取列表已含测试语义）。
- 不做多 API key 轮换。
- 收缩态不做会话搜索（空间不够；搜索是展开态功能）。

## 验证

- F1：收缩态可见会话图标列、可点击切换、运行中绿点；搜索切换不残留。
- F2：config.example.json 含全字段；老 config 加载零迁移；表单必选缺失
  阻止保存；console 视图同步。
- F3：获取后出现下拉、点选写入、tsc/lint/build 绿。
