# 配置中心可配置化

> 把「配置中心」从写死只读展示改成真配置入口：该开放的开放、
> 该藏的藏。状态：**Done**（2026-08-15 二期 goal 落地）（2026-08-15 用户裁决方向；开放/隐藏清单
> 已盘点，具体交互待开工确认）。

## 用户裁决（2026-08-15 原话）

> 「设置里那个配置中心，我感觉没啥用。全是写死只读的，也配置不了。
> 要么把它变成非写死的、非只读的，让用户可以配置。具体配置逻辑：
>
> 1. 区分是否开放：有些东西可以配置，有些东西根本不需要配置，甚至
>    不需要给用户开放（用户不需要在后台看到）。
> 2. 区分配置类型：在需要配置的东西里，有些是可选配置，有些是必配。
>    反正基本上没有必须配置的，自由度高一点。
> 总之，把那些应该给用户开放的东西都开放出来，一些不该开放的东西
> 全给它省略掉就完事儿了。」

## 现状（2026-08-15）

C1 配置中心四个 GET（config/prompts/memory/health）+ ConsoleCenter 只读
组件：Prompt 分层视图、工具提示词、回退链可视化、行为参数表、数据位置、
记忆统计格——**零可写**。用户判断正确：纯展示没有使用价值。

## 方案

### F1. 开放/隐藏/只读 三态清单（全量盘点 Config）

**开放可配置**（设置页表单化，写回 config.json 走已有 PUT /api/config）：

| 项 | 必/可选 | 现状 | 改动 |
|---|---|---|---|
| 默认使用者 default_user | 可选 | 已可配（设置页） | 保留 |
| LLM 全局超时 llm_timeout_sec | 可选 | 只读展示 | 开放编辑 |
| Agent 最大迭代 agent_max_iterations* | 可选 | 只读展示 | 开放编辑（*当前是常量，需提升为 config 字段） |
| 回退链 router.fallback（max_retries/backoff_ms/chain） | 可选 | 只读展示 | 开放编辑（chain 为模型名有序列表） |
| 检索权重/聚合上限等记忆行为参数* | 可选 | 未暴露 | 按需提升为 config（先盘点常量表，逐个决定） |

**隐藏**（内部实现细节，用户无需看到，从配置中心删除）：

- Prompt 分层 L0-L3a 视图（这是给开发调试看 prompt 组装的，不是用户
  配置项——观测台 debug 入口保留或一并撤，待定）
- 工具提示词列表（同上，纯内部信息）
- 记忆统计（归观测台/记忆库页，配置中心不放）
- server.addr / frontend_dist（部署项，改配置文件重启，不进 UI）
- wiki_dir / history_db / data_dir（P9 数据根；改了要迁数据，UI 不开放，
  保留只读展示位置提醒）

**只读展示**（用户该知道但不应在 UI 改）：

- 数据位置（数据根/wiki/history 路径——移动需停服迁移，给路径+提示）
- 服务版本/健康（归观测台）

### F2. 配置项表单化

- 每个开放项：说明文字 + 输入控件 + 默认值提示 + 「恢复默认」。
- 可选项全部带默认值——不填=默认行为（用户说「基本上没有必须配置的，
  自由度高一点」；必选项仅模型注册那组，已在模型管理页）。
- 保存走现有 PUT /api/config 合并写回（已支持配置热更新+回写文件）。
- 与 sidebar-models-ux F2 的模型级参数（timeout/retries）联动：模型级
  覆盖全局，配置界面注明优先级。

### F3. 配置中心信息架构重排

- 「配置中心」tab 重命名「行为与参数」（或并入设置主页分节）：
  全局行为（超时/迭代/回退链）+ 记忆行为参数。
- 纯展示的 Prompt 分层/工具提示词/记忆统计迁到观测台（debug 语境）或
  删除（若观测台已有等价信息）。
- 保留「数据位置」只读卡（路径+迁移提示）。

## 非目标

- 不做 prompt 模板编辑（C3 编辑态明确排除在一期外；模板文件
  prompts/system.md 编辑重启生效已是后门）。
- 不做多配置 profile。
- 不开放 server/存储路径 UI 编辑。

## 验证

- 每个新开放字段：改→保存→GET 回读一致→行为生效（如改 max_iterations
  后 agent 循环上限变化有集成测试）。
- 常量提升（agent_max_iterations 等）零迁移默认值。
- 配置中心无纯展示死内容（每个区块要么可配要么明确只读理由）。
