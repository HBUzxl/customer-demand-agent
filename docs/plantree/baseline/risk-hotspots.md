# 风险热点

## 风险清单

| 风险 | 影响 | 概率 | 缓解 |
|------|------|------|------|
| LLM 输出格式不稳定（JSON 解析失败） | 高 | 中 | retry + fallback 纯文本；structured output 模式 |
| 产品知识不完整/过时 | 高 | 高 | Wiki 页面作为唯一权威源，建立更新机制 |
| LLM 幻觉（推荐不存在的产品功能） | 高 | 中 | prompt 中明确约束"仅限已知产品"；输出校验 |
| Token 预算超限（长对话+大知识库） | 中 | 中 | 压缩机制 + 知识检索截断 |
| 公司 LLM 网关不稳定 | 中 | 低 | 重试 + 超时 + 降级提示 |
| Go 项目结构不被团队接受 | 低 | 中 | 参考公司现有 Go 项目惯例 |
