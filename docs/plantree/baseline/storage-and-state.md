# 存储与状态

## 数据分类

| 数据 | 存储方式 | 生命周期 |
|------|----------|----------|
| 产品知识 | LLM Wiki 页面（只读） | 持久，手动更新 |
| 对话缓冲 | 进程内存 | 会话期间 |
| 压缩摘要 | 进程内存 | 会话期间 |
| 会话元数据 | 进程内存（map） | 会话期间 |

## 一期不做持久化

一期会话数据全部在进程内存中，服务重启即丢失。理由：
- 钉钉机器人场景下，每次粘贴是独立分析任务，不依赖历史
- 会话级上下文仅用于同一窗口内的追问
- 降低复杂度，聚焦记忆系统核心逻辑
